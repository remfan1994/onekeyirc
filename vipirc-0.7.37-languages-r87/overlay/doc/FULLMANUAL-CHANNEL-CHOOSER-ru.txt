EXACT COMMAND/CONTROL EXAMPLES (not translated):
Open    Join    Part    Close    Back

F3 или /channels (/cl, /views) показывает пункт 0 сервера/MOTD и сохранённые окна каналов, включая уже покинутые. Действует стандартная навигация по списку; действия: Open, Join, Part, Close, Back.

Join открывает Command с подготовленным /join и сохраняет черновики. Part покидает канал, сохраняя историю; Close удаляет окно. p выполняет Part, c - Close, o открывает Join. /channel NUMBER или #NAME выбирает окно; /view NUMBER использует нумерацию каналов, /view NAME выбирает окно по имени. После закрытия номера могут меняться: пользуйтесь текущим списком.

Close сначала выходит из канала, если он ещё посещается, удаляет историю и черновик, отменяет ожидающие сообщения этому адресату; уже отправляемое сообщение может завершиться. Непустой черновик требует подтверждения, по умолчанию No. Окна сервера и упоминаний закрыть нельзя; /disconnect останавливает сетевую работу сервера. /close [NAME|NUMBER] закрывает указанный канал/личную беседу либо текущую. Из канала 0 выходить нельзя. Back/Escape возвращает в чат.
