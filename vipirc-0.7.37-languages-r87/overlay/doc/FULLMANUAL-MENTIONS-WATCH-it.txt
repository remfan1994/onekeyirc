MENZIONI E STRINGHE MONITORATE

Il proprio nickname corrente viene monitorato automaticamente. La corrispondenza segue le regole sui maiuscoli e sui confini dei nickname annunciate dal server IRC. Cambiare nickname aggiorna tale corrispondenza automatica.

    /watch add project name
    /watch remove project name
    /watch list

I valori personalizzati sono sottostringhe letterali, non espressioni regolari né modelli di shell. Si applicano le regole IRC/ASCII per maiuscole, lettere e simboli; i caratteri non ASCII devono corrispondere esattamente. Sono ammessi fino a 32 valori personalizzati di 127 byte UTF-8 ciascuno. Durante l'uso normale, /save conserva le modifiche nella configurazione selezionata; in modalità di prova restano in memoria. Le menzioni sono conservate in memoria secondo i limiti della cronologia: non formano un archivio permanente di notifiche né un registro su disco. Le date/ore indicano la ricezione locale nel formato YYYY-MM-DD HH:MM:SS.
