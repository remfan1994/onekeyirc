Практическое руководство vipirc / onekeyirc - Каналы
=======================================================

ЧЕРНОВОЙ ПЕРЕВОД. Пишите команды и параметры точно как показано.
Точные правила безопасности - в английских MANUAL.txt и SECURITY.md.

/help list
----------

Запрашивает список каналов выбранного IRC-сервера; требуется регистрация. Серверу передаётся только фильтр MASK.

Фильтры минимума/максимума участников, имени и темы работают локально даже без расширенных фильтров LIST у сети.

Значения --sort: channel, users, topic; стандарт — users по убыванию. --limit 0 не ограничивает показ в ограниченном кэше.

/list show показывает кэш; --sort, --asc/--desc и --limit сортируют и ограничивают его без нового запроса IRC. /list clear очищает кэш.

При разрыве или отказе в LIST частичный кэш остаётся, но запрос завершается; повторите /list после регистрации либо /list clear.

Полноэкранный клиент открывает сортируемый каталог каналов; минимальный режим использует те же опции и /list show.

Для локального списка каналов используйте /ls или /cl; /list ищет в сети.

/help ls
--------

Без аргумента показывает каналы выбранного сервера. Это локальная команда клиента, не команда оболочки и не общесетевой запрос IRC LIST.

Используйте /server N, /channel N и /pm NICK для выбора соответствующих записей.

/help manual
------------

Справка по темам и командам доступна без соединения. /help TOPIC — краткий путь.

/help servers
-------------

Показывает слоты серверов 1..8 (основной 1), выбранный сервер, состояние и autoconnect для каждого сервера.

Загруженный профиль доступен даже без соединения.

/help unignore
--------------

То же, что /ignore remove MASK. Сохраните выбранный профиль, чтобы изменение сохранилось.

/help aliases
-------------

Альтернативные имена должны совпадать точно; неоднозначные или приблизительные команды не выполняются.

/conn = /connect; /disc = /disconnect; /detach = /background; /exit = /quit

/j = /join; /leave = /part; /message и /privmsg = /msg

/nickname = /nick; /names и /nicks = /users; /unaway = /back

/channellist = /cl; /querylist = /ql; /serverlist = /servers

/configure и /preferences = /panel; /saveconfig = /saveconf

/autocommand = /autocommands

Автодополнение предлагает канонические имена; аргументы не меняются, фильтрация секретов в истории сохраняется.
