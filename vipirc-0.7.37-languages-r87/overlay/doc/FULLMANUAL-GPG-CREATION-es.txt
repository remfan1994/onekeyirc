CREACIÓN DE ARCHIVOS DE CONTRASEÑAS CIFRADAS

Para crear una credencial GPG, use /panel desde cualquiera de las interfaces. Seleccione el servidor, elija gpg como fuente de autenticación o de contraseña del servidor y luego create. Se propone una ruta absoluta en un directorio de credenciales junto a la configuración seleccionada. Para la configuración principal predeterminada:

    ~/.config/vipirc/credentials/account-password.gpg

La contraseña PASS usa server-password.gpg. Los nombres existentes se omiten y se proponen alternativas numeradas. El panel muestra la ruta absoluta real; la tilde del ejemplo es explicativa, no sintaxis literal de configuración. Enter acepta el destino propuesto y puede preparar los directorios privados con modo 0700. Ver la propuesta no crea nada. Para un destino personalizado debe existir un directorio padre privado, propiedad del usuario; nunca se cambian permisos a los directorios existentes. Se comprueban el destino y gpg local antes de pedir clave y contraseña. Introduzca la huella hexadecimal completa de 40 o 64 dígitos de una clave de cifrado ya presente en el llavero GPG local, y escriba dos veces la contraseña oculta. Pueden seguir seleccionándose archivos cifrados existentes. Las rutas que se introducen en el panel se almacenan como absolutas: cambiar el directorio de inicio no altera su significado. No se descarga ni genera ninguna clave, ni se crea archivo de contraseña en claro.

Solo la acción final Save, Apply o Connect inicia el cifrado y publica el nuevo texto cifrado solicitado, con modo 0600. Apply only y Connect once pueden crear el archivo cifrado sin guardar la configuración. Se rechazan archivos existentes y enlaces simbólicos. Cada auxiliar dispone de cinco segundos; la interfaz continúa atendiendo la red. Si el cifrado falla, los ajustes no se aplican y se informa de la ruta y el motivo sin mostrar secreto ni salida del auxiliar. Finish distingue destinos propuestos de archivos ya creados. Si funciona, remite a /autoauth status para consultar rutas completas; si falla el guardado o hay publicación parcial, mantiene las ubicaciones en la revisión desplazable. Puede reintentarse guardar la configuración sin cifrar de nuevo. La cancelación solo elimina archivos nuevos sin cambios de este intento; conserva los ya referenciados en una configuración guardada. Escape retrocede una pregunta y cancela la creación pendiente; cerrar la configuración borra las entradas ocultas. El modo sin conexión rechaza crear antes de acceder a GPG, al llavero o a archivos. Para descifrar más tarde, desbloquee fuera del programa la clave privada cuando sea necesario.
