МИНИМАЛИСТИЧНЫЙ ИНТЕРФЕЙС

    vipirc -i
    vipirc --idle --test-mode
    /connect irc.ircnow.org
    /join #ircnow
    /saveconf

Режим -i использует ту же конфигурацию vipirc и тот же каталог серверов. По умолчанию ник берётся из допустимого имени учётной записи или пользователя. Команда /saveconf сохраняет настройки и исправные профили, а также запоминает выбранное соединение, включая дополнительный профиль, для следующей команды /connect без аргументов. Сохранение само по себе не включает автоподключение. /quickstart и /panel — необязательные мастера настройки.

Обычный экран — журнал. / открывает Command, ? — контекстную справку, а остальные печатаемые символы начинают ввод в Compose и сохраняются. Enter или Insert открывает пустой Compose. В живом журнале Up прокручивает на одну сохранённую строку назад, Page Up — на страницу, Home — к самой старой сохранённой странице; Down/Page Down/End удерживают просмотр в конце живого потока. Left/Right/Delete/Backspace там не действуют. В просмотрщике истории End или Escape возвращают к живому потоку.

Стрелки в Compose редактируют текст, но не вызывают ранее отправленные сообщения. Tab/Shift-Tab дополняют ники в Compose и названия команд в Command. В Command клавиша Down выбирает подсказки; Up/Down перемещают по ним, а Up на первой возвращает к строке ввода. Enter вставляет выбранную подсказку; для выполнения после её появления нужен отдельный Enter. Up в строке Command вызывает принятые команды, совпадающие с вводом; Down возвращает к исходному черновику. Полное описание клавиш: /help keys и /help commands.

Режим line оставляет одну строку ввода под концом живого журнала; fullscreen использует многострочный редактор с меньшей областью живого журнала. Перерисовка при поступлении сообщений сохраняет черновик и позицию курсора. Escape выходит из редактора в журнал; Escape в журнале переводит процесс в фоновый режим. В Review клавиша Escape или новый ввод восстанавливают прежний редактор, черновик и курсор; новое нажатие Enter подтверждает. Ctrl-D не действует без явной привязки; сигналы терминала сохраняют унаследованное назначение. Распознанная вставка остаётся буквальным текстом и не может отправить сообщение.

    /set send_mode direct|review
    /set composer_mode line|fullscreen
    /set output_format compact|full
    /save input
    /save output

По умолчанию выбраны немедленная отправка, однострочный ввод и краткий вывод [HH:MM:SS] <nick> text. Формат full добавляет дату/сервер/адресата; упоминания и диагностика между серверами сохраняют необходимый контекст в обоих форматах. Эти настройки принадлежат основному профилю и действуют на всех серверах. Отдельное подтверждение лимита байтов и согласие на несколько сообщений по-прежнему обязательны.

/help ls перечисляет темы; /help /ls объясняет локальную команду списка. Для синтаксиса и примеров используйте /help COMMAND, указывая за раз только одну тему или команду. /manual и vipirc -i --manual выводят полную справку минималистичного режима, которая также находится в doc/vipirc-idle-manual.txt. Команды и управление отличаются от полного режима ncurses. Справка и длинные ответы команд открываются в отдельном просмотрщике с ограниченным размером. Стрелки/Page Up/Page Down/Home/End прокручивают, Escape возвращает назад. Enter прокручивает справку, но закрывает успешно полученный список /users. / из просмотрщика открывает Command; отмена возвращает в просмотрщик. Новый результат команды заменяет предыдущий. Клавиша r в Summary обновляет снимок состояния. Работа сети продолжается во время чтения.

/panel начинает с 0 Application preferences: история, режимы отправки/ввода, вывод, уведомления, ведение журналов, режим одного сеанса, подсказки команд и интерфейс по умолчанию. В конце предлагаются Save или Apply without saving; это не устанавливает соединение и не переключает чат. В обоих интерфейсах панели профилей пронумерованы 1..8: панель 1 редактирует основной профиль, называемый server 0 в полном режиме и 1 в минималистичном. Панели изменяют настройки отдельных серверов, в том числе идентификацию bouncer. В конце предлагаются Save and connect, Save only (по умолчанию), Connect once или Apply only. /quickstart спрашивает сервер/TLS/порт/ник и по умолчанию предлагает Connect once; существующие данные входа в bouncer не меняются.

Enter сохраняет показанный ответ; '-' очищает необязательное поле. Escape возвращает на шаг назад или выходит из первого вопроса. Tab выбирает заголовок для справки ?, после чего Tab/Enter продолжает редактирование. Скрытые пароли и ответы никогда не попадают в историю команд. Только завершающий выбор применяет/сохраняет/подключает; активное соединение не перенаправляется, а последующая ошибка подключения не отменяет явные изменения. Полный vipirc тоже поддерживает эти мастера; /settings там открывает графическую форму.

В минималистичном /servers номера 1..8, в полном /servers — 0..7. Channel 0 — вид сервера/MOTD в обоих интерфейсах. Основная настройка истории ограничивает внутреннее хранение всех разговоров жёсткими пределами из /help history. Необязательная запись журнала открытым текстом по умолчанию отключена. DCC использует общие явные команды /dcc без графических форм.
