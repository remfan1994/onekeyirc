PLATTFORMEN, KOMPILIERUNG UND LIZENZ

Zielplattformen sind Linux, die Linux-Umgebung von ChromeOS und BSD-Systeme. Zum Kompilieren werden C11, POSIX-Schnittstellen, GNU/BSD getopt_long, Wide-Character-Curses und passende TLS-Entwicklungsdateien benötigt. Der Client braucht keine Laufzeitumgebung einer Programmiersprache. Python 3 dient Tests und Dokumentationsgenerierung; mit den mitgelieferten Exportdateien sind normales Bauen und Chatten ohne Python möglich. Abhängigkeiten stehen in INSTALL.

    ./configure
    make
    make check-offline
    make check
    make install PREFIX="$HOME/.local"

INSTALL beschreibt Abhängigkeiten und Bau, SECURITY.md das Sicherheitsmodell und Grenzen. Tatsächlich getestete Plattformen stehen im Validierungsbericht zur Version. Eine native BSD-Ausführung erfordert eigene Prüfung: Portabilitätsabsicht beweist keine Tests auf allen Unix-Systemen. make check-offline führt CLI-/PTY-Tests ohne Netzwerksocket aus; make check nutzt zusätzlich lokale simulierte Server auf Loopback.
