CRÉER DES FICHIERS DE MOTS DE PASSE CHIFFRÉS

Pour créer un identifiant GPG, utilisez /panel dans l'une ou l'autre interface. Choisissez le serveur, gpg comme source d'authentification ou de mot de passe serveur, puis create. Un chemin absolu est proposé dans un répertoire d'identifiants adjacent à la configuration sélectionnée. Pour la configuration principale par défaut :

    ~/.config/vipirc/credentials/account-password.gpg

Le PASS serveur utilise server-password.gpg. Les noms déjà occupés sont évités au profit d'alternatives numérotées. Le panneau affiche le véritable chemin absolu ; le tilde ci-dessus est explicatif, pas une syntaxe à copier dans la configuration. Enter accepte l'emplacement proposé et peut préparer ses répertoires privés en mode 0700. Consulter la proposition ne crée rien. Un chemin personnalisé nécessite un répertoire parent privé existant et appartenant à l'utilisateur ; les droits de répertoires existants ne sont jamais modifiés. L'emplacement et la présence de gpg sont vérifiés avant de demander la clé et le mot de passe. Entrez l'empreinte hexadécimale complète de 40 ou 64 chiffres d'une clé de chiffrement déjà dans le trousseau GPG local, puis saisissez deux fois le mot de passe masqué. Les fichiers chiffrés existants restent sélectionnables. Les chemins du panneau sont enregistrés en absolu ; changer de répertoire de lancement ne change donc rien. Aucune clé n'est téléchargée ni générée, aucun fichier de mot de passe en clair n'est créé.

Seule l'action finale Save, Apply ou Connect déclenche le chiffrement et publie le nouveau texte chiffré demandé avec le mode 0600. Apply only et Connect once peuvent créer ce fichier sans enregistrer la configuration. Les fichiers existants et liens symboliques sont refusés. Chaque auxiliaire dispose de cinq secondes ; l'interface continue de traiter le réseau. En cas d'échec, les réglages restent sans application et le chemin et la raison sont indiqués sans secret ni sortie de l'auxiliaire. Finish distingue emplacements proposés et fichiers déjà créés. Une réussite invite à consulter /autoauth status pour les chemins complets ; après échec de sauvegarde ou publication partielle, les emplacements restent dans la vue de révision défilante. Une sauvegarde de configuration ratée peut être retentée sans rechiffrer. L'annulation ne supprime que les nouveaux fichiers inchangés de cette tentative ; ceux déjà référencés par une configuration enregistrée sont conservés. Escape revient à la question précédente et annule la création en attente ; fermer l'assistant efface les champs masqués. Le mode hors ligne refuse toute création avant l'accès à GPG, au trousseau ou aux fichiers. Pour déchiffrer ultérieurement, déverrouillez la clé privée hors de l'application si nécessaire.
