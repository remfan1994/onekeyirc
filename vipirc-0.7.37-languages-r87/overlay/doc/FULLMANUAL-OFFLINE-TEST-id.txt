vipirc --test-mode --config /absolute/config.ini --no-connect

Simulasi memakai antarmuka, editor, filter, serta penanganan protokol dan antrean yang berlaku, tetapi tanpa soket jaringan, DNS, pembacaan sandi atau berkas CA, GPG, maupun penyimpanan. Nama host terkonfigurasi hanyalah label. Setiap profil memiliki simulator sendiri; New server menambah simulator lain. Nilai server atau nama panggilan yang kosong tidak memunculkan pertanyaan. Kanal demonstrasi bawaan adalah #test-one dan #test-two jika tidak ada kanal yang dikonfigurasi.

Simulasi dimulai setelah layar selamat datang meskipun autoconnect tersimpan; --no-connect menahannya. /disconnect dan /connect menghentikan atau memulai simulator terpilih. Untuk jaringan nyata, keluar lalu mulai ulang tanpa --test-mode. Simulator lokal C tidak memerlukan daemon eksternal atau Python.

Setiap dua detik muncul peristiwa obrolan, sebutan, kata pantau, percakapan privat, dan perubahan daftar anggota. Kata pantau khusus bergilir sekali per siklus 16 detik. /msg mendapat balasan simulasi berlabel; JOIN/PART/NICK/WHOIS/TOPIC/AWAY juga dibalas secara simulasi. Ini tidak menirukan semua aturan server, izin kanal berkunci, SASL, atau pengiriman nyata.

Uji pembungkusan baris, penyuntingan lintas baris, pengubahan ukuran, penempelan, peringatan/konfirmasi, sebutan, dan daftar. Tawaran DCC contoh hanya ada di memori: tinjau/tolak/batalkan berfungsi, tetapi Send/Accept ditolak sebelum mengakses berkas atau soket. Menutup server sekunder hanya mengubah keadaan saat berjalan. Penulisan konfigurasi dan berkas penghitung dinonaktifkan; sunting konfigurasi dari luar dan jalankan ulang untuk perubahan tetap.

--check-config adalah pemeriksaan terpisah atas sintaks dan nilai berkas tersimpan. Kedua mode tidak membuktikan DNS, TLS, kredensial, atau interoperabilitas bouncer yang sebenarnya.
