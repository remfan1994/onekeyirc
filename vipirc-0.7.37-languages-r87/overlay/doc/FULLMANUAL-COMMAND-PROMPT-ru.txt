ПОЛЕ ВВОДА КОМАНД

Откройте Command через F1 > Command, через / либо введя / при нулевой позиции курсора чата. Черновик и позиция курсора чата сохраняются отдельно. Косая черта в другом месте или внутри защищённой вставки в чат остаётся текстом. Enter/Run отправляет команду; Escape/Cancel возвращает на экран, откуда её открыли, включая Summary. Пустой ввод ничего не делает. Принятые команды возвращают в чат, кроме открывающих иной экран; неверные/отклонённые остаются редактируемыми.

Settings > Interface > Command suggestions предлагает пять режимов: Commonly used (подборка по умолчанию с учётом соединения/вида), Recent history (принятые целые строки, новые первыми), Most used (счётчики канонических команд сохранённого профиля), Alphabetical (имена реализованных команд) и Contextual (приоритет экрана-источника с сохранением остальных совпадений).

Для фильтра введите начало имени команды без учёта регистра; аргументы не предсказываются. Down выбирает предложение, Up/Down листает, Up с первого возвращается к вводу. Enter на предложении только вставляет его, не исполняет: строка каталога сохраняет уже введённые аргументы, строка истории вставляет всё целиком. Проверьте и отредактируйте, затем отдельно нажмите Enter после показа. Дополнительные байты Enter из одной пачки ввода не выполнят команду. ? на выделенной строке открывает справку и возвращает выделение; ? в поле ввода буквальный.

Delete удаляет выделенную запись Recent либо сбрасывает счётчик Most used, но никогда реализованную команду. Page Up/Page Down и колёсико прокручивают список. Невидимые строки в очень маленьком терминале не выбираются. Right в конце префикса дополняет/перебирает имя; щелчок по предложению вставляет его. Tab не переходит к заголовку и не запускает команды. Дополнение ников остаётся в чате.

Up из поля ввода вызывает принятые команды, начинающиеся с исходного префикса; Down переходит к более новым и обратно к исходному черновику. Аргументы сравниваются byte-for-byte. Неудачные команды не сохраняются. История — максимум 64 записи/64 KiB на сервер, подряд идущие одинаковые объединяются, старые вытесняются. Вызов истории возможен лишь пока открыты этот интерфейс и сервер; смена интерфейса или завершение worker стирает её.

Постоянные счётчики отдельны: CONFIG_PATH.commands содержит максимум 96 канонических имён и ограниченные счётчики, но не аргументы, адресатов или переписку. Сохранённый профиль обеспечивает автоматическую приватную атомарную запись после принятых команд/сбросов; для несохранённых профилей счётчики остаются в памяти до Save. Ошибочный/отсутствующий файл счётчиков не мешает запуску. Test mode не читает и не пишет их; основная конфигурация их не хранит.

Команды join с ключом и распознанные служебные/аутентификационные сообщения полностью исключаются из истории; исключаются и безвредные сообщения известным чувствительным службам. Фильтр не может обнаружить абсолютно любой секрет; не вводите их в обычный чат. Управление баунсером описано в BOUNCER CONNECTIONS.

Вставка в Command — только данные: CR/LF/Tab превращаются в пробелы, недопустимые управляющие знаки/размеры вызывают сообщение; всё равно требуется новое Enter/Run. Нет кавычек, подстановок, объединения команд или исполнения оболочки. Аргументы TEXT/PATH получают остаток строки буквально; заключайте #channel в кавычки лишь в настоящей оболочке. /msg, /me и // соблюдают ограничения сообщений, интервалы и обязательное согласие на разбиение с ответом No по умолчанию. // означает обычный чат и не попадает в историю команд. Действия Join/New предварительно заполняют /join или /pm.
