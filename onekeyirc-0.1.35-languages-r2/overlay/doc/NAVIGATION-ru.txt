vipirc / onekeyirc - navigation help (ru)
==========================================

IRC commands and uppercase arguments are entered literally.
For full English security and protocol details see MANUAL.txt.

/channel
--------
Номера указаны в /channels. Выбор меняет текущий диалог и адресата следующего обычного сообщения.
Команда не входит в канал. Перед отправкой нужно снова войти в канал, из которого вы вышли.

/channels
---------
Канал 0 всегда показывает сообщения сервера/MOTD. Для личных диалогов есть список /ql.
Строки показывают вход/выход, число непрочитанных сообщений и упоминаний.

/cl
---
Список каналов сервера, включая канал 0 для сообщений сервера и состояние входа/выхода.
Выберите /channel NUMBER или /channel #NAME. Для личных диалогов есть отдельный список /ql.

/close
------
Без аргумента закрывает текущий диалог. Перед удалением вида клиент выходит из канала.
Постоянные виды сервера и упоминаний закрывать нельзя. Номера каналов есть в /channels.

/disconnect
-----------
Без номера отключает выбранный сервер. История и настройки сохраняются.
Это не меняет автоподключение при следующем запуске.

/help
-----
Для списка тем: /help ls; для команд: /help commands; для одной команды: /help autoconnect.
Укажите тему или команду без аргументов. /help /ls описывает локальный список; /help ls показывает темы. Начальный слэш необязателен.
/help all открывает полное руководство в отдельном окне справки.

/me
---
Нужны открытый канал или личный диалог и зарегистрированное соединение. Действуют лимиты и режим отправки.
Перед постановкой разделённого сообщения в очередь интерфейс предлагает его проверить.

/mentions
---------
Открывает упоминания этого сервера. Хранит ограниченное число последних строк с исходным временем.
/mentions clear удаляет сохранённые копии упоминаний со всех серверов без смены вида.
Исходная история бесед, непрочитанные сообщения и ожидающие действия сохраняются.
Для дополнительных фраз используйте /watch; /channel или /pm вернёт в диалог с отправкой.

/msg
----
Нужна регистрация. Команда готовит отправку; режим прямой/проверки и согласие на разделение сохраняются.
Не меняет адресата незаметно. Сообщения служб и учётных данных не входят в историю команд.

/next
-----
Переключает сервер, упоминания, каналы и личные беседы; внутренний буфер руководства пропускается.

/nick
-----
При подключении запрашивает подтверждение смены сервером. Без связи меняет имя для следующего входа.
Ники используют поддерживаемый синтаксис IRC ASCII и ограничены 63 байтами.

/pm
---
Имя открывает или выбирает личный диалог. Номер выбирает существующий диалог из /ql этого сервера.
Открытие диалога не связывается с ником до отправки. После закрытия номера могут измениться.

/prev
-----
Обратная команда к /next. Не подключает, не входит в каналы и не отправляет.

/ql
---
Номера личных диалогов начинаются с 1 отдельно от каналов. Выберите /query NICK или /query NUMBER.
Закройте диалог через /close NICK и снова откройте /ql: последующие номера могли смениться.

/queries
--------
Использует тот же список личных диалогов, что /ql. Нумерация каналов отдельная.

/settings
---------
Показывает настройки программы отдельно от ожидающих параметров подключения выбранного сервера.
Способ аутентификации показан по типу источника; пароли и пути к ключам не печатаются.
Для изменения настроек используйте /autoconnect, /autojoin, /autoauth и /set.

/sl
---
Использует тот же список серверов и стабильные номера слотов, что /servers.
Выберите сервер через /server NUMBER.

/unread
-------
Строки содержат номер сервера, имя беседы, непрочитанные сообщения и упоминания.
Выберите /server NUMBER, затем /channel или /pm для перехода к беседе.

/view
-----
Номера каналов есть в /channels, имена личных диалогов в /ql. Подходят также сервер и упоминания.
Используйте /help вместо внутреннего буфера руководства.

/views
------
Псевдоним использует номера каналов; личные диалоги остаются в /ql.
