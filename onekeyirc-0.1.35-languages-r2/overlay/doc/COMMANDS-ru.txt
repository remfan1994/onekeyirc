vipirc / onekeyirc - command guide (ru)
=======================================

Commands, argument names and saved configuration keys remain literal.
For complete reference and security details see MANUAL.txt and SECURITY.md.

/autoconnect
------------
Без аргументов показывает настройки выбранного сервера. Изменения действуют при следующем запуске.

Используйте /connect для немедленного подключения, /save для сохранения выбора запуска.

У каждого сохраненного сервера свои настройки автоподключения, автовхода в каналы и аутентификации.

/away and /back
---------------
Требуется регистрация. Сервер подтверждает статус отсутствия. MESSAGE - буквальный текст.

То же, что /away без сообщения. Требует регистрации на сервере.

/cancel
-------
Удаляет ожидающие отправки сообщения и останавливает отложенные автокоманды выбранного сервера.

Кадр, который уже записывается, может быть завершен.

Отмена не отзывает сообщения, уже полученные сервером.

/query, /ql, /pm
----------------
Выбирает личный диалог без отправки сообщения. Пишите как обычно для этого ника.

Команда /ql показывает нумерованные диалоги, /close NICK закрывает диалог. /pm принимает те же имена и номера.

Номер должен указывать существующий диалог на выбранном сервере; 0 не выбирает и не создает диалог.

/background
-----------
Используйте /background, чтобы соединения продолжали работать.

/whois
------
Требуется регистрация. Открывает вид сервера для показа ответа. Локальные команды не выполняются.

/nick
-----
Ники используют поддерживаемый синтаксис IRC ASCII и ограничены 63 байтами.

/server
-------
Загруженный профиль доступен даже без соединения.

Уже настроенный подходящий сервер сохраняет порт, транспорт, ник и аутентификацию.

/autoauth
---------
Сохраните через /save. Сначала отключитесь, затем /connect применит изменения; текущее соединение не меняется.

/autojoin
---------
Изменения проверяются до применения; входа в канал или выхода из него не будет.

/bindings
---------
По умолчанию нет своих привязок клавиш. Списки имен: /bindings keys и /bindings actions.

/connect
--------
Значение PORT по умолчанию 6697. Другой порт не выключает TLS; открытый текст надо выбрать явно.

/help
-----
Неизвестная команда. См. /help commands или /help COMMAND; оболочка и сырые команды IRC недоступны.
