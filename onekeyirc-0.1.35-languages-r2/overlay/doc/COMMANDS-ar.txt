vipirc / onekeyirc - command guide (ar)
=======================================

Commands, argument names and saved configuration keys remain literal.
For complete reference and security details see MANUAL.txt and SECURITY.md.

/autoconnect
------------
دون وسيط، يعرض إعداد الخادم المحدد. تسري التغييرات عند التشغيل التالي.

استخدم /connect للاتصال فورا، و/save لحفظ خيار الاتصال عند بدء التشغيل.

لكل خادم محفوظ إعداداته الخاصة للاتصال التلقائي والانضمام للقنوات والمصادقة.

/away and /back
---------------
يلزم التسجيل لدى الخادم. يؤكد الخادم حالة الغياب. MESSAGE نص حرفي.

مثل /away بلا رسالة. يتطلب اتصالا مسجلا.

/cancel
-------
يزيل رسائل الدردشة المنتظرة ويوقف الأوامر التلقائية المعلقة للخادم المحدد.

يسمح بإكمال الإطار الذي بدأت كتابته.

الإلغاء لا يسحب الرسائل التي استلمها الخادم بالفعل.

/query, /ql, /pm
----------------
يختار محادثة خاصة دون إرسال رسالة. اكتب كالمعتاد لمراسلة هذا اللقب.

استخدم /ql لسرد المحادثات المرقمة و/close NICK لإغلاق إحداها. يقبل /pm الأسماء والأرقام نفسها.

يجب أن يشير الرقم إلى محادثة موجودة على الخادم المحدد؛ لا يحدد 0 محادثة ولا ينشئها.

/background
-----------
استخدم /background لإبقاء الاتصالات جارية.

/whois
------
يلزم التسجيل. يعرض نافذة الخادم لتظهر الاستجابة. لا ينفذ أمرا محليا.

/nick
-----
تستخدم الألقاب صيغة IRC ASCII المدعومة وبحد أقصى 63 بايت.

/server
-------
يظل الملف الشخصي المحمل متاحا حتى عند عدم الاتصال.

يحتفظ الخادم المطابق الحالي بمنفذه ونوع اتصاله ولقبه وإعدادات المصادقة.

/autoauth
---------
استخدم /save للحفظ. افصل الاتصال أولا ثم استخدم /connect لتطبيق التغييرات؛ لا يعاد توجيه الاتصال النشط.

/autojoin
---------
يتم التحقق من التغييرات قبل تطبيقها، ولا تنضم إلى قناة نشطة أو تغادرها.

/bindings
---------
لا توجد روابط مفاتيح مخصصة افتراضيا. راجع /bindings keys و/bindings actions للأسماء المدعومة.

/connect
--------
PORT الافتراضي هو 6697. تغيير المنفذ لا يعطل TLS؛ يجب اختيار الاتصال غير المشفر صراحة.

/help
-----
أمر غير معروف. استخدم /help commands أو /help COMMAND؛ أوامر الصدفة وIRC الخام غير متاحة.
