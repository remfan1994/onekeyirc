CONNECTION HELP LOCALIZATION - 2026-11-19
Client: onekeyirc 0.1.42
Paired release: vipirc 0.7.43 and onekeyirc 0.1.42.

COVERAGE
  405 display text entries in each of 10 languages.
  Exact interactive command/topic help: 122/477 (25.6%).
  Newly translated detailed help lines: 40 per language.
  355 help lines have no translated catalog key.

SCOPE
  /connect: transport, first connection, server profile selection.
  /autoauth: current/pending auth, literal paths and GPG boundaries.
  /autojoin: pending/current channel lists and bouncer exceptions.
  /saveconf: save scope, atomic writes, default server selection.
  /help reconnect: backoff, errors that do not retry and staged settings.
  /help tls: host verification, CA bundles and certificate pinning.
  Corrected an earlier --check-config translation which omitted CA-source
  validation limits. Command spelling and configuration values are literal.

DOCS
  doc/CONNECTION-XX.txt contains translated help excerpt for locale XX.
  Generated by tools/generate_locale_connection_guides.py from the exact
  source help and JSON catalog. English SECURITY.md and MANUAL.txt remain
  authoritative, and the complete manuals are not localized.

TESTING
  tests/test_connection_help_translation.py checks 49 displayed lines
  (40 new, 9 earlier) for consistency and literal syntax in all 10 locales.
  tests/test_l10n_connection_terminal.py checks actual offline output.
  Source and untranslated-help coverage are measured, not estimated.
  These tests are not certification of linguistic quality or bidi layout.

LIMITATIONS
  Translations are drafts requiring native-speaker review.
  Arabic needs right-to-left shaping and terminal testing.
  Native OpenBSD and full vipirc ncurses tests are pending.
