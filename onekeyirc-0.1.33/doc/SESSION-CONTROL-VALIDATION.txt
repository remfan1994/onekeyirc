NEW FEATURE COVERAGE

The close protocol fixture checks attached/detached identity, separate
controller EOF, second attachment refusal, UID/token/reused-job rejection,
unexpected rights and reserved fields, partial replies, acceptance without
completion, original lease release before completion, legacy fallback,
bounded HUP/close waits and restored shared tty flags/alternate screen.
Socket calls/file type are mocked; files, locks, PTYs and signal handlers
are real. This is not native AF_UNIX or SCM_RIGHTS runtime coverage.

The actual-main fixture checks saved startup choice, nonpersistent -i/-N
overrides, -n nickname compatibility, fixed standalone mode, management
without config/TTY, malformed/conflicting options, result propagation and
IRC/DCC teardown before background_finish can confirm completion.

Config/client/command/panel regressions verify strict transactional parsing,
legacy absence, both serialized values, primary ownership, live/lazy/new
profile propagation, Save/Apply/cancel behavior and active-session retention.
The full ncurses Settings regression is included but remains unexecuted.

The idle terminal-loss fixture passes all seven cases, normal and ASan/UBSan:
master closure, backlogged closure, managed HUP, controller EOF, stdin EOF,
stdin EIO and unmanaged HUP. Managed cases retain draft/history, keep IRC
PING responsive, detach actual standard descriptors, restore shared tty flags,
reattach to a fresh terminal and honor subsequent TERM. Initial managed setup
and handshake are substituted because AF_UNIX is denied. EOF/EIO are injected
at the production read boundary; PTY master closure/backlog are real.

The full-UI cleanup-boundary fixture extracts the production loss branch and
checks actual backend detach before deliberately blocking stdio cleanup. It
does not link or run the complete curses UI. Baseline blocks until its alarm.

Baseline idle comparisons: simple PTY closure already passed; backlogged
closure failed with exit 1, managed HUP with 129, stdin EOF/EIO with 0/1.
The corresponding fixed managed cases all pass with continuing IRC traffic.
