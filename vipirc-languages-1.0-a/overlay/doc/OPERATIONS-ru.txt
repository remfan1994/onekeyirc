vipirc / onekeyirc - selected operations help (ru)
====================================================

DRAFT - selected help excerpts only; not a complete security manual.
Commands, numeric limits and file names must be entered literally.
Authoritative reference: English MANUAL.txt and SECURITY.md.

/help deployment
----------------
Для запуска сеанса без терминала и приветственного нажатия используйте --background.

Настройте и сохраните /autoconnect on для каждого запускаемого сервера.

--background сам не включает autoconnect; --no-connect по-прежнему запрещает соединения при запуске.

Предупреждение выводится один раз до отсоединения. Успех означает локальное задание, а не вход на IRC.

В другом терминале той же учётной записи используйте --sessions и --resume [NUMBER].

Перезапуск VPS завершит задания, черновики и историю в RAM. Системная задача может запустить новый клиент.

Инструкции OpenBSD и необязательный пример rc.d: doc/OPENBSD-VPS.txt.

Запускайте как обычный пользователь с абсолютными путями конфигурации и секретов. Ключ GPG не сможет запросить ввод при загрузке.

--check-config проверяет настройки, но не доступ к секретам, DNS, TLS или вход на IRC.

Для временных сбоев сети используйте --reconnect; контроль падения процесса выполняет ОС отдельно.

/help security
--------------
Удалённый текст очищается перед выводом в терминал. Ввод трактуется как локальные команды IRC, а не команды оболочки.

Нет /raw, выхода в оболочку и автоматического приёма файлов. Распознанная вставка в скобках не выполняет команду.

Свой пакет CA должен быть непустым обычным файлом PEM размером до 16 MiB; пароль не запрашивается.

Запись бесед на диск по умолчанию выключена. Изменения конфигурации нужно явно сохранять.

См. /help tls, /help authentication, /help logging и SECURITY.md: ограничения и прошлые проверки.

/help history
-------------
История сообщений и команд ограничена в RAM. Постоянные журналы необязательны и по умолчанию отключены.

При смене вида показываются последние записи; /mentions показывает совпадающие исходные строки.

/clear удаляет историю вида из RAM, но не старый журнал на диске. Повтор bouncer предоставляет сам bouncer.

Up/Down в Compose двигает курсор, не возвращает отправленный чат. В Command возвращаются только принятые команды.

/help hotkeys
-------------
Свои назначения клавиш необязательны и изначально пусты. Обычная навигация и редактор сохраняются.

Для списка: /bindings, клавиш: /bindings keys, функций: /bindings actions.

Назначьте через /bind KEY ACTION; повторное назначение заменит. Удалите через /unbind KEY или /unbind all.

/help logging
-------------
/clear очищает лишь RAM. Журналы остаются после выхода, --close-session и сохранения. Выключение записи останавливает новые записи, не удаляя старые.
