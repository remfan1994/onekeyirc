СПИСОК ЛИЧНЫХ БЕСЕД

F4 или /ql (/queries) показывает только личные беседы этого сервера, нумеруя их с 1 независимо от каналов. Действуют обычные клавиши списков и пункты:

    Открыть    Новый    Закрыть    Назад

New открывает Command с подготовленной /pm; в пустом списке Open на New query... делает то же самое. c закрывает, o/n открывает New. Закрытие непустого черновика требует подтверждения, по умолчанию No. /pm NICK|NUMBER или /query NICK|NUMBER открывает/выбирает беседу без отправки, даже без подключения. /msg NICK TEXT явно отправляет сообщение; /close NICK закрывает беседу по имени.

Escape из личной беседы открывает Queries с выделенной беседой независимо от способа её открытия; Escape/Back из списка возвращает беседу и черновик. Имя собеседника остаётся в строке беседы и не заменяет категорию заголовка.
