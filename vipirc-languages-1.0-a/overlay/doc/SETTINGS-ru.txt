Практическое руководство vipirc / onekeyirc - Настройки
=======================================================

ЧЕРНОВОЙ ПЕРЕВОД. Пишите команды и параметры точно как показано.
Точные правила безопасности - в английских MANUAL.txt и SECURITY.md.

/help set
---------

direct — режим по умолчанию: Enter отправляет текст; для нескольких сообщений IRC нужно подтверждение.

review добавляет проверку перед постановкой обычных сообщений в очередь.

output_format compact — по умолчанию: выбранный чат показывает [HH:MM:SS] <nick> текст.

output_format full выводит сервер, дату и цель каждой строки. compact сохраняет происхождение упоминаний и диагностики других серверов.

queue_notices off скрывает обычные уведомления очереди и повтор после проверки. Ошибки и подтверждение нескольких сообщений видны.

program_messages off скрывает мелкие сообщения об отмене черновика, очистке ввода и сохранении черновика. Ошибки и предупреждения остаются видны.

persistent_logging on: .log (0600) в частном каталоге 0700. Обычно выключен. Лимит 16 MiB: архив, off/on. Опасный/занятый файл остановит запись, чат продолжится.

single_session on оставляет одну фоновую задачу клиента; --resume без номера однозначен. Несколько серверов IRC допустимы в одной сессии.

default_interface задаёт интерфейс при новом запуске, если доступно; текущий не меняет. /save input сохраняет выбор.

command_suggestions выбирает алфавит, частые, последние, самые используемые команды либо подходящие исходному экрану.

composer_mode line оставляет строку ввода под чатом; fullscreen даёт многострочный редактор и окно чата. По умолчанию: line.

part_message и quit_message — причины выхода IRC по умолчанию. Явный текст /part или /quit заменяет их; пустое значение отключает.

background_away отправляет background_away_message после /background или потери терминала. autoaway_minutes включает away при простое; 0 отключает.

Только установленный клиентом away сбрасывается после возврата или реального ввода. Ручной /away не изменяется и не сбрасывается.

«Часто используемые» — по умолчанию. «Контекстные» выделяет команды канала, диалога, сервера или клиента, сохраняя другие совпадения.

«Часто используемые» использует заранее заданный удобный порядок. «Контекстные» помнит исходный экран, включая общий просмотр сводки.

Это настройки клиента для всех серверов. Для сохранения используйте /save input или /save output.

/panel, затем 0, меняет эти настройки и общий предел истории.
