vipirc / onekeyirc - authentication and bouncers (ar)
=====================================================

DRAFT TRANSLATIONS - native-speaker review is outstanding.
Commands, flags, values and config keys must be entered literally.
The English SECURITY.md and MANUAL.txt remain authoritative.

/help soju
----------
يلزم ملف soju متصل معد عبر /panel. دون وسيط يطلب المساعدة من BouncerServ.

ترسل COMMAND رسالة خاصة واحدة بتباعد زمني، بلا صدى محلي أو سجل للأوامر.

اتصال IRC المباشر لا يدعم هذا الاختصار. تظهر الردود في عرض الخادم.

راجع مساعدة الوسيط لأوامر الحساب والشبكة.

/help znc
---------
يلزم ملف ZNC متصل معد عبر /panel. دون وسيط يطلب Help من *status.

ترسل COMMAND رسالة خاصة واحدة بتباعد زمني، بلا صدى محلي أو سجل للأوامر.

استخدم /msg *module COMMAND لوحدة ZNC مفعلة. تظهر الردود في عرض الخادم.

اتصال IRC المباشر لا يدعم الاختصار. راجع مساعدة الوسيط لأوامره.

/help authentication
--------------------
تأتي بيانات الدخول من ملف كلمة السر أو محتوى GPG المفكوك؛ المسارات حرفية.

استخدم /panel لإنشاء سر مشفر بـ GPG لبصمة مفتاح عام محلي موجود.

استخدم مفتاح GPG مفتوحا مسبقا. لا يعمل pinentry داخل محرر الدردشة.

تقبل قيم password= و server_password= الصريحة في ملفات الإعداد الخاصة.

اختر مصدرا واحدا لكل سر. يخفي /settings و /summary مسارات الملفات.

يعرض /autoauth status مسارات الأسرار الحالية والمعلقة دون قراءتها أو كشف كلمات السر.

للوسيط، أدر الدخول ومصدره معا عبر /panel؛ ترفض تعديلات /autoauth.

يجب أن تكون ملفات الأسرار عادية مملوكة للمستخدم بنمط 0600 أو 0400؛ تمنع الروابط وتجاوز المجلد الأب.

حد SASL هو 1024 بايت، و PASS العادي 503 بايت. يجب أن يلائم دخول ZNC سطرا واحدا من IRC.

يفحص --check-config الإعداد والمصدر دون قراءة الأسرار أو اختبار الدخول. راجع /help tls و /help bouncers.

/help tls
---------
حزمة CA الخاصة ملف عادي غير فارغ حتى 16 MiB. يسمح برابط رمزي إلى CA؛ مسارات الأسرار والإعداد أشد قيودا.

يفتح ملف CA مرة مع فحص حجمه أثناء القراءة. ترفض FIFO والأجهزة وغيرها؛ لا يطلب PEM المحمي كلمة سر تفاعليا.

حد حجم الملف لا يحد تأخير I/O للملفات العادية أو الشبكية. استخدم حزمة CA موثوقة على تخزين ملائم.

/help bouncers
--------------
أدخل مضيف الوسيط ومنفذ TLS، مستخدم الوسيط، اسم شبكة المنبع الموجودة، واسم عميل ثابت اختياري.

تعمل أوامر البدء الصريحة أيضا. راجعها قبل تفعيل ملف الوسيط لمنع تكرار الانضمام أو أوامر الخدمات.

حالة away التلقائية عند الخمول أو الخلفية مغلقة ما لم تفعل للوسيط. يعمل /away و /back اليدويان.

السجل محدود. لا بحث أرشيف عند الطلب ولا اكتشاف تلقائي للشبكات ولا إنشاء ملف لكل شبكة.

راجع doc/BOUNCERS.txt وأمثلة الوسيط في examples/ للإعداد وحدود الاختبارات المنفذة.
