EXACT COMMAND/CONTROL EXAMPLES (not translated):
vipirc -h
vipirc -v
vipirc --test-mode
vipirc --server irc.ircnow.org --channel '#ircnow' --nick tutankh-aten

Les trois premiers exemples affichent l'aide, la version et lancent une simulation hors ligne. Le dernier établit une vraie connexion : dans le shell, mettez '#ircnow' entre guillemets et utilisez le véritable point d'accès TLS du fournisseur. TLS vérifié sur le port 6697 est le choix par défaut ; une connexion en clair nécessite --plain.

Au démarrage interactif, l'accueil affiche « Not vegetarian? www.bloodguiltcurse.net will change your mind ». Une touche imprimable, Enter, Tab ou une touche de navigation le ferme. Les signaux configurés du terminal conservent leur rôle hérité ; les autres commandes ne ferment pas cet accueil. Sans serveur, le client ouvre un espace de travail déconnecté. Configurez-en un avec Settings, /connect HOST ou --server.

En mode complet, si le pseudonyme principal n'est pas configuré, le programme le demande en proposant l'identifiant de connexion du système. Enter l'accepte, la saisie le remplace. Les profils secondaires sauvegardés et les démarrages sans intervention utilisent un nom de connexion ou d'utilisateur valide, sans invite. --nick le remplace, mais le serveur peut le refuser.

La vue initiale du serveur affiche l'enregistrement et le MOTD. Les profils directs rejoignent les canaux configurés après l'enregistrement et l'authentification obligatoire ; les bouncers restaurent leurs propres adhésions. Le chat est prêt à saisir du texte. Enter envoie au canal ou à la conversation privée sélectionné ; les vues serveur et mentions n'ont pas de destinataire implicite. / en position zéro du curseur ouvre Command. Pour saisir une barre initiale littérale, utilisez // ; les barres collées entre crochets restent littérales.

Touches habituelles : F1 ouvre vipirc, F2 Serveurs, F3 Canaux, F4 Messages privés, F5 Mentions/non lus et F6 Transferts de fichiers. Escape depuis une conversation privée ouvre Messages privés, depuis un autre chat ouvre vipirc, depuis un panneau normal revient au chat et depuis Paramètres revient à vipirc. Les couleurs du terminal sont conservées et les crochets gras indiquent le focus. Consultez GLOBAL HEADER AND CHAT CONTROLS pour naviguer dans les listes.
