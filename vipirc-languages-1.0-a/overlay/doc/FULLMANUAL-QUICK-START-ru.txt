EXACT COMMAND/CONTROL EXAMPLES (not translated):
vipirc -h
vipirc -v
vipirc --test-mode
vipirc --server irc.ircnow.org --channel '#ircnow' --nick tutankh-aten

Первые три примера показывают справку, версию программы и запускают автономную симуляцию. Последний устанавливает настоящее соединение: заключите '#ircnow' в кавычки в командной оболочке и укажите действительный TLS-узел провайдера. По умолчанию используется проверенный TLS на порту 6697; для незашифрованного подключения нужен --plain.

При интерактивном запуске выводится приветствие «Not vegetarian? www.bloodguiltcurse.net will change your mind». Его закрывает печатная клавиша, Enter, Tab или клавиша навигации. Настроенные сигналы терминала сохраняют унаследованное назначение; остальные клавиши приветствие не закрывают. Без сервера открывается отключённое рабочее пространство. Настройте сервер через Settings, /connect HOST или --server.

Если в полном интерфейсе не задан основной ник, программа предлагает имя системного входа как значение по умолчанию. Enter принимает его, ввод заменяет. Сохранённые вторичные профили и запуск без оператора используют допустимое имя входа или пользователя без запроса. --nick заменяет его, однако сервер может отклонить ник.

Первое окно сервера показывает регистрацию и MOTD. Прямые профили входят в настроенные каналы после регистрации и обязательной аутентификации; баунсеры восстанавливают своё членство в каналах. Поле чата готово к вводу. Enter отправляет в выбранный канал или личную беседу; в окнах сервера и упоминаний не подразумевается получатель. / при позиции курсора ноль открывает Command. Для буквального начального слеша используйте //; слеши, вставленные в скобках, остаются буквальными.

Обычные клавиши: F1 открывает vipirc, F2 Серверы, F3 Каналы, F4 Личные сообщения, F5 Упоминания/непрочитано, F6 Передачи файлов. Escape из личной беседы открывает Личные сообщения, из других чатов - vipirc, из обычной панели возвращает к чату, из Настройки - к vipirc. Цвета терминала сохраняются; жирные квадратные скобки показывают фокус. Навигация по спискам описана в GLOBAL HEADER AND CHAT CONTROLS.
