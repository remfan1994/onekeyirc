ИНТЕРФЕЙС ПО УМОЛЧАНИЮ

Чтобы сделать минималистский режим постоянным выбором, выполните в любом интерфейсе:

    /set default_interface idle
    /save input

Также можно использовать Настройки > Интерфейс > Интерфейс по умолчанию или /panel > 0. Другой способ — указать default_interface=idle в существующем разделе [session] основного файла настроек, не удаляя остальные ключи. Если параметр не задан, используется ncurses. Выбор действует при новых запусках, включая --background; он не переключает текущий интерфейс и не переподключает IRC.

-i/--idle или -N/--ncurses явно выбирают интерфейс для данного запуска; действует последняя опция, а сохранение других настроек не делает её постоянной. Строчная -n/--nick по-прежнему задаёт ник. Чтобы вернуть полный интерфейс по умолчанию, выполните /set default_interface ncurses и /save input. Вторичные профили не владеют этой настройкой.

--resume без опции интерфейса сохраняет интерфейс существующего рабочего процесса. -i --resume NUMBER запрашивает минималистский, -N --resume NUMBER — ncurses, без переподключения или замены процесса. Старые процессы без поддержки переключения сохраняют свой интерфейс. При смене теряются локальные для интерфейса черновики и история вызова команд; заранее прочитайте RUNNING IN THE BACKGROUND. onekeyirc всегда использует минималистский интерфейс и отклоняет -N/--ncurses..
