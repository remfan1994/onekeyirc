Практическое руководство vipirc / onekeyirc - Конфигурация
======================================================

ЧЕРНОВОЙ ПЕРЕВОД. Пишите команды и параметры точно как показано.
Точные правила безопасности - в английских MANUAL.txt и SECURITY.md.

/help configuration
-------------------

[connection] содержит server, port, tls, nick, username, realname, channel, autoconnect, auth и источники учётных данных.

[bouncer] type=none|znc|soju, username, network, client и automatic_away задают bouncer-профиль сети; см. /help bouncers.

[input] send_mode=direct|review и [output] format=compact|full, queue_notices=true|false, program_messages=true|false, persistent_logging=true|false - параметры основного файла.

[input] command_suggestions=common|history|frequent|alphabetical|contextual задаёт порядок команд; по умолчанию common.

[input] composer_mode=line|fullscreen выбирает ввод/команды в простом интерфейсе; обычно line. Оба показывают новые сообщения.

[input] use_signals=false По умолчанию Use signals = no. Ctrl-C и Ctrl-Z отменяют неотправленное сообщение или команду, не завершая и не приостанавливая программу. Выберите yes на панели 0 или в настройках Interface клиента vipirc, чтобы разрешить сигналы терминала. Apply действует сразу; Save также сохраняет [input] use_signals=true|false. При выходе и приостановке исходные настройки терминала восстанавливаются.

[hotkeys] содержит до 64 необязательных KEY=action без значений по умолчанию. Основной файл; см. /help hotkeys.

[session] single_session=true|false разрешает несколько фоновых заданий; по умолчанию false.

[session] default_interface=ncurses|idle - настройка главного профиля. Варианты запуска описаны ниже.

Формат compact задан по умолчанию. history_lines в главном файле ограничивает историю всех серверов.

[mentions] word= и [ignore] mask= можно повторять.

[autocommands] хранит enabled, delay_seconds, interval_seconds и повторяемые строки command= для сервера.

Текст команд хранится открыто в закрытом файле. /autocommands скрывает секреты в списках и истории.

Дополнительные серверы сохраняются в соседнем каталоге .servers и папке .d.

Подключитесь через /connect HOST, затем /join #channel и /saveconf для сохранения рабочей настройки.

/saveconf сохраняет предпочтения, исправные профили и выбранный сервер для следующего /connect без аргументов.

/quickstart задаёт четыре вопроса. /panel: 0 - настройки, 1..8 - профили; панель 1 меняет основной.

Правки панели скрыты до Finish. Путь GPG может создать каталог 0700; шифрование, запись и подключение ждут последнего выбора.

Для сохранения: /save - выбранный сервер; /save input или /save output - основной; /saveconf - исправные профили и выбор.

Счётчики команд читаются и пишутся в <config_path>.commands; главный конфиг их не содержит.

Закрытый ограниченный файл хранит только имена команд и счётчики, без аргументов и истории. Тестовый режим его не читает и не пишет.

Правки [connection] через /autojoin или /autoauth действуют при следующем отключённом /connect, не меняя текущий сеанс.

Файлы конфигурации закрыты; каждый заменяется атомарно, но не вся группа одной транзакцией. Импорта/экспорта нет.

Неизвестные разделы, ключи и значения - ошибки. Значения буквальные, без кавычек shell, экранирования, переменных и ~.

Обычные значения обрезаются по краям. password= и server_password= хранят всё после = до конца строки; без кавычек и комментариев.

Сохранение перезаписывает настройки и удаляет ручное форматирование/комментарии. Заметки храните отдельно.

Секреты: /help authentication; CA: /help tls; дисковые логи: /help logging; активные процессы: /help sessions.
