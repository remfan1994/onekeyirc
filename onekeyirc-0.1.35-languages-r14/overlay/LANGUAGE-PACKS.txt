onekeyirc 0.1.35 - OPTIONAL LANGUAGE + ARABIC RTL PATCH r14

Use onekeyirc-0.1.35-english-source-r1.tar.gz and
onekeyirc-0.1.35-languages-r14.tar.gz.
Apply only to a fresh extracted English r1 source before configure/make:
  sh onekeyirc-0.1.35-languages-r14/apply.sh onekeyirc-0.1.35
Never layer this over r11 or any other language pack. The application version
remains 0.1.35; identify the build as English source r1 plus language+RTL patch r14.

Arabic visual text and editing (system FriBidi and a UTF-8 locale required):
  ONEKEYIRC_LANG=ar ONEKEYIRC_ARABIC_VISUAL=1 ./onekeyirc
vipirc also supports the same setting with -i for its minimalist interface.
Use visual mode only when the terminal does not already shape/reorder Arabic.
Leave the visual variable unset or 0 for ordinary logical text.

r12 improves editor redraw/cursor consistency under allocation failure,
one-column boundary movement, ncurses mark cells and history row consistency,
and repeated paragraph layout work during minimalist scrolling.

All ten languages retain 844 catalog entries and complete minimalist manuals:
  ONEKEYIRC_LANG=ar ./onekeyirc --manual > manual-ar.txt
  doc/MINIMAL-MANUAL-XX.txt (XX: en id ms tr es pt fr de ru it ar)
Exports, stored text and IRC wire text remain logical UTF-8.

The English/Arabic terminal guides document current behavior and tests.
Native target terminal/OpenBSD validation, full ncurses manual/security
translation and native-speaker review remain pending.
