/help aliases
-------------

تُقبل الأسماء البديلة المطابقة تماماً فقط؛ لا يُنفذ أمر غامض أو تقريبي.

/conn = /connect; /disc = /disconnect; /detach = /background; /exit = /quit

/j = /join; /leave = /part; /message و /privmsg = /msg

/nickname = /nick; /names و /nicks = /users; /unaway = /back

/channellist = /cl; /querylist = /ql; /serverlist = /servers

/configure و /preferences = /panel; /saveconfig = /saveconf

/autocommand = /autocommands

يقترح الإكمال الأسماء الأساسية؛ تبقى الوسائط كما هي ويظل ترشيح الأسرار من سجل الأوامر كما هو.

/help authentication
--------------------

استخدم TLS الموثق مع /autoauth sasl USER file PATH أو /autoauth sasl USER gpg PATH.

تأتي بيانات الدخول من ملف كلمة السر أو محتوى GPG المفكوك؛ المسارات حرفية.

استخدم /panel لإنشاء سر مشفر بـ GPG لبصمة مفتاح عام محلي موجود.

استخدم مفتاح GPG مفتوحا مسبقا. لا يعمل pinentry داخل محرر الدردشة.

تقبل قيم password= و server_password= الصريحة في ملفات الإعداد الخاصة.

اختر مصدرا واحدا لكل سر. يخفي /settings و /summary مسارات الملفات.

يعرض /autoauth status مسارات الأسرار الحالية والمعلقة دون قراءتها أو كشف كلمات السر.

تطبق إعدادات المصادقة عند /connect بعد قطع الاتصال؛ يحفظها /save.

للوسيط، أدر الدخول ومصدره معا عبر /panel؛ ترفض تعديلات /autoauth.

يجب أن تكون ملفات الأسرار عادية مملوكة للمستخدم بنمط 0600 أو 0400؛ تمنع الروابط وتجاوز المجلد الأب.

حد SASL هو 1024 بايت، و PASS العادي 503 بايت. يجب أن يلائم دخول ZNC سطرا واحدا من IRC.

يفحص --check-config الإعداد والمصدر دون قراءة الأسرار أو اختبار الدخول. راجع /help tls و /help bouncers.

/help bouncers
--------------

افتح /panel واختر الخادم ثم نوع الاتصال znc أو soju.

أدخل مضيف الوسيط ومنفذ TLS، مستخدم الوسيط، اسم شبكة المنبع الموجودة، واسم عميل ثابت اختياري.

احفظ ملفا لكل شبكة خلف الوسيط. اختر الملف الصحيح قبل /connect عند اشتراكها في المضيف.

ينشئ العميل هوية الدخول. يستخدم ZNC مصدر كلمة مرور الخادم، وsoju مصدر كلمة مرور التوثيق. أدخل كلمة مرور bouncer فقط، لا هوية مركبة أو كلمة مرور NickServ.

يعيد الوسيط القنوات. لا يعاد تشغيل /autojoin المحلي ولا تعديله؛ استخدم /join و /part.

تعمل أوامر البدء الصريحة أيضا. راجعها قبل تفعيل ملف الوسيط لمنع تكرار الانضمام أو أوامر الخدمات.

حالة away التلقائية عند الخمول أو الخلفية مغلقة ما لم تفعل للوسيط. يعمل /away و /back اليدويان.

يحفظ السجل المدفوع أوقات UTC الأصلية ويوجه الخاص إلى مستلمه، ولا ينشئ إشارات ذكر ولا ينفذ CTCP/DCC ولا يغير الحالة الحية.

السجل محدود. لا بحث أرشيف عند الطلب ولا اكتشاف تلقائي للشبكات ولا إنشاء ملف لكل شبكة.

استعمل /znc أو /soju بلا وسيطات لمساعدة الخدمة. لا يدخل نص التحكم في السجل أو الصدى؛ تظهر الردود في عرض الخادم دون تسجيل دائم.

تخفى نسخ التحكم الصادرة المعروفة حتى عند replay باسم قديم. قد يبقى النص المحرر ظاهرا؛ ولدى bouncer سياسة تسجيل مستقلة.

يتصل العميل بالوسيط فقط. اضبط TLS والمصادقة وحفظ السجل عند المنبع بشكل مستقل.

راجع doc/BOUNCERS.txt وأمثلة الوسيط في examples/ للإعداد وحدود الاختبارات المنفذة.

/help configuration
-------------------

[connection] يضم server وport وtls وnick وusername وrealname وchannel وautoconnect وauth ومصادر بيانات الدخول.

[bouncer] type=none|znc|soju وusername وnetwork وclient وautomatic_away تحدد ملف bouncer لكل شبكة؛ انظر /help bouncers.

[input] send_mode=direct|review و[output] format=compact|full, queue_notices=true|false, program_messages=true|false, persistent_logging=true|false تفضيلات الملف الرئيسي.

[input] command_suggestions=common|history|frequent|alphabetical|contextual يحدد ترتيب الأوامر؛ الافتراضي common.

[input] composer_mode=line|fullscreen يحدد تخطيط الكتابة والأوامر المبسط؛ الافتراضي line. كلاهما يعرض الرسائل الحديثة.

يعطّل [input] use_signals=false الإشارات التي تولّدها الطرفية أثناء تحكم العميل في tty. يفعّل true تعيينات الإشارات الحالية. يسري «تطبيق» فورا؛ ويحفظ «حفظ» التفضيل في الإعداد الرئيسي.

يحوي [hotkeys] حتى 64 ربط KEY=action اختياريا بلا افتراضات. يخص الإعداد الرئيسي؛ انظر /help hotkeys.

[session] single_session=true|false يحدد السماح بعدة مهام بالخلفية؛ الافتراضي false.

[session] default_interface=ncurses|idle تفضيل للملف الرئيسي. خيارات البدء موضحة أدناه.

المظهر compact هو الافتراضي. تحدد history_lines في الإعداد الرئيسي طول السجل المحفوظ لكل الخوادم.

يمكن تكرار [mentions] word= و[ignore] mask=.

يحوي [autocommands] كلا من enabled وdelay_seconds وinterval_seconds وأسطر command= متكررة للخادم.

تخزن الأوامر كنص واضح في ملف خاص. يدير /autocommands النص دون كشف الأسرار في القوائم أو السجل.

تستخدم ملفات الخوادم الإضافية المحفوظة فهرس .servers والمجلد المجاور .d.

اتصل عبر /connect HOST ثم استخدم /join #channel و/saveconf لحفظ الإعداد الناجح.

يحفظ /saveconf التفضيلات وملفات الخوادم السليمة والخادم المختار لاستخدام /connect لاحقا بلا وسيطات.

يطرح /quickstart أربعة أسئلة للاتصال. يستخدم /panel الرقم 0 للتفضيلات و1..8 للملفات؛ اللوحة 1 للرئيسي.

تبقى تعديلات اللوحة خاصة حتى «إنهاء». قد يُنشئ قبول مسار GPG مجلد 0700؛ التشفير والحفظ والاتصال تنتظر القرار النهائي.

للبقاء بعد إعادة البدء: /save للخادم المختار، /save input أو /save output للرئيسي، أو /saveconf للملفات السليمة والافتراضي.

تستخدم الإعدادات المحفوظة <config_path>.commands لقراءة وكتابة عدد الأوامر؛ الملف الرئيسي لا يخزن الأعداد.

هذا الملف الخاص المحدود يحوي أسماء الأوامر القياسية وأعدادها فقط، لا الوسيطات أو الرسائل. وضع الاختبار لا يقرأه ولا يكتبه.

تسري تعديلات [connection] من /autojoin أو /autoauth عند /connect التالي بعد الفصل؛ الاتصال النشط لا يتغير.

ملفات الإعداد خاصة؛ يُستبدل كل ملف بصورة ذرية، وليس كامل المجموعة كعملية واحدة. لا توجد أوامر استيراد/تصدير.

القسم أو المفتاح أو القيمة غير المعروفة خطأ. القيم حرفية دون اقتباس shell أو هروب أو متغيرات أو ~.

تزال المسافات الطرفية من القيم العادية. يحتفظ password= وserver_password= بكل ما بعد = حتى نهاية السطر؛ لا تضف تعليقات أو اقتباسات.

يعيد الحفظ كتابة الإعدادات المدعومة ويزيل التنسيق والتعليقات اليدوية. احتفظ بالملاحظات خارج الملف المولد.

انظر /help authentication للأسرار و/help tls لـCA و/help logging للسجلات و/help sessions للمهام الحية.

/help deployment
----------------

استخدم --background لبدء جلسة من دون طرفية أو ضغط مفتاح الترحيب.

اضبط واحفظ /autoconnect on لكل خادم ينبغي تشغيله.

لا يفعّل --background الاتصال التلقائي وحده؛ ويظل --no-connect مانعا لاتصالات البدء.

يظهر التحذير المعتاد مرة قبل فصل الطرفية. النجاح يؤكد مهمة محلية، لا نجاح تسجيل الدخول إلى IRC.

من طرفية أخرى بالحساب نفسه استخدم --sessions و--resume [NUMBER].

يشمل --sessions المهام ذات الطرفيات المرفقة. يفصل --detach-session NUMBER الطرفية دون إنهاء المهمة لاستئنافها من مكان آخر. ينهي --close-session NUMBER المهمة المحددة وكل اتصالات IRC فيها.

استخدم معرف المهمة المدرج، لا PID. قد تفشل العمليات غير المستجيبة أو القديمة التي لا تدعم التحكم المطلوب. راجع /help sessions للاستعادة والترقية.

إعادة تشغيل VPS تنهي المهام والمسودات وسجل RAM. يمكن لمهمة بدء النظام إطلاق عميل جديد.

إرشادات OpenBSD ومثال rc.d اختياري في doc/OPENBSD-VPS.txt.

شغّل البرنامج كمستخدم عادي بمسارات مطلقة للإعدادات وبيانات الدخول. لا يستطيع مفتاح GPG المغلق طلب إدخال عند إقلاع النظام.

يتحقق --check-config من الإعدادات، لا من الوصول إلى بيانات الدخول أو DNS أو TLS أو تسجيل دخول IRC.

استخدم --reconnect لانقطاع الشبكة المؤقت؛ مراقبة تعطل العملية مسؤولية مستقلة لنظام التشغيل.

يجب أن تتيح برامج التشغيل انتظار العمليات التابعة: تجاهل SIGCHLD أو حصد العمليات التابعة تلقائيا يفشل أول بدء في الخلفية أو إنشاء محلل الأسماء أو مساعد بيانات الاعتماد. إعادة فصل مهمة مدارة لا تنشئ عملية عاملة جديدة.

/help documentation
-------------------

ابحث عن المهمة عبر /help ls؛ يشرح /help commands إدخال الأوامر ويسردها. اكتب اسم موضوع أو أمر واحد كل مرة.

يعرض /help COMMAND الصيغة والتأثير والأمثلة. يشرح /help /ls القائمة المحلية؛ ويسرد /help ls المواضيع.

يفتح /help all أو /manual المرجع. يشرح --help خيارات البدء؛ ويمكن حفظ خرج --manual في الوضع المبسط في ملف.

يرشد README.md إلى الوثائق؛ يشرح MANUAL.txt الواجهة وINSTALL البناء. وتشرح صفحة man المثبتة استعمال shell.

يشرح CONTRIBUTING.md التعديل؛ يحدد doc/SOURCE-MAP.txt مواضع الكود، وtests/README.md الاختبارات. يوثق DESIGN.md الترتيب والمسؤولية.

يعرض doc/TROUBLESHOOTING.txt فحوص الأعراض. يبين SECURITY.md التهديدات؛ ويشرح doc/BOUNCERS.txt وdoc/SESSION-CONTROLS.txt التشغيل. كل تدقيق يخص نسخته وبيئته.

/help history
-------------

سجل العرض والأوامر محدود في RAM. التسجيل الدائم اختياري ومعطل افتراضيا.

تغيير العرض يعيد آخر السجلات المحفوظة؛ ويعرض /mentions أسطر المصدر المطابقة.

يحد إعداد سجل التطبيق عدد السجلات في جميع الخوادم والعروض معا؛ عدله عبر /panel ثم 0.

حد الاحتفاظ هو الأصغر بين ذلك الإعداد و2048 سجلا، مع حد أقصى مستقل للحجم قدره 512 KiB.

يبدأ /catchup في قناة أو محادثة خاصة عند آخر نص ألفته وأرسلته محليا. يجرب سجلا خاصا مؤهلا ثم الذاكرة المحتفظ بها؛ يشرح /help catchup القارئين.

الاستدراك الدائم منفصل لكل خادم ومحادثة. يجب تفعيل التسجيل الدائم قبل إرسال رسالة الارتكاز؛ وهو نص صريح خاص، حده 16 MiB لكل ملف إعداد محفوظ، وليس تخزينا مشفرا.

يحتفظ استدعاء الأوامر بحد أقصى 64 إدخالا و64 KiB، ويحذف الأقدم. يمسح /clear سجل المحادثة لا سجل استدعاء الأوامر.

تستخدم اقتراحات السجل الحديث هذه الأسطر الكاملة. يحذف Delete صف السجل المحدد.

تستخدم اقتراحات الأكثر استعمالا بدلا من ذلك حتى 96 اسما قياسيا للأوامر وعدادات محدودة في <config_path>.commands.

للإعدادات المحفوظة، تحدث الأوامر المقبولة وتصفير عدادات التكرار ذلك الملف الخاص تلقائيا. لا تحفظ فيه الوسيطات أو الأهداف أو الرسائل.

تبقي ملفات الإعداد غير المحفوظة العدادات في الذاكرة حتى أول حفظ ناجح. ملفات العدادات المفقودة أو غير القابلة للاستخدام لا تمنع التشغيل.

تستخدم المساعدة وردود الأوامر متعددة الأسطر قارئا منفصلا بمخزن محدود إلى 512 KiB. ولا تصبح جزءا من سجل الدردشة.

يمكن استدعاء الأوامر المقبولة في محرر الأوامر. تستثنى تغييرات المصادقة والانضمامات بمفتاح ورسائل الخدمات الحساسة.

يحرك Up/Down المؤشر في Compose ولا يستعيد الدردشة المرسلة. في Command تُستعاد الأوامر المقبولة فقط.

يحتفظ الفصل والاستئناف بالواجهة نفسها بالمسودات واستدعاء الأوامر. تبديل الواجهات عندما يكون مدعوما يحذف المسودات والاستدعاء ونماذج الإعداد؛ والخروج أو إعادة تشغيل النظام ينهيان أيضا سجل الدردشة ومراسي الاستدراك في الذاكرة.

تحتوي عدادات التكرار المحفوظة أسماء فقط. تبقى سجلات النص الصريح القديمة بعد الخروج، لكنها لا تستورد تلقائيا إلى جلسة جديدة أو إلى المحرر.

يحذف /clear سجل العرض من RAM لا السجل القديم على القرص. إعادة تشغيل السجل من bouncer مسؤولية bouncer.

/help hotkeys
-------------

تخصيص اختصارات المفاتيح اختياري وفارغ افتراضيا. تظل أدوات التصفح والتحرير العادية متاحة.

استخدم /bindings للقائمة و/bindings keys للمفاتيح و/bindings actions للوظائف المحلية.

عيّن باستخدام /bind KEY ACTION؛ كرر للتبديل. احذف باستخدام /unbind KEY أو /unbind all.

تطبق التغييرات فورا على كل الخوادم؛ يحفظها /save input في الإعداد الرئيسي. الملفات الإضافية لا تتجاوز الجدول.

الصيغة [hotkeys] وسطر KEY=action لكل مفتاح، بحد 64. تكرار المفاتيح أو أسمائها البديلة خطأ.

تعمل الإجراءات في الدردشة الرئيسية وموجه الأوامر فقط؛ لا في كلمات السر أو الإعداد أو اللصق أو القراءة أو التأكيد.

في الواجهة البسيطة تحفظ شاشات القراءة المسودة والمؤشر. تغيير الشاشة أو المحرر يرفض مسودة غير فارغة؛ أنهها أو امسحها.

لا إجراءات إرسال أو أوامر عشوائية أو shell أو وحدات نصية. للخلفية والخروج آثارهما المعتادة.

تتوفر F1..F12 وCtrl-A..Z وAlt-a..z/0..9 ومفاتيح التنقل؛ وتبقى الأحرف العادية نصا.

تشترك Ctrl-H/Backspace وCtrl-I/Tab وCtrl-J/Ctrl-M/Enter وCtrl-[/Escape في البايتات؛ لا تربط منفصلة.

إشارات الطرفية واختصارات المضاعف تسبق غيرها. لا يعمل Ctrl-C أو Ctrl-Z إلا إذا وصلا للتطبيق؛ لا يعاد تعيين المفاتيح.

اللصق المؤطر المعترف به لا يشغل الاختصارات. لا يمكن تمييز اللصق غير المؤطر عن الكتابة؛ انظر /help keys.

/help keys
----------

في السجل (Log)، يفتح / شاشة «أمر» (Command)؛ ويشرح ? سجل المحادثة أو المراقبة المحدد. تفتح المفاتيح القابلة للطباعة الأخرى «كتابة رسالة» (Compose) مع الاحتفاظ بالحرف المدخل.

قد تتجاوز الروابط المخصصة هذه المفاتيح في الدردشة الرئيسية أو شاشة «أمر» (Command)؛ لا تعين روابط افتراضيا. راجع /help hotkeys.

في السجل الحي، يصعد Up سطرا أقدم وPage Up صفحة وHome إلى أقدم صفحة محفوظة. تبقي Down وPage Down وEnd العرض حيا؛ ولا تفتح Left أو Right أو Delete أو Backspace شاشة «كتابة رسالة» (Compose).

يفتح Insert أو Enter شاشة «كتابة رسالة» (Compose) فارغة. تحرر الأسهم وHome وEnd وDelete وBackspace النص. يكمل Tab وShift-Tab الألقاب في «كتابة رسالة» (Compose) وأسماء الأوامر في «أمر» (Command).

يبقي وضع التأليف السطري صف إدخال واحدا تحت ذيل السجل الحي؛ ويبقي وضع ملء الشاشة محررا متعدد الأسطر مع مساحة أصغر لذيل السجل.

في «أمر» (Command)، يحدد Down الاقتراحات. يتنقل Up وDown بينها؛ ويعيد Up من أول اقتراح إلى الإدخال.

يدرج Enter الاقتراح دون تنفيذه. اقرأه أو عدله، ثم اضغط Enter مرة أخرى بعد عرضه لتنفيذه.

في «أمر» (Command)، يستدعي Up سجلا مقبولا مطابقا؛ ويعيد Down باتجاه الإدخال الأصلي. في «كتابة رسالة» (Compose)، يحرك Up وDown المؤشر حتى مع استمرار الضغط؛ ويرسل Enter النص.

يحذف Delete صفا محددا من «السجل الحديث» أو يصفر عداد «الأكثر استخداما» المحدد. تبقى أوامر الفهرس متاحة.

يشرح ? الأمر المحدد ويربطه بمساعدة شاشة الأوامر. في كل محررات النصوص، يكون ? نصا عاديا.

تستخدم المراجعة شاشة بديلة مؤقتة؛ لا تدخل مسودتها أو مطالبتها سجل الدردشة. تؤكد ضغطة Enter جديدة؛ ويعيد Escape أو الكتابة المحرر والمسودة والمؤشر. تتصفح Up وDown وPage Up وPage Down وHome وEnd المراجعة.

يمرر Up وDown المساعدة أو الرد؛ ويغير Page Up وPage Down الصفحة؛ وينقل Home وEnd إلى البداية والنهاية.

يعيد Enter من قائمة الأعضاء إلى السجل؛ وفي المساعدة وقارئات الردود الأخرى يمرر سطرا واحدا.

في القارئ، يفتح / شاشة «أمر» (Command) مع الإكمال والسجل المعتادين. يلغي Escape تلك المطالبة ويعود إلى القارئ.

في قارئ الملخص، يحدث r اللقطة؛ ويشرح ? الرد وقارئه.

في المساعدة السياقية، يتبع Enter رابط About المميز الذي يشرح الشاشة. يعيد Escape إلى مساعدة العنصر ثم إلى الشاشة الأصلية نفسها.

في الإعداد، يحدد Tab عنوان السؤال؛ ويشرح ? خياره أو شاشته. يعيد Tab أو Enter إلى تحرير الإجابة.

يستبدل تنفيذ أمر الرد السابق. تعيد التأكيدات القصيرة إلى السجل؛ وتبقي الأخطاء القصيرة الأمر قابلا للتحرير.

يلغي Escape محرر «كتابة رسالة» (Compose) أو «أمر» (Command) ويعود إلى السجل. من المراجعة، يعيد Escape إلى ذلك المحرر دون فقد المسودة. وفي السجل، ينقل Escape العميل إلى الخلفية.

ينتظر Escape المنفرد نحو 500 ms؛ ويسمح تسلسل جار بمهلة 1000 ms بين بايتات المتابعة. يستمر عمل الشبكة.

تعالج تسلسلات المفاتيح المكتملة فورا. إذا تأخرت علامة بدء اللصق بعد أول Escape فيها بما يتجاوز المهلة، فقد ينتقل العميل إلى الخلفية.

بعد بدء التقاط اللصق، تبقى علامة إغلاقه معروفة حتى عند قراءات مجزأة أو متأخرة لأي مدة.

تبقى تعيينات مفاتيح المقاطعة والإنهاء والتعليق في الطرفية كما هي؛ يعطّل «استخدام الإشارات» = no تأثير إشاراتها أثناء تشغيل العميل.

[input] use_signals=false تعطّل القيمة no (الافتراضية) إشارات الطرفية أثناء تحكم البرنامج بها، ويُلغي Ctrl-C/Ctrl-Z المسودة. تفعّل yes تعيينات مفاتيح الإشارات الموجودة دون تغييرها. لا تُحجب إشارات العمليات الخارجية ([input] use_signals=true).

تنهي إشارات الطرفية المفعلة العملية أو تعلقها بعد استعادة حالة الطرفية؛ ويستأنف fg المهمة المعلقة.

لا يفعل Ctrl-D شيئا إلا إذا ربط بوظيفة في الدردشة الرئيسية أو «أمر» (Command). ينهي /quit البرنامج؛ ويفصل /background الطرفية مع استمرار عمل الشبكة.

تخلو الشاشات المعتادة من تلميحات المفاتيح المتكررة؛ ويظل هذا الموضوع مرجع لوحة المفاتيح الكامل.

يبقى اللصق المحاط بعلامات والمعروف نصا حرفيا. تنتظر المفاتيح محررا ظاهرا وإدخالا جديدا وتوقفا وجيزا. لا تسمح شاشة صغيرة جدا أو فاشلة بالموافقة؛ كبر الطرفية وأفلت المفاتيح المضغوطة.

يفتح اللصق في سجل المراقبة «كتابة رسالة» (Compose) بشرطات مائلة حرفية. يبقى اللصق داخل «أمر» (Command) فيه؛ وتصبح CR/LF/Tab مسافات. راجعه ثم اضغط Enter ضغطة جديدة.

لا يمكن تمييز اللصق دون علامات عن الكتابة؛ استخدم دعم اللصق المحاط بعلامات.

/help limits
------------

حدود IRC بالبايت لا بعدد الرموز المرئية. قد يشغل حرف UTF-8 أكثر من بايت.

يحسب العميل سعة الرسالة مع الوجهة والأمر وكلفة الترحيل؛ ولا يقسم حرف UTF-8.

عند حد رسالة واحدة، يتوقف إدخال النص حتى يؤكد Enter متابعة التحرير؛ ولا يرسل Enter شيئا.

الرسائل المقسمة تحتاج موافقة منفصلة حتى في الوضع المباشر. ترسل المحادثة سطرا كل 1.2 ثانية.

يسمح الإرسال بحد أقصى 64 رسالة و 16384 بايت من النص. اختصر النص أو أرسله في دفعات مقصودة.

الحد الأقصى 8 خانات خوادم و 32 عرضا لكل خادم، بما فيها العروض المحجوزة.

/help logging
-------------

التسجيل الدائم اختياري ومعطل افتراضيا. يفعله /set persistent_logging on ويحفظه /save output.

يلحق كل ملف خادم بـ CONFIG_PATH.log. يجب ملكية الدليل الأب وصلاحية 0700؛ والملف العادي برابط واحد وصلاحية 0600. ترفض الروابط الرمزية وتجاوز الدليل.

السجلات plaintext وليست نسخا مشفرة. حد الملف 16 MiB؛ خطأ الكتابة يوقف التسجيل لا الدردشة.

انقل السجل الممتلئ خارج مساره النشط ثم أوقف التسجيل وأعده. قد تبطل التدويرة مرساة /catchup؛ أرسل رسالة مؤهلة جديدة قبل الاعتماد عليها.

تستثنى كلمات السر والمسودات، حتى بأسماء قديمة. قد تسجل الدردشة والخدمات المجهولة والأسرار المكتوبة. احتفاظ الخادم وbouncer منفصل.

لا يستخدم /catchup سجلا سليما إلا بمرساة محلية مطابقة سجلتها هذه العملية. لا يطلب أرشيف bouncer ولا يستورد سجلات قديمة بعد إعادة التشغيل.

يمسح /clear ذاكرة RAM فقط. تبقى السجلات بعد الخروج أو --close-session أو الحفظ. إيقاف التسجيل يمنع السجلات الجديدة ولا يحذف القديمة.

قد تؤخر عمليات القرص على تخزين بطيء العملية. راجع /help catchup و/help history وSECURITY.md.

/help messages
--------------

استخدم /join #channel لدخول قناة واختيارها، أو /query NICK لفتح محادثة خاصة.

اختر قناة محفوظة عبر /channel. يرسل /msg TARGET TEXT إلى وجهة محددة و /me TEXT فعلا.

يفتح /query محادثة بلا إرسال؛ و /pm اسم بديل. يفصل /ql المحادثات الخاصة عن القنوات.

الإرسال المباشر افتراضي؛ يضيف /set send_mode review مراجعة. يغير /set composer_mode line|fullscreen العرض.

عند بلوغ حد الرسالة، أكد متابعة التحرير؛ وتقسيم الرسائل يحتاج موافقة منفصلة.

يجب إكمال الانضمام والمصادقة قبل وضع الرسائل في الطابور. يلغي /cancel الطابور لا الرسائل المرسلة.

/help reconnect
---------------

يفعل --reconnect إعادة المحاولة لهذه العملية؛ لا يحفظ إعدادا ولا يبدأ اتصالا.

دون هذا الخيار، يحتاج فشل الاتصال إلى /connect. يتحكم /autoconnect ببدء التشغيل فقط.

تتكرر محاولات أخطاء DNS المؤقتة ورفض/فقد الاتصال والمهلة بعد 5 و10 و20 و40 و80 و160 ثم 300 ثانية.

الاتصال المسجل لمدة 60 ثانية على الأقل يصفر التأخير. يستمر الاستطلاع بلا نوم حاجب.

تبقى أخطاء الشهادات والمصادقة والبروتوكول والإعدادات منفصلة حتى التصحيح.

تؤجل رسالة ERROR قبل التسجيل؛ وبعده قد تؤدي إلى إعادة الاتصال.

يلغي /disconnect الصريح محاولة معلقة. ويبدأ /connect لاحقا محاولة جديدة.

تستخدم المحاولات الإعدادات الحالية؛ تتطلب التعديلات المعلقة /connect صريحا.

تسقط الرسائل المعلقة عند الانقطاع ولا تعاد تلقائيا.

تعاد المصادقة وأوامر البدء المفعلة. يعيد الملف المباشر autojoin بعد التسجيل؛ يستعيد bouncer قنواته.

وضع الاختبار دون شبكة لا يعيد الاتصال بالشبكة إطلاقا.

/help security
--------------

تُنقّى النصوص البعيدة قبل عرضها في الطرفية. يُفسر الإدخال كأوامر IRC محلية، لا أوامر صدفة النظام.

لا يتوفر /raw ولا خروج إلى الصدفة ولا قبول ملفات تلقائي. اللصق المحدد المعروف لا ينفذ أمرا.

يتحقق TLS من هوية الخادم. تتطلب SASL وPASS وأوامر التوثيق الخاصة TLS موثقا. حدث مكتبة TLS في النظام؛ راجع SECURITY.md.

يجب أن تكون حزمة CA المخصصة ملف PEM عاديا غير فارغ بحجم لا يتجاوز 16 MiB، ولا تطلب كلمة مرور.

تخفى كلمات المرور في المساعدة والإعدادات. تستبعد أوامر الأسرار المعروفة من الاستدعاء؛ وقد يحتفظ النظام بالأسرار المكتوبة كنص عادي.

لا تُكتب محادثات إلى القرص افتراضيا. تتطلب تغييرات الإعدادات حفظا صريحا.

العمليات الأخرى بالحساب نفسه وخادم IRC أو bouncer والطرفية أو النظام المخترق خارج هذه الحماية. TLS ليس تشفير دردشة من طرف إلى طرف.

السجلات الاختيارية وأسرار الإعدادات نص واضح. ترشح الأوامر الحساسة المعروفة، ولا يمكن كشف كل سر في الدردشة بدقة.

راجع /help tls و/help authentication و/help logging وSECURITY.md للقيود ونتائج المراجعات السابقة.

/help sessions
--------------

المهمة عملية عميل واحدة تضم خوادمها والنقل والمسودات والسجل. رقم الخادم داخل البرنامج ليس معرف مهمة shell.

شغل --sessions من الصدفة. افحص حالة المهمة واستخدم رقم المهمة لا رقم العملية.

إن بقيت جلسة SSH القديمة متصلة: --detach-session NUMBER ثم --resume NUMBER. يبقى IRC جاريا.

يختار --resume بلا رقم مهمة منفصلة واحدة موثقة فقط. تتطلب المهام المتعددة رقما، والمهمة المتصلة مشغولة حتى فصلها. قد يعاد استخدام الأرقام.

لا تستخدم --close-session NUMBER إلا لإنهاء المهمة كلها. يغلق اتصالات IRC والنقل ويفقد المسودات وتاريخ RAM؛ تبقى الإعدادات والسجلات المحفوظة.

نجاح الإغلاق بعد التحقق من التنظيف. عند انتهاء المهلة افحص --sessions مجددا؛ قد ينتهي لاحقا. لا يحذف الفشل منفذا حيا ولا يرسل إشارة إلى PID مخمن.

تنجو المهمة المدارة فقط من فقد الطرفية. العملية العادية في المقدمة لا تستأنف بعد انقطاع SSH. ابدأ مع --background أو نفذ /background أولا.

تخص المهمة حساب Unix والمضيف نفسيهما، وتقبل طرفية واحدة في كل مرة. البرامج الأخرى بذلك الحساب ضمن حد الثقة نفسه.

تثبيت برنامج جديد لا يبدل كود العملية الجارية. احفظ الإعدادات وأوقف القديمة وافحص --version ثم ابدأ عملية جديدة.

قد لا تدعم العملية القديمة التحكم الجديد أو تبديل الواجهة. احتفظ بالبرنامج المتوافق حتى إيقافها إذا لزم الاتصال بها.

لا يغير العميل مهلة خمول SSH. راجع /help background و/help deployment وdoc/SESSION-CONTROLS.txt.

/help startup
-------------

شغل البرنامج وأغلق الترحيب، ثم اكتب /connect irc.example.org وبعده /join #channel.

لا تحتاج لإنشاء ملف خادم أو اسم بديل أو رقم أولا. /server HOST اختصار للاتصال المباشر.

إن لم تحدد لقبا، يستخدم اسم دخول النظام الصالح، وإلا user. لا تظهر مطالبة باللقب.

احفظ الإعدادات والخيار الافتراضي عبر /saveconf. عند التشغيل التالي يعيد /connect استخدامهما.

الحفظ لا يفعل الاتصال التلقائي؛ فهو خيار مستقل. /quickstart و /panel دليلان اختياريان.

تعمل خيارات الصدفة أيضا: --server HOST و --channel '#CHANNEL' و --nick NICK. ضع #CHANNEL بين علامتي اقتباس.

عند التشغيل العادي، تتجاوز --nick و --port و --channel و --tls و --plain و --ca-file القيم المحفوظة.

يحدد --server الصريح أول اتصال. يستخدم --init-config و --check-config ملف الإعدادات الرئيسي.

تغيير --server لمضيف آخر يمحو بيانات الدخول القديمة و CA الخاص وهوية الوسيط والقنوات وأوامر البدء.

إن تعذر الخيار المحفوظ، حدد --server أو أصلحه قبل تجاوز إعدادات الاتصال.

تخص autoconnect و autojoin و autoauth كل ملف خادم محفوظ. راجع /help autoconnect.

يمنع --no-connect الاتصال عند البدء؛ ويحاكي --test-mode العمل دون شبكة أو كتابة إعدادات.

يسرد --sessions المهام المتصلة والمنفصلة عن الطرفية. يعيد --resume [NUMBER] وصلها؛ راجع /help background.

ينهي --close-session NUMBER المهمة كاملة وكل اتصالات IRC بعد تأكيد الإنهاء. NUMBER معرف مهمة وليس PID.

عند فقد الطرفية، استخدم --sessions ثم --detach-session NUMBER و --resume NUMBER. يحتفظ العامل بكوده حتى إعادة تشغيله؛ راجع /help sessions.

يعمل -h/--help و -v/--version دون طرفية.

/help tls
---------

TLS الموثق افتراضي. يجب التحقق من اسم الخادم وشهاداته؛ لا تجاوز ولا رجوع إلى plaintext.

رقم المنفذ لا يعطل TLS. يختار --plain أو /connect -plain اتصال IRC بلا تشفير ولا بيانات اعتماد.

استخدم اسم مضيف TLS ومنفذه الصحيحين. قد يكون الخطأ عنوانا خاطئا أو شهادة منتهية/غير موثوقة أو ثقة محلية؛ افحص الخطأ أولا.

يستخدم TLS مخزن الثقة الافتراضي. يختار --ca-file FILE أو ca_file= حزمة PEM CA خاصة، لا يثبت شهادة الخادم النهائية.

حزمة CA الخاصة ملف عادي غير فارغ حتى 16 MiB. يسمح برابط رمزي إلى CA؛ مسارات الأسرار والإعداد أشد قيودا.

يفتح ملف CA مرة مع فحص حجمه أثناء القراءة. ترفض FIFO والأجهزة وغيرها؛ لا يطلب PEM المحمي كلمة سر تفاعليا.

حد حجم الملف لا يحد تأخير I/O للملفات العادية أو الشبكية. استخدم حزمة CA موثوقة على تخزين ملائم.

لا يجري --check-config مصافحة TLS ولا يثبت عمل CA أو مصدر بيانات الاعتماد. لا يتصل --test-mode بالخادم.

يحمي TLS هذا الاتصال فقط. تضبط حماية المنبع وتاريخ plaintext لدى الوسيط بشكل منفصل.

/help troubleshooting
---------------------

مشغول بعد انقطاع SSH؟ تحقق عبر --sessions ثم --detach-session NUMBER وبعده --resume NUMBER. تجنب --close-session. See /help sessions.

لا يستعيد Up النص: يحرر Compose الرسائل؛ ويستعيد Command الأوامر المقبولة. افتح Command عبر / من السجل. الدردشة والأوامر الحساسة ليست في سجل الاستعادة.

إذا بدا النص الملتف مقطوعا، يحجز المحرر أسطرا ويظهر الأحدث. اخرج من المحرر أو أعد اختيار القناة؛ ظهور النص لا يثبت التسليم.

ظهور النص كاملا بعد تغيير القناة يعني اختلاف العرض. عند الخلل سجل الواجهة والوضع والحجم وlocale وخطوات آمنة بلا كلمات مرور أو محادثات خاصة.

لا قنوات؟ افحص الخادم والمصادقة. للاتصال المباشر /autojoin list؛ وللوسيط /join أو /part.

فشل الدخول؟ افحص الحساب ومصدر السر والأذونات وTLS ووكيل GPG. لا يقرأ /autoauth status الأسرار.

تعذر catch-up: ربما زالت العلامة أو بدأ التسجيل لاحقا أو توقف أو تغير الملف. راجع /help catchup و/help logging؛ السجلات لا تعيد عملية منتهية.

تغيير غير مطبق؟ يلزم /connect بعد الانقطاع. الحفظ لا يفعل autoconnect؛ إعدادات البدء تحتاج إعادة تشغيل.

إذا فشل بدء المساعد، صحح سياسة SIGCHLD أو جمع العمليات الفرعية تلقائيا لدى المشغل لكي يستطيع العميل انتظارها.

استخدم --check-config و doc/TROUBLESHOOTING.txt. يختبر --test-mode الواجهة لا DNS أو TLS أو الوسيط الفعلي.

/help /autoauth
---------------

فحص مصادقة SASL أو إعدادها
الاستخدام: /autoauth [status|off|sasl USER file PATH|sasl USER gpg PATH]

يغير مصادقة الخادم المحدد للاتصال التالي. يلزم TLS موثق.

دون وسيطات أو مع status يعرض حالة الاتصال والمصادقة ومسارات ملفات الاعتماد، ولا يعرض كلمات المرور.

يميز بين الإعدادات الحالية والمعلقة. تظهر المسارات الطويلة كاملة في أسطر متابعة معنونة.

PATH هو بقية النص حرفيا بما فيه الفراغات؛ لا توسيع لأوامر الصدفة ولا تفسير لعلامات الاقتباس.

لا يفتح هذا الأمر ملفات. يجب فتح مفاتيح GPG خارج البرنامج.

يمكن ضبط كلمات المرور النصية صراحة في ملف إعدادات خاص فقط، وليس كوسيط للأمر.

استخدم /panel لملف bouncer؛ يرفض /autoauth لأن هوية الدخول ومصدر الاعتماد يداران معا.

استخدم /save للحفظ. افصل الاتصال أولا ثم استخدم /connect لتطبيق التغييرات؛ لا يعاد توجيه الاتصال النشط.

/help /autocommands
-------------------

إعداد أوامر مؤجلة للاتصال التالي
الاستخدام: /autocommands [list|add COMMAND|remove NUMBER|clear|on|off|delay SECONDS|interval SECONDS]

تخص الأوامر الخادم المحدد. تنفذ مرة واحدة بعد التسجيل ونجاح SASL المطلوب.

التأخير الافتراضي 15 ثانية، وبين اكتمال أمر وآخر 2 ثانية على الأقل.

اضبط الوقت عبر delay 0..300 وinterval 2..60. توقف الاتصال لا يطلق دفعة تعويضية.

الأوامر المسموحة: /msg و/join و/nick و/away و/back و/whois، مع أسمائها البديلة الموثقة.

الحد 16 أمرا، طول كل منها 511 بايت UTF-8. يجب أن يسع الأمر رسالة IRC واحدة ولا يقسم تلقائيا.

لا صدفة أو أوامر IRC خام أو توسعة للمحادثة الحالية. الانضمام التلقائي لا يبدل العرض.

تسري التغييرات عند الاتصال التالي. يوقف /cancel أوامر البدء التي لم ترسل بعد.

تخفي القوائم نص الرسائل ومفاتيح القنوات؛ ولا تحفظ الأوامر الآلية في السجل أو الصدى المحلي.

احفظ عبر /save. يجب أن يكون الملف خاصا (0600 أو 0400)؛ والقائمة المفعلة غير الفارغة تتطلب TLS موثقا.

وضع الاختبار لا يشغل الأوامر الآلية. يحفظ نصها كما هو في الإعدادات دون تشفير GPG.

أمثلة:
/autocommands add /msg ChanServ op #chat mynick
/autocommands delay 15
/autocommands interval 2
/autocommands list
/save

/help /background
-----------------

أبق الاتصالات عاملة وحرر الطرفية
الاستخدام: /background

يعيد الطرفية ثم يفصل الجلسة العاملة. تعرض الصدفة أمر الاستئناف المرقم.

يعرض --sessions في الصدفة المهام الخاصة المتصلة والمنفصلة؛ يستأنف --resume المهمة المنفصلة الوحيدة المتاحة.

عند تعدد المهام استخدم --resume NUMBER. يشير NUMBER إلى معرف المهمة لا PID؛ يبقى حتى انتهائها وقد يعاد استخدامه.

يفصل --detach-session NUMBER الطرفية مع إبقاء العامل واتصالات IRC والمسودات والسجل لاستئنافها عبر --resume NUMBER.

ينهي --close-session NUMBER المهمة واتصالات IRC والنقل والمسودات غير المحفوظة وسجل RAM. لا يعلن النجاح إلا بعد التحقق من الإغلاق.

إذا كان الاستئناف مشغولا بعد فقدان SSH، اعرض المهام وافصل المعنية ثم استأنفها. راجع /help sessions.

قد يفشل عامل لا يستجيب أو إصدار قديم يفتقر للتحكم المطلوب. تثبيت برنامج جديد لا يحدث العامل الجاري؛ أعد تشغيله بعد الترقية.

يعيد الاستئناف عرض سجل RAM ولو لم تصل رسائل. يمنع /set single_session on مهمة خلفية ثانية ليبقى --resume واضحا.

للبدء دون طرفية استخدم --background في الصدفة؛ راجع --help للخيارات.

عند تفعيل background_away وسماح الملف، يرسل /background أو فقدان الطرفية حالة AWAY بعد الفصل. الاستئناف يمحو هذه الحالة الآلية فقط؛ يبقى /away اليدوي.

أضف --reconnect لإعادة محاولة الاتصال بعد أخطاء مؤقتة. راجع /help deployment و/help reconnect.

لا تحتاج إلى مضاعف طرفية. قد يتطلب حل الاسم أو مساعد بيانات الاعتماد المعلق إعادة المحاولة.

تعليق عملية عادية في المقدمة يوقف شبكتها. يمكن تعليق متحكم طرفية جلسة مستأنفة بينما يواصل العامل اتصالاته.

أمثلة:
/background

/help /connect
--------------

اتصل بالخادم أو استخدم الاتصال المحفوظ
الاستخدام: /connect [-tls|-plain] [-nick NICK] HOST [PORT] | /connect

ابدأ بـ /connect irc.example.org. لا حاجة لإنشاء ملف أو اسم بديل أو رقم خادم أولا.

يستخدم الخادم الجديد TLS موثقا على المنفذ 6697 واسم دخول النظام، أو user إذا لم يصلح.

يحتفظ الخادم المطابق الحالي بمنفذه ونوع اتصاله ولقبه وإعدادات المصادقة.

استخدم -nick NICK لاسم محدد أو /nick NICK قبل الاتصال. لا تمرر كلمات المرور كوسائط موضعية.

استخدم -plain لاتصال IRC غير مشفر (المنفذ الافتراضي 6667). يختار -tls و-ssl اتصال TLS موثقا.

يختار +PORT أيضا TLS. رقم المنفذ العادي لا يعطل TLS. تقبل الخيارات --tls و--plain و--nick.

يحدد الاتصال ويفتح عرض الخادم/MOTD. لا ينشئ نسخة ثانية من اتصال مطابق نشط.

يحصل عنوان مختلف على إعدادات مصادقة جديدة؛ لا تنسخ بيانات اعتماد وقنوات خادم آخر.

يستخدم /connect وحده الخادم المحدد وإعداداته المطبقة. يحفظ /saveconf الخادم الافتراضي للتشغيل القادم.

لملفات bouncer على المضيف نفسه، اختر الملف عبر /server NUMBER ثم استخدم /connect وحده.

تقبل أرقام الخوادم الموجودة للتوافق. وضع الاختبار بلا شبكة؛ يجب حفظ التعديلات صراحة.

أمثلة:
/connect irc.example.org
/join #chat
/saveconf
/connect
/connect -nick mynick irc.example.org +6697
/connect -plain localhost 6667

/help /dcc
----------

عرض نقل الملفات مباشرة، ومراجعة عمليات النقل وإدارتها
الاستخدام: /dcc [list|NICK PATH|send [-address IPV4] [-port PORT] NICK PATH|accept NUMBER [DIRECTORY]|reject NUMBER|cancel NUMBER]

دون معاملات يعرض النقل. يعرض /dcc NICK PATH ملفا على الخادم المحدد.

PATH هو بقية النص حرفيا بما فيه الفراغات؛ والمسار نسبي لمجلد بدء العملية.

لا يغير العميل هذا المجلد حتى عند تصفح الملفات أو التشغيل في الخلفية.

يعلن الإرسال المختصر IPv4 المحلي لاتصال IRC. خلف NAT استخدم -address لعنوان IPv4 يمكن الوصول إليه و-port لمنفذ محول.

لا يطلب كشف العنوان من خدمة خارجية. اتصال IRC المعتمد على IPv6 فقط يتطلب IPv4 محددا.

DCC اتصال مباشر غير مشفر. يرى الطرف الآخر IP المعلن؛ وقبول العرض يكشف له IP أيضا.

لا يفتح العرض الوارد حتى /dcc accept NUMBER. يستخدم DIRECTORY مجلد البدء افتراضيا ويجب أن يكون ملكك وخاصا.

لا يستبدل ملفا موجودا؛ وترفض الروابط الرمزية والملفات الخاصة. وضع الاختبار لا يفتح ملفات أو مقابس.

ارفض العرض عبر /dcc reject NUMBER أو ألغ النقل الجاري عبر /dcc cancel NUMBER.

أرقام النقل مشتركة بين خوادم العملية. إغلاق الخادم الأصلي يلغي نقله؛ وقطع IRC لا يلغي نقلا مقبولا.

أمثلة:
/dcc alice file.txt
/dcc list
/dcc accept 1 ./downloads
/dcc send -address 203.0.113.20 -port 5000 alice file.txt
/dcc cancel 2

/help /list
-----------

طلب دليل قنوات الشبكة وتصفيته
الاستخدام: /list [MASK] [--min-users N] [--max-users N] [--name TEXT] [--topic TEXT] [--sort channel|users|topic] [--asc|--desc] [--limit N] | /list show [--sort channel|users|topic] [--asc|--desc] [--limit N] | /list clear

يطلب قائمة القنوات من خادم IRC المحدد؛ يلزم اكتمال التسجيل. لا يُرسل إلى الخادم إلا المرشح MASK.

تُطبق حدود عدد المستخدمين الأدنى والأقصى ومرشحات الاسم والموضوع محلياً حتى لو لم تدعم الشبكة مرشحات LIST المتقدمة.

قيم --sort هي channel أو users أو topic؛ الافتراضي users تنازلياً. تعني --limit 0 عدم حد للعرض ضمن الذاكرة المؤقتة المحدودة.

يعرض /list show الذاكرة المؤقتة؛ ترتب --sort و--asc/--desc و--limit النتائج محلياً دون طلب IRC جديد. يمسح /list clear الذاكرة المؤقتة.

يفتح العميل بملء الشاشة متصفح قنوات قابلاً للفرز؛ يستخدم الوضع المبسط الخيارات نفسها و/list show.

/help /panel
------------

افتح لوحة الإعداد التفاعلية
الاستخدام: /panel

اختر 0 (الافتراضي) لتفضيلات التطبيق، أو إحدى لوحات ملفات الإعداد 1..8؛ تعدل اللوحة 1 الملف الرئيسي. هذه أرقام لوحات وليست معرفات مهام shell.

تضم تفضيلات التطبيق الاحتفاظ بالسجل ووضع الإرسال وتنسيق الخرج وإشعارات الطابور واقتراحات الأوامر لجميع الخوادم.

تعمل دون خادم مهيأ. الخياران النهائيان هما 1 حفظ (الافتراضي) و2 تطبيق دون حفظ؛ لا يبدأ أي منهما اتصالا.

تضم لوحة الخادم إعدادات اتصاله وبدء تشغيله ومصادقته وإشاراته وتجاهله فقط.

اختيار أي لوحة لا يغير محادثة الدردشة الحالية.

يبقي Enter القيمة المعروضة؛ ويمسح '-' حقلا اختياريا. يعيد Escape سؤالا واحدا إلى الوراء؛ كرره للخروج دون تطبيق التعديلات.

يحدد Tab عنوان السؤال. اضغط ? هناك لشرح الخيار وشاشته؛ ويعيدك Tab أو Enter إلى الإجابة.

يبقى ? نصا حرفيا في كل إجابة قابلة للتحرير، بما في ذلك أول حرف وأقنعة المطابقة ذات المحارف البديلة.

أدخل كلمات المراقبة وأقنعة التجاهل واحدا تلو الآخر؛ إدخال جديد فارغ ينهي القائمة.

يخفى إدخال بيانات الاعتماد ولا تسجل إجابات الإعداد في سجل الأوامر أبدا. لا يقرأ البرنامج ملفات بيانات الاعتماد الموجودة أثناء التحرير.

لمصدر GPG، اختر إنشاء جديد أو استخدام موجود. يعرض الإنشاء مسارا افتراضيا خاصا؛ يقبله Enter ويجهز دليله بالأذونات 0700.

يجب أن تكون الوجهة الأخرى داخل دليل موجود تملكه وأذوناته 0700. يفحص المسار قبل سؤالي المفتاح وكلمة المرور.

ثم يطلب الإنشاء البصمة الكاملة لمفتاح عام محلي وكلمة المرور مرتين. لا يستبدل ملفات موجودة أو روابط رمزية أبدا.

تخزن مسارات بيانات الاعتماد كمسارات مطلقة. يعرض /autoauth status مواقعها المهيأة كاملة دون قراءة محتوياتها.

يبدأ التشفير بعد اختيار «إنهاء» فقط، ويبقى IRC مستجيبا، ولا يستخدم ملفا مؤقتا بنص صريح أبدا. يلغي Escape العمل المعلق.

إذا فشل حفظ الإعداد، يبقى النص المشفر المكتمل متاحا لإعادة محاولة مقصودة؛ وتحفظ الملفات التي يشير إليها إعداد محفوظ.

لا يشغل وضع الاختبار GPG ولا ينشئ ملفات بيانات اعتماد. افتح قفل المفتاح الخاص المطابق خارج البرنامج قبل المصادقة.

خيارات لوحة الخادم النهائية: 1 حفظ واتصال، 2 حفظ فقط (الافتراضي)، 3 اتصال مرة، أو 4 تطبيق فقط.

مجرد فتح اللوحة أو الإجابة عن أسئلتها السابقة لا يطبق شيئا ولا يحفظه ولا يبدأ اتصالا.

اتصال مرة يطبق دون حفظ؛ تطبيق فقط لا يحفظ ولا يتصل. الاتصال الحي لا يغير هدفه ولا يعاود الاتصال خفية.

فشل الاتصال لا يلغي التغييرات التي طبقت أو حفظت بالفعل بالإجراء النهائي.

استخدم /quickstart لإعداد أقصر للخادم ونوع الاتصال والمنفذ واللقب.

أمثلة:
/panel

---------------

احفظ الإعداد وتذكر الاتصال المحدد
الاستخدام: /saveconf

يحفظ تفضيلات البرنامج وإعدادات جميع الخوادم السليمة، ويتذكر الخادم المحدد كافتراضي.

عند التشغيل التالي يستخدم /connect الإعداد الافتراضي المحفوظ؛ لا يلزم رقم خادم أو إعداد منفصل.

يشمل الاسم والقنوات والمصادقة وخيارات البدء؛ تتقدم تعديلات الاتصال المعلقة الصريحة.

هذا لا يفعل الاتصال التلقائي عند البدء. استخدم /autoconnect on أولا إن أردته.

يستبدل كل ملف بشكل خاص وذري. تبقى عمليات الحفظ الناجحة ولو فشل ملف آخر.

يتذكر الافتراضي فقط إذا نجح حفظه؛ تبلغ الأخطاء ولا تستبدل الملفات غير المقروءة.

وضع الاختبار لا يكتب إعدادات. يتيح /save حفظا أدق للملفات والتفضيلات.

أمثلة:
/connect irc.example.org
/join #chat
/saveconf
/quit

/help /server
-------------

الاتصال بخادم أو اختيار خادم موجود
الاستخدام: /server [-tls|-plain] [-nick NICK] HOST [PORT] | /server [NUMBER|add HOST [PORT] [NICK]|connect NUMBER|disconnect NUMBER|close NUMBER]

مع اسم مضيف يعمل مثل /connect المباشر؛ لا يلزم إنشاء ملف مسبقا.

بلا وسيط يختار رسائل/MOTD الخادم الحالي. NUMBER يختار خانة خادم دون اتصال.

ينشئ add ملفا ببيانات دخول جديدة وTLS موثوق وautoconnect مغلق؛ لا يختار ولا يتصل ولا يحفظ.

PORT الافتراضي هو 6697. تغيير المنفذ لا يعطل TLS؛ يجب اختيار الاتصال غير المشفر صراحة.

لا يغير connect/disconnect الاختيار. يحذف close جلسة أو قيدا ثانويا، لا ملف الإعداد.

أرقام الخوادم المبسطة 1..8 والرئيسي 1. يبقى الرئيسي؛ افصله بدلا من إغلاقه.

تبقى الأرقام ثابتة طوال الجلسة. Panel 0 مخصصة لتفضيلات التطبيق.

أمثلة:
/server irc.example.org
/join #chat
/saveconf
/servers
/server 1

اعرض جميع جلسات الخوادم المضبوطة
الاستخدام: /servers

يعرض خانات الخوادم 1..8 (الأساسي 1) في الوضع المبسط، والخادم المحدد وحالته وخيار autoconnect لكل خادم.

/help /set
----------

اختيار تفضيلات الإدخال والإخراج والحضور للتطبيق كله
الاستخدام: /set send_mode direct|review | /set composer_mode line|fullscreen | /set output_format compact|full | /set queue_notices on|off | /set program_messages on|off | /set persistent_logging on|off | /set single_session on|off | /set default_interface idle|ncurses | /set command_suggestions alphabetical|common|history|frequent|contextual | /set part_message [TEXT] | /set quit_message [TEXT] | /set background_away on|off | /set background_away_message TEXT | /set autoaway_minutes 0..1440 | /set autoaway_message TEXT

direct هو الافتراضي: يرسل Enter النص، وتلزم موافقة إذا احتاج الأمر رسائل IRC متعددة.

يضيف review خطوة مراجعة مقصودة قبل وضع الرسائل العادية في الطابور.

output_format compact هو الافتراضي: يعرض الحوار المحدد [HH:MM:SS] <nick> النص.

يضيف output_format full الخادم والتاريخ والهدف لكل سطر. يحتفظ compact بمصدر الإشارات والتشخيصات من الخوادم الأخرى.

يخفي queue_notices off إشعارات الطابور العادية. في الوضع المبسط لا تتكرر رسالة التأكيد بعد المراجعة. تبقى الأخطاء وتأكيد الرسائل المتعددة ظاهرين.

يخفي program_messages off إشعارات محلية ثانوية مثل إلغاء المسودة أو مسح الإدخال أو الاحتفاظ به. تبقى الأخطاء وتأكيدات الأمان ظاهرة.

persistent_logging on: سجل .log خاص (0600) بمجلد 0700. معطل افتراضياً. حد 16 MiB: أرشف ثم بدّل off/on. الملف غير الآمن/المشغول يوقف السجل لا الحوار.

يسمح single_session on بمهمة خلفية واحدة لهذا العميل، فيصبح --resume بلا رقم واضحاً. يمكن استخدام خوادم IRC متعددة في الجلسة.

يحدد default_interface الواجهة عند التشغيل الجديد إن كان مدعوماً، ولا يبدل الحالية. يحفظ /save input الاختيار.

يختار command_suggestions الترتيب الأبجدي أو الشائع أو الأخير أو الأكثر استخداماً أو المناسب لشاشة المنشأ.

يضع composer_mode line سطر إدخال تحت الحوار المباشر؛ يوفر fullscreen محرراً متعدد الأسطر وجزءاً للحوار. الافتراضي: line.

يوفر part_message وquit_message سببي خروج IRC الافتراضيين؛ يعلوهما نص /part أو /quit الصريح. القيمة الفارغة تلغي النص الافتراضي.

يرسل background_away الرسالة background_away_message بعد /background الناجح أو فقد الطرفية. يضبط autoaway_minutes الغياب للخمول؛ 0 يعطله.

يُمسح تلقائياً فقط وضع away الذي أنشأه العميل بعد العودة أو الإدخال الحقيقي. لا يُغير أو يُمسح /away اليدوي.

«شائع الاستخدام» هو الافتراضي. يقدم «حسب السياق» أوامر القناة والمحادثة والخادم والعميل دون إخفاء المطابقات الأخرى.

يستخدم «شائع الاستخدام» ترتيباً منتقى مفيداً. يتذكر «حسب السياق» الشاشة الأصلية، ومنها قارئ الملخص العام.

هذه تفضيلات للعميل في كل الخوادم. احفظها عبر /save input أو /save output.

يعدل /panel ثم 0 هذه التفضيلات وحد سجل المحادثات العام.

أمثلة:
/set send_mode review
/set composer_mode line
/set command_suggestions contextual
/save input
/set output_format full
/set queue_notices off
/set program_messages off
/set persistent_logging on
/set single_session on
/save output

/help /soju
-----------

التحكم في وسيط soju المحدد
الاستخدام: /soju [COMMAND]

يلزم ملف soju متصل معد عبر /panel. دون وسيط يطلب المساعدة من BouncerServ.

ترسل COMMAND رسالة خاصة واحدة بتباعد زمني، بلا صدى محلي أو سجل للأوامر.

اتصال IRC المباشر لا يدعم هذا الاختصار. تظهر الردود في عرض الخادم.

راجع مساعدة الوسيط لأوامر الحساب والشبكة.

أمثلة:
/soju
/soju network status

/help /summary
--------------

تلخيص جميع جلسات الخوادم الحالية ونشاطها
الاستخدام: /summary

يعرض كل الخوادم وchannel 0 والقنوات والمحادثات وغير المقروء والإشارات والطوابير وأوامر البدء ونقل الملفات.

هذه خلاصة محلية تعمل دون اتصال. اضغط r في القارئ أو أعد الأمر لتحديثها.

فتحها لا يغير المحادثة ولا يحدد رسائل كمقروءة. نُسخ الإشارات لا تدخل في مجموع النشاط.

قد تكون الإشارات غير مقروءة أيضا؛ لا تجمع الأعداد. تُميز القنوات المنضم إليها عن المتروكة.

للتقرير قارئ قابل للتمرير ويحفظ المسودات. الشرطة المائلة تفتح الأوامر؛ الإلغاء يعود للخلاصة.

إذا فشل التحديث تبقى الخلاصة السابقة. الفتح والتحديث لا يرسلان طلبا للشبكة.

لا تعرض بيانات الدخول أو محتوى الرسائل المنتظرة أو الأوامر الآلية مطلقا.

أمثلة:
/summary

/help /topic
------------

طلب موضوع القناة الحالية أو تغييره
الاستخدام: /topic [TEXT]

يتطلب التسجيل والانضمام للقناة. دون نص يطلب الموضوع؛ وإلا يرسل TEXT حرفيا.

الخادم يقرر إن كانت صلاحياتك في القناة تسمح بالتعديل.

أمثلة:
/topic
/topic Welcome to our channel

/help /transfers
----------------

إدارة عمليات نقل الملفات (اسم بديل لـ /dcc)
الاستخدام: /transfers [ARGUMENTS]

الأوامر والحماية مثل /dcc. انظر /help dcc للإرسال والاستقبال والإلغاء.

أمثلة:
/transfers
/transfers alice file.txt

/help /unbind
-------------

إزالة ربط مخصص واحد للمفاتيح أو جميع روابط المفاتيح المخصصة
الاستخدام: /unbind KEY|all

حذف الربط يعيد السلوك المعتاد للمفتاح. يمسح all قائمة الاختصارات المخصصة فقط.

يسري التغيير فورا على كل الخوادم. استخدم /save input لبقائه بعد إعادة التشغيل.

أمثلة:
/unbind F7
/unbind all
/save input

/help /unignore
---------------

إزالة قناع تجاهل محلي واحد
الاستخدام: /unignore MASK

يكافئ /ignore remove MASK. احفظ الملف الشخصي المحدد للإبقاء على التغيير.

أمثلة:
/unignore noisy!*@*

/help /unread
-------------

سرد المحادثات غير المقروءة عبر الخوادم
الاستخدام: /unread

تضم السطور رقم الخادم واسم المحادثة والرسائل غير المقروءة وعدد الإشارات.

استخدم /server NUMBER ثم /channel أو /pm لاختيار محادثة.

أمثلة:
/unread
/server 1
/pm alice

/help /users
------------

طباعة المستخدمين المعروفين في القناة الحالية أو المسماة
الاستخدام: /users [#CHANNEL]

هذه قائمة نصية للمستخدمين، لا تبديل للظهور. تُعرض بادئات أوضاعهم إن عُرفت.

تفتح القائمة قارئا منفصلا حتى إن كانت فارغة. Enter أو Escape أو q يعيدك إلى المحادثة.

تمرر Up/Down وPage Up/Down القائمة. في Help يتابع Enter التمرير.

تُوسم إجابات NAMES الناقصة أو المحدودة بالسعة. لا تُرسل طلبات WHOIS.

أمثلة:
/users
/users #ircnow

/help /view
-----------

اختيار محادثة بالاسم أو قناة بالرقم
الاستخدام: /view NAME|NUMBER

أرقام القنوات في /channels وأسماء الخاص في /ql. تقبل أسماء الخادم والإشارات أيضا.

استخدم /help بدلا من اختيار مخزن الدليل الداخلي.

أمثلة:
/view #ircnow
/view alice
/view 0

/help /views
------------

سرد القنوات (اسم بديل لـ /channels)
الاستخدام: /views

يستخدم هذا الاسم البديل أرقام القنوات؛ ويبقى الخاص في /ql.

أمثلة:
/views

/help /watch
------------

إدارة نصوص إضافية لرصد الإشارات بالمطابقة الحرفية
الاستخدام: /watch [list|add TEXT|remove TEXT]

إشارات الاسم المستعار مفعلة دائما. يتعامل Add/remove مع الباقي كنص حرفي، لا كتعبير نمطي.

حتى 32 سلسلة إضافية من 1..127 بايت UTF-8 لكل خادم. احفظها عبر /save.

أمثلة:
/watch list
/watch add release day
/watch remove release day
/mentions

/help /whois
------------

طلب معلومات الاسم المستعار من الخادم
الاستخدام: /whois NICK

يلزم التسجيل. يعرض نافذة الخادم لتظهر الاستجابة. لا ينفذ أمرا محليا.

أمثلة:
/whois alice

/help /znc
----------

التحكم في وسيط ZNC المحدد
الاستخدام: /znc [COMMAND]

يلزم ملف ZNC متصل معد عبر /panel. دون وسيط يطلب Help من *status.

ترسل COMMAND رسالة خاصة واحدة بتباعد زمني، بلا صدى محلي أو سجل للأوامر.

استخدم /msg *module COMMAND لوحدة ZNC مفعلة. تظهر الردود في عرض الخادم.

اتصال IRC المباشر لا يدعم الاختصار. راجع مساعدة الوسيط لأوامره.

أمثلة:
/znc
/znc ListNetworks
/znc Connect
