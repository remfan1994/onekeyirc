دليل عملي لـ vipirc / onekeyirc - قنوات
=======================================================

ترجمة أولية. اكتب الأوامر والخيارات كما هي تماما.
للتفاصيل الأمنية الكاملة راجع MANUAL.txt وSECURITY.md بالإنجليزية.

/help list
----------

يطلب قائمة القنوات من خادم IRC المحدد؛ يلزم اكتمال التسجيل. لا يُرسل إلى الخادم إلا المرشح MASK.

تُطبق حدود عدد المستخدمين الأدنى والأقصى ومرشحات الاسم والموضوع محلياً حتى لو لم تدعم الشبكة مرشحات LIST المتقدمة.

قيم --sort هي channel أو users أو topic؛ الافتراضي users تنازلياً. تعني --limit 0 عدم حد للعرض ضمن الذاكرة المؤقتة المحدودة.

يعرض /list show الذاكرة المؤقتة؛ ترتب --sort و--asc/--desc و--limit النتائج محلياً دون طلب IRC جديد. يمسح /list clear الذاكرة المؤقتة.

عند انقطاع الاتصال أو رفض LIST تبقى النتائج الجزئية لكن ينتهي الطلب؛ أعد /list بعد التسجيل أو استخدم /list clear.

يفتح العميل بملء الشاشة متصفح قنوات قابلاً للفرز؛ يستخدم الوضع المبسط الخيارات نفسها و/list show.

استخدم /ls أو /cl لقنوات العميل المحلية؛ يبحث /list في الشبكة.

/help ls
--------

دون وسيط، يعرض قنوات الخادم المحدد. هذا أمر محلي للعميل، وليس أمر shell ولا طلب IRC LIST للشبكة كلها.

استخدم /server N و/channel N و/pm NICK لاختيار الإدخالات المطابقة.

/help manual
------------

تتوفر مساعدة المواضيع والأوامر دون اتصال. /help TOPIC هو الطريق الأقصر.

/help servers
-------------

يعرض خانات الخوادم 1..8 (الأساسي 1) في الوضع المبسط، والخادم المحدد وحالته وخيار autoconnect لكل خادم.

يظل الملف الشخصي المحمل متاحا حتى عند عدم الاتصال.

/help unignore
--------------

يكافئ /ignore remove MASK. احفظ الملف الشخصي المحدد للإبقاء على التغيير.

/help aliases
-------------

تُقبل الأسماء البديلة المطابقة تماماً فقط؛ لا يُنفذ أمر غامض أو تقريبي.

/conn = /connect; /disc = /disconnect; /detach = /background; /exit = /quit

/j = /join; /leave = /part; /message و /privmsg = /msg

/nickname = /nick; /names و /nicks = /users; /unaway = /back

/channellist = /cl; /querylist = /ql; /serverlist = /servers

/configure و /preferences = /panel; /saveconfig = /saveconf

/autocommand = /autocommands

يقترح الإكمال الأسماء الأساسية؛ تبقى الوسائط كما هي ويظل ترشيح الأسرار من سجل الأوامر كما هو.
