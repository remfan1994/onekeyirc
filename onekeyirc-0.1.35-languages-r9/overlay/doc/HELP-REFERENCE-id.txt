/help about
-----------

Aplikasi dari ThatIAm.vip (www.thatiam.vip), dirancang oleh remfan1994.

Lisensi: IALA (Insha-Allah License Agreement); lihat teks lisensi yang disertakan.

Peringatan pembuka: Bukan vegetarian? www.bloodguiltcurse.net akan mengubah pikiran Anda

Sesi berjalan juga menampilkan pengingat lokal ini sekali ketika antarmuka dipasang:

Pengingat ini tanpa pertanyaan tambahan dan tidak dikirim ke IRC. Menghubungkan ulang atau memasang ulang antarmuka tidak mengatur ulang penanda sekali per proses pekerja.

/help aliases
-------------

Nama alias harus tepat; tidak ada eksekusi ambigu atau pencocokan kira-kira.

/conn = /connect; /disc = /disconnect; /detach = /background; /exit = /quit

/j = /join; /leave = /part; /message dan /privmsg = /msg

/nickname = /nick; /names dan /nicks = /users; /unaway = /back

/channellist = /cl; /querylist = /ql; /serverlist = /servers

/configure dan /preferences = /panel; /saveconfig = /saveconf

/autocommand = /autocommands

Saran pelengkapan memakai nama resmi; argumen tetap persis dan penyaringan riwayat rahasia tidak berubah.

/help authentication
--------------------

Gunakan TLS terverifikasi dengan /autoauth sasl USER file PATH atau /autoauth sasl USER gpg PATH.

Berkas kata sandi atau isi GPG yang didekripsi menyediakan kredensial; jalur digunakan apa adanya.

Gunakan /panel untuk membuat kredensial terenkripsi GPG bagi sidik jari kunci publik lokal yang sudah ada.

Gunakan kunci GPG yang telah dibuka. pinentry tidak dijalankan dalam editor chat.

password= dan server_password= teks biasa juga didukung dalam berkas konfigurasi privat.

Pilih satu sumber saja per kredensial. /settings dan /summary menyembunyikan lokasi berkas.

/autoauth status menampilkan lokasi berkas kredensial aktif dan tertunda tanpa membacanya atau menampilkan kata sandi.

Pengaturan autentikasi berlaku pada /connect berikutnya setelah terputus; /save menyimpannya.

Pada profil bouncer, kelola login dan sumbernya bersama lewat /panel; perubahan /autoauth ditolak.

Berkas kredensial harus berjenis biasa, dimiliki pengguna, bermode 0600 atau 0400; symlink dan lintasan direktori induk ditolak.

Batas kredensial SASL ialah 1024 byte; server PASS biasa 503 byte. Login ZNC gabungan juga harus muat dalam satu baris IRC.

--check-config memvalidasi konfigurasi dan pilihan sumber tanpa membaca kredensial atau menguji login. Lihat /help tls dan /help bouncers.

/help bouncers
--------------

Gunakan /panel, pilih server, lalu jenis koneksi znc atau soju.

Masukkan hostname dan port TLS bouncer, nama pengguna bouncer, nama jaringan upstream yang ada, serta nama klien tetap opsional.

Simpan satu profil per jaringan hulu. Pilih profil yang tepat sebelum /connect tanpa argumen jika nama host sama.

Klien menyusun identitas masuk. ZNC memakai sumber sandi server; soju memakai sumber sandi autentikasi. Masukkan hanya sandi bouncer, bukan identitas gabungan atau sandi NickServ.

Bouncer memulihkan kanal yang diikuti. /autojoin lokal tidak dijalankan dan tidak dapat diubah; gunakan /join dan /part.

Perintah startup eksplisit tetap dijalankan. Tinjau sebelum mengaktifkan profil bouncer agar join atau perintah layanan tidak berulang tanpa niat.

Away otomatis saat idle/latar belakang mati pada tiap profil bouncer kecuali diaktifkan. /away dan /back manual tetap berlaku.

Riwayat dorongan memakai waktu UTC asli, mengarahkan pesan pribadi ke penerima, dan tidak membuat mention, menjalankan CTCP/DCC, atau mengubah status aktif.

Riwayat dibatasi. Tak ada pencarian arsip sesuai permintaan, penemuan jaringan otomatis, atau pembuatan profil otomatis per jaringan.

Jalankan /znc atau /soju tanpa argumen untuk bantuan layanan. Teks kendali tidak masuk riwayat atau echo; jawaban tampil di server tanpa log persisten.

Salinan kendali keluar yang dikenali disembunyikan walaupun replay memakai nama lama. Teks yang diketik masih bisa tampil dan bouncer punya aturan log sendiri.

Klien hanya terhubung ke bouncer. Atur TLS, autentikasi, dan penyimpanan riwayat di sisi hulu secara terpisah.

Lihat doc/BOUNCERS.txt dan contoh bouncer di examples/ untuk pengaturan dan batas validasi yang dicatat.

/help configuration
-------------------

[connection] berisi server, port, tls, nick, username, realname, channel, autoconnect, auth, dan sumber kredensial.

[bouncer] type=none|znc|soju, username, network, client, dan automatic_away mengatur profil bouncer per jaringan; lihat /help bouncers.

[input] send_mode=direct|review dan [output] format=compact|full, queue_notices=true|false, program_messages=true|false, persistent_logging=true|false adalah preferensi di konfigurasi utama.

[input] command_suggestions=common|history|frequent|alphabetical|contextual mengatur urutan perintah; bawaan common.

[input] composer_mode=line|fullscreen memilih tata letak penulisan/komando minimalis; bawaan line. Keduanya menampilkan pesan terbaru.

[input] force_terminal_signals=false menjaga sinyal terminal bawaan; true mengaktifkannya tanpa mengubah tombol. Preferensi utama ini dibaca saat mulai.

[hotkeys] memuat paling banyak 64 ikatan KEY=action opsional tanpa bawaan. Milik konfigurasi utama; lihat /help hotkeys.

[session] single_session=true|false menentukan boleh tidaknya beberapa tugas latar; bawaan false.

[session] default_interface=ncurses|idle adalah preferensi aplikasi utama. Pilihan saat mulai dijelaskan di bawah.

Tampilan compact adalah bawaan. history_lines di konfigurasi utama mengatur jumlah riwayat yang disimpan untuk semua server.

[mentions] word= dan [ignore] mask= boleh diulang.

[autocommands] berisi enabled, delay_seconds, interval_seconds, dan baris command= berulang untuk satu server.

Perintah ini berupa teks biasa dalam konfigurasi privat. /autocommands mengelolanya tanpa membuka rahasia di daftar/riwayat.

Profil server tambahan yang disimpan memakai katalog .servers dan direktori .d di sebelahnya.

Hubungkan lewat /connect HOST, lalu /join #channel dan /saveconf untuk menyimpan konfigurasi yang berfungsi.

/saveconf menyimpan preferensi dan profil server yang sehat, serta mengingat server terpilih untuk /connect tanpa argumen nanti.

/quickstart menanyakan empat hal koneksi. /panel memakai 0 untuk preferensi dan 1..8 untuk profil; panel 1 mengubah profil utama.

Perubahan panel tetap privat sampai Finish. Menerima tujuan GPG dapat menyiapkan direktori 0700; enkripsi, penulisan konfigurasi, dan koneksi menunggu pilihan akhir.

Agar tetap setelah mulai ulang, pakai /save untuk server terpilih, /save input atau /save output untuk profil utama, atau /saveconf untuk profil sehat dan pilihan bawaan.

Konfigurasi yang tersimpan memakai <config_path>.commands untuk membaca/menulis hitungan penggunaan perintah; konfigurasi utama tidak menyimpan hitungan.

Berkas privat terbatas ini hanya berisi nama perintah baku dan jumlahnya, bukan argumen atau riwayat pesan. Mode uji tidak membaca/menulisnya.

Perubahan [connection] dari /autojoin atau /autoauth berlaku pada /connect berikutnya saat terputus; koneksi aktif tidak berubah.

Berkas konfigurasi bersifat privat; penulisan mengganti tiap berkas secara atomik, bukan seluruh ruang kerja sekaligus. Tidak ada impor/ekspor.

Bagian, kunci, atau nilai tak dikenal adalah kesalahan. Konfigurasi memakai nilai literal, bukan kutip shell, escape, variabel, atau ~.

Nilai umum dipangkas di ujungnya. password= dan server_password= mempertahankan isi setelah = kecuali akhir baris; jangan tambah komentar atau tanda kutip.

Penyimpanan menulis ulang pengaturan yang didukung dan mengganti format/komentar buatan tangan. Simpan catatan di luar konfigurasi yang dihasilkan.

Lihat /help authentication untuk rahasia, /help tls untuk CA, /help logging untuk log disk, dan /help sessions untuk kendali pekerja aktif.

/help deployment
----------------

Gunakan --background untuk menjalankan sesi tanpa terminal atau menekan tombol pembuka.

Atur dan simpan /autoconnect on pada setiap server yang harus dimulai.

--background tidak otomatis mengaktifkan autoconnect; --no-connect tetap mencegah koneksi saat mulai.

Peringatan biasa ditampilkan sekali sebelum lepas dari terminal. Sukses berarti tugas lokal berjalan, bukan login IRC berhasil.

Dari terminal lain pada akun pengguna yang sama, gunakan --sessions dan --resume [NUMBER].

--sessions mencakup pekerjaan terpasang. --detach-session NUMBER melepas terminal tanpa merusak pekerjaan agar bisa dilanjutkan di tempat lain. --close-session NUMBER mengakhiri pekerjaan terpilih dan semua koneksi IRC.

Gunakan ID pekerjaan dalam daftar, bukan PID. Pekerja tidak responsif atau versi lama tanpa kendali yang diminta bisa gagal. Lihat /help sessions untuk pemulihan dan peningkatan.

Mulai ulang VPS mengakhiri tugas lama, draf, dan riwayat RAM. Tugas awal OS dapat memulai klien baru.

Petunjuk OpenBSD dan contoh rc.d opsional ada di doc/OPENBSD-VPS.txt.

Jalankan sebagai pengguna biasa dengan jalur konfigurasi dan kredensial absolut. Kunci GPG yang terkunci tidak dapat meminta input saat boot.

--check-config memeriksa pengaturan, bukan akses kredensial, DNS, TLS, atau login IRC.

Gunakan --reconnect saat jaringan putus sementara; pengawasan proses yang crash adalah tugas sistem operasi terpisah.

Peluncur harus membiarkan anak dapat ditunggu: SIGCHLD yang diabaikan atau penuaian anak otomatis menggagalkan awal latar pertama, resolver, atau pembantu kredensial. Pelepasan ulang terkelola tidak membuat pekerja baru.

/help COMMAND menampilkan sintaks, dampak, dan contoh. /help /ls menjelaskan daftar lokal; /help ls mencantumkan topik.

/help all atau /manual membuka referensi lengkap. --help menjelaskan opsi saat mulai; keluaran --manual pada mode minimal dapat dialihkan ke berkas.

/help history
-------------

Riwayat tampilan dan perintah dibatasi di RAM. Log persisten bersifat opsional dan mati secara baku.

Beralih tampilan memutar ulang riwayat terakhirnya; /mentions memutar ulang baris sumber yang cocok.

Pengaturan riwayat aplikasi membatasi gabungan catatan semua server/tampilan; edit melalui /panel, lalu 0.

Retensi dibatasi nilai terkecil antara pengaturan itu dan 2048 catatan, dengan batas byte mutlak terpisah 512 KiB.

/catchup dalam kanal atau percakapan pribadi mulai dari pesan susunan terakhir yang Anda kirim lokal. Ia mencoba log privat yang layak, lalu memori tersimpan; /help catchup menjelaskan kedua pembaca.

Pemulihan persisten berlaku per server dan percakapan. Log harus sudah aktif saat pesan acuan dikirim; isinya transkrip teks polos privat, maksimal 16 MiB per profil tersimpan, tanpa enkripsi.

Riwayat perintah menampung hingga 64 entri dan 64 KiB, membuang yang terlama. /clear menghapus riwayat percakapan, bukan riwayat perintah.

Saran Riwayat terbaru memakai baris lengkap ini. Delete menghapus baris riwayat terpilih.

Saran Paling sering memakai hingga 96 nama perintah baku dan hitungan terbatas dalam <config_path>.commands.

Untuk konfigurasi tersimpan, perintah yang diterima dan pengaturan ulang frekuensi otomatis memperbarui berkas privat itu. Argumen, tujuan, dan pesan tidak disimpan di dalamnya.

Profil belum tersimpan menyimpan hitungan di memori hingga Simpan pertama berhasil. Berkas hitungan yang hilang atau tidak dapat dipakai tidak menghalangi awal aplikasi.

Bantuan dan respons perintah multibaris memakai pembaca terpisah dengan penyangga terbatas 512 KiB. Keduanya tidak masuk riwayat percakapan.

Perintah yang diterima dapat dipanggil lagi di editor perintah. Perubahan autentikasi, bergabung dengan kunci, dan pesan layanan sensitif dikecualikan.

Up/Down di Compose memindahkan kursor, bukan memanggil chat terkirim. Hanya perintah diterima dapat dipanggil di Command.

Lepas/lanjut pada antarmuka sama mempertahankan draf dan riwayat perintah. Ganti antarmuka, jika didukung, membuang keduanya dan formulir; keluar/reboot juga menghapus percakapan dalam memori dan acuan catch-up.

Hitungan frekuensi tersimpan hanya memuat nama. Log teks polos lama tetap ada setelah keluar, tetapi tidak diimpor otomatis ke sesi baru atau editor.

/clear menghapus riwayat RAM tampilan, bukan transkrip lama di disk. Pemutaran ulang bouncer berasal dari bouncer.

/help hotkeys
-------------

Pintasan tombol khusus opsional dan awalnya kosong. Navigasi dan editor bawaan tetap tersedia.

Gunakan /bindings untuk daftar, /bindings keys untuk tombol, dan /bindings actions untuk fungsi lokal.

Tetapkan dengan /bind KEY ACTION; tetapkan lagi untuk mengganti. Hapus dengan /unbind KEY atau /unbind all.

Perubahan langsung berlaku pada semua server; /save input menyimpannya di konfigurasi utama. Profil server lain tidak mengganti tabel ini.

Format [hotkeys], lalu satu KEY=action per baris, maksimal 64. Tombol ganda termasuk alias terminal adalah kesalahan.

Aksi khusus hanya berjalan di obrolan utama dan kolom perintah, bukan pada sandi, pengaturan, tempelan, pembaca, atau konfirmasi.

Di mode minimal, pembaca mempertahankan draf dan kursor. Pintasan pengalih tampilan/editor menolak draf yang belum kosong; selesaikan atau hapus dahulu.

Tidak ada aksi kirim, perintah bebas, kode shell, atau makro teks. Latar dan keluar tetap berfungsi seperti biasa.

Tersedia F1..F12, Ctrl-A..Z, Alt-a..z/0..9, dan tombol navigasi; karakter biasa tetap menjadi teks.

Ctrl-H/Backspace, Ctrl-I/Tab, Ctrl-J/Ctrl-M/Enter, Ctrl-[/Escape berbagi byte; tak bisa diberi ikatan berbeda.

Sinyal dan pintasan terminal/multiplexer lebih utama. Ctrl-C atau Ctrl-Z bekerja hanya bila byte tiba di aplikasi; tombol tak dipetakan ulang.

Tempelan berbingkai yang dikenali tidak menjalankan pintasan. Tempelan tanpa bingkai tampak seperti ketikan; lihat /help keys.

/help keys
----------

Log: / membuka Perintah; ? menjelaskan log percakapan/pantauan terpilih. Tombol cetak lain membuka Tulis pesan dengan karakter itu tetap ada.

Ikatan tombol khusus dapat mengganti kendali ini dalam percakapan utama/Perintah; tidak ada yang ditetapkan secara bawaan. Lihat /help hotkeys.

Log langsung: Up mundur satu baris, Page Up satu halaman, Home ke halaman tersimpan terlama. Down/Page Down/End tetap langsung; Left/Right/Delete/Backspace tidak membuka Tulis pesan.

Insert atau Enter membuka Tulis pesan kosong. Panah, Home/End, Delete dan Backspace mengedit teks. Tab/Shift-Tab melengkapi nama panggilan di Tulis pesan dan nama perintah di Perintah.

Mode penulis sebaris menyisakan satu baris masukan di bawah ekor log langsung; layar penuh memakai editor multibaris dengan panel log langsung yang lebih kecil.

Dalam Perintah, Down memilih saran. Up/Down berpindah antarsaran; Up dari yang pertama kembali ke masukan.

Enter pada saran menyisipkannya tanpa menjalankan. Baca/edit, lalu tekan Enter lagi setelah tampil untuk menjalankan.

Dalam Perintah, Up memanggil riwayat diterima yang cocok; Down kembali menuju masukan awal. Dalam Tulis pesan, Up/Down menggerakkan kursor, juga saat ditahan; Enter mengirim.

Delete menghapus baris Riwayat terbaru terpilih atau mengatur ulang hitungan Paling sering terpilih. Perintah katalog tetap tersedia.

? pada perintah terpilih menjelaskannya dan menautkan bantuan layar perintah. Dalam semua editor teks, ? adalah teks biasa.

Tinjauan memakai layar alternatif sementara; draf/pertanyaannya tidak masuk riwayat percakapan. Enter baru mengonfirmasi; Escape atau mengetik memulihkan editor/draf/kursor. Jelajahi dengan Up/Down, Page Up/Down dan Home/End.

Dalam bantuan/respons, Up/Down menggulir; Page Up/Down berpindah halaman; Home/End ke awal/akhir.

Dalam daftar pengguna, Enter kembali ke log; pembaca bantuan dan respons lain memakai Enter untuk menggulir satu baris.

Dalam pembaca, / membuka Perintah dengan pelengkapan/riwayat biasa. Escape membatalkan masukan itu dan kembali ke pembaca.

Dalam pembaca ringkasan, r menyegarkan cuplikan; ? menjelaskan respons dan pembacanya.

Dalam bantuan konteks, Enter mengikuti tautan Tentang layar yang disorot. Escape kembali ke bantuan item, lalu ke layar asal yang tepat.

Dalam penyiapan, Tab memilih judul pertanyaan; ? menjelaskan opsi/layarnya. Tab/Enter kembali mengedit jawaban.

Menjalankan perintah mengganti respons sebelumnya. Konfirmasi singkat kembali ke log; kesalahan singkat membiarkan perintah dapat diedit.

Escape membatalkan editor Tulis pesan/Perintah ke log. Dari Tinjauan, Escape kembali ke editor tanpa membuang draf. Escape pada log memindahkan klien ke latar belakang.

Escape tunggal menunggu sekitar 500 ms; urutan yang berjalan mengizinkan 1000 ms antarbyte lanjutan. Jaringan tetap berjalan.

Urutan tombol lengkap ditangani segera. Penanda awal tempel yang tertunda setelah Escape pertamanya melewati tenggang itu bisa memindahkan klien ke latar belakang.

Setelah penangkapan tempel dimulai, penanda akhirnya tetap dikenali meski pembacaan terpisah dan tertunda selama apa pun.

Pemetaan terminal untuk interupsi, keluar, dan tunda serta status sinyal aktif/nonaktif diwarisi.

[input] force_terminal_signals=false adalah bawaan. true mengaktifkan sinyal tetapi tidak pernah menetapkan byte tombol.

Sinyal terminal aktif mengakhiri atau menunda setelah memulihkan terminal; fg melanjutkan pekerjaan tertunda.

Ctrl-D tidak bekerja kecuali diikat dalam percakapan utama/Perintah. /quit keluar; /background melepas terminal sementara jaringan tetap berjalan.

Layar rutin tidak mengulang petunjuk tombol; topik ini tetap menjadi referensi lengkap papan ketik.

Tempelan berbingkai yang dikenali tetap literal. Tombol menunggu editor terlihat, masukan baru, dan jeda. Bingkai kecil/gagal tidak dapat menyetujuinya; ubah ukuran dan lepas tombol tertahan.

Tempel pada log pantauan membuka Tulis pesan dengan garis miring literal. Tempel dalam Perintah tetap di sana; CR/LF/Tab menjadi spasi. Tinjau, lalu tekan Enter baru.

Tempel tanpa bingkai tidak dapat dibedakan dari mengetik; gunakan dukungan tempel berbingkai.

/help limits
------------

Batas IRC dihitung dalam byte, bukan jumlah karakter tampilan. Karakter UTF-8 dapat memakai lebih dari satu byte.

Klien menghitung ruang pesan termasuk tujuan, perintah, dan overhead relai; ia tidak memotong karakter UTF-8.

Pada batas satu pesan, teks tambahan ditahan sampai Enter mengonfirmasi lanjut mengedit; Enter itu tidak mengirim.

Pesan yang terpecah tetap perlu izin terpisah sebelum antre, bahkan pada mode langsung. Obrolan dikirim satu baris tiap 1.2 detik.

Sekali pengiriman maksimal 64 pesan dan 16384 byte teks. Singkat teks atau kirim terpisah secara sengaja.

Maksimal ada 8 slot server dan 32 tampilan per server, termasuk tampilan cadangan.

/help logging
-------------

Log persisten opsional dan mati secara bawaan. /set persistent_logging on mengaktifkan; /save output menyimpan pilihan.

Setiap profil server tersimpan menambah CONFIG_PATH.log. Direktori induk terakhir harus milik pengguna, mode 0700; berkas milik pengguna, biasa, satu tautan, tepat 0600. Symlink dan lintasan naik direktori ditolak.

Log berupa plaintext, bukan cadangan terenkripsi. Batasnya 16 MiB per berkas; kegagalan penulisan menghentikan log, bukan obrolan.

Arsipkan log penuh di luar jalur aktif, lalu matikan/nyalakan log. Rotasi atau tulis ulang bisa membatalkan penanda /catchup; kirim pesan baru yang memenuhi syarat sebelum mengandalkannya.

Kredensial yang dikenal dan draf belum terkirim dikecualikan, termasuk autentikasi ulang dengan nama lama. Obrolan biasa, layanan tak dikenal, dan rahasia yang diketik bisa tetap terekam. Retensi server dan bouncer terpisah.

/catchup memakai log sehat hanya jika penanda lokal tepat dicatat selama proses ini berjalan. Tidak meminta arsip dari bouncer atau mengimpor log lama setelah mulai ulang.

/clear hanya membersihkan RAM. Log tetap ada setelah keluar, --close-session, atau menyimpan. Mematikan log menghentikan catatan baru, bukan menghapus yang lama.

I/O disk biasa bisa memperlambat proses pada penyimpanan lambat. Lihat /help catchup, /help history, dan SECURITY.md.

/help messages
--------------

Gunakan /join #channel untuk bergabung dan memilih saluran, atau /query NICK untuk membuka percakapan pribadi.

Pilih saluran tersimpan dengan /channel. /msg TARGET TEXT mengirim ke tujuan tertentu; /me TEXT mengirim aksi.

/query membuka percakapan tanpa mengirim; /pm adalah alias. /ql memisahkan daftar percakapan pribadi dari saluran.

Pengiriman langsung adalah baku; /set send_mode review menambah peninjauan. /set composer_mode line|fullscreen mengubah tampilan.

Setelah batas satu pesan tercapai, akui dulu untuk lanjut mengedit; pemecahan pesan tetap memerlukan persetujuan terpisah.

Bergabung dan autentikasi harus selesai sebelum pesan bisa diantrikan. /cancel membatalkan antrean, bukan pesan yang sudah terkirim.

/help reconnect
---------------

--reconnect mengaktifkan percobaan ulang pada proses ini; tidak menyimpan pengaturan atau memulai koneksi.

Tanpa opsi ini, koneksi gagal masih memerlukan /connect. /autoconnect hanya mengatur saat mulai.

Gangguan DNS sementara, koneksi ditolak/putus, dan batas waktu server dicoba lagi setelah 5, 10, 20, 40, 80, 160, lalu 300 detik.

Koneksi yang terdaftar selama sekurangnya 60 detik mengatur ulang jeda itu. Polling tanpa tidur yang memblokir.

Galat verifikasi sertifikat, autentikasi, protokol rusak, dan konfigurasi tetap terputus sampai diperbaiki.

ERROR server sebelum registrasi dipertahankan; setelah registrasi dapat memicu koneksi ulang.

/disconnect secara eksplisit membatalkan percobaan tertunda. /connect kemudian memulai upaya baru.

Percobaan ulang memakai pengaturan koneksi saat ini; edit tertunda tetap memerlukan /connect secara eksplisit.

Pesan yang mengantre dibuang saat terputus dan tidak dikirim ulang otomatis.

Autentikasi dan perintah awal yang aktif berjalan lagi. Profil langsung mengulang autojoin setelah autentikasi; bouncer memulihkan kanalnya sendiri.

Mode uji offline tidak pernah menghubungkan ulang ke jaringan.

/help security
--------------

Teks jarak jauh disaring sebelum tampil di terminal. Input ditafsirkan sebagai perintah IRC lokal, bukan perintah shell.

Tidak ada /raw, pelarian shell, atau penerimaan berkas otomatis. Tempelan bracketed yang dikenali tidak pernah menjalankan perintah.

TLS memverifikasi identitas server. SASL, PASS, dan perintah autentikasi pribadi yang dikenali wajib memakai TLS terverifikasi. Perbarui pustaka TLS sistem; lihat SECURITY.md.

Bundel CA khusus harus berkas PEM biasa yang tidak kosong, maksimal 16 MiB, dan tidak meminta kata sandi.

Kata sandi yang disetel disembunyikan dari bantuan/pengaturan. Perintah kredensial yang dikenali tidak masuk riwayat perintah; rahasia dalam teks biasa mungkin tetap tersimpan.

Transkrip percakapan tidak disimpan ke disk secara baku. Perubahan konfigurasi harus disimpan secara eksplisit.

Proses lain pada akun yang sama, server IRC atau bouncer, serta terminal atau sistem yang disusupi berada di luar perlindungan ini. TLS bukan enkripsi obrolan ujung-ke-ujung.

Log opsional dan rahasia di berkas konfigurasi berupa teks biasa. Perintah sensitif yang dikenal disaring, tetapi rahasia bebas dalam obrolan tidak selalu dapat dideteksi.

Lihat /help tls, /help authentication, /help logging, dan SECURITY.md untuk batas perlindungan dan riwayat audit.

/help sessions
--------------

Satu job adalah proses klien yang memuat semua server, transfer, draf, dan riwayatnya. Nomor server di aplikasi bukan ID job pada shell.

Dari shell jalankan --sessions. Gunakan ID pekerjaan yang terdaftar, bukan ID proses; periksa status terpasang atau terlepas.

Jika terminal SSH lama masih menguasai sesi, jalankan --detach-session NUMBER lalu --resume NUMBER. IRC tetap berjalan.

--resume tanpa nomor hanya memilih satu job terlepas yang terverifikasi. Banyak job memerlukan nomor; job terpasang sibuk sampai dilepas. Nomor dapat dipakai kembali setelah keluar.

Gunakan --close-session NUMBER hanya untuk mengakhiri seluruh job. Semua sambungan IRC dan transfer ditutup; draf dan riwayat RAM hilang. Konfigurasi dan log tersimpan tetap ada.

Penutupan baru berhasil setelah pembersihan terverifikasi. Bila batas waktu habis, cek --sessions lagi: proses mungkin selesai nanti. Kegagalan tidak menghapus endpoint aktif atau mengirim sinyal ke PID dugaan.

Hanya job terkelola yang bertahan saat terminal hilang. Proses biasa di latar depan tidak dapat dipulihkan setelah SSH putus. Mulai dengan --background atau jalankan /background dahulu.

Job milik akun Unix dan host yang sama, dengan satu terminal terpasang sekaligus. Program lain pada akun tersebut berada dalam batas kepercayaan yang sama.

Memasang program baru tidak mengganti kode pekerja yang sedang berjalan. Simpan konfigurasi, hentikan pekerja lama, periksa --version, lalu mulai pekerja baru.

Pekerja lama mungkin tidak punya kendali baru atau fitur ganti antarmuka. Simpan biner yang kompatibel sampai pekerja berhenti jika masih perlu tersambung.

Klien tidak mengubah kebijakan batas waktu idle SSH. Lihat /help background, /help deployment, dan doc/SESSION-CONTROLS.txt.

/help startup
-------------

Jalankan program, tutup sambutan, lalu ketik /connect irc.example.org dan /join #channel.

Tak perlu membuat profil server, alias, atau nomor lebih dulu. /server HOST adalah alias sambungan langsung.

Jika tidak diberi nama panggilan, dipakai nama login sistem yang valid, atau user jika tak cocok. Tidak ada permintaan nama panggilan.

Gunakan /saveconf untuk menyimpan konfigurasi dan pilihan baku. Saat dijalankan lagi, /connect menggunakannya.

Menyimpan tidak mengaktifkan sambungan otomatis; pilih itu secara terpisah. /quickstart dan /panel adalah panduan opsional.

Opsi shell juga berlaku: --server HOST, --channel '#CHANNEL', dan --nick NICK. Beri tanda kutip pada #CHANNEL di shell.

Saat mulai biasa, --nick, --port, --channel, --tls, --plain, dan --ca-file mengganti pilihan baku yang tersimpan.

--server yang ditentukan memilih sambungan pertama. --init-config dan --check-config memakai berkas konfigurasi utama.

Mengubah --server ke host lain menghapus kredensial host lama, CA khusus, identitas bouncer, saluran, dan perintah awal.

Jika pilihan baku tersimpan tidak tersedia, tentukan --server atau perbaiki pilihannya sebelum mengubah sambungan.

Autoconnect, autojoin, dan autoauth berlaku per profil server tersimpan. Lihat /help autoconnect untuk pengalihnya.

--no-connect mencegah sambungan awal; --test-mode mensimulasikan aktivitas tanpa jaringan atau penulisan konfigurasi.

--sessions mencantumkan job terpasang dan terlepas. --resume [NUMBER] memasang lagi; lihat /help background.

--close-session NUMBER menutup seluruh job terpilih beserta sambungan IRC setelah selesai terverifikasi. NUMBER adalah ID job, bukan PID.

Setelah terminal terputus, pakai --sessions, lalu --detach-session NUMBER dan --resume NUMBER. Worker memakai kode lama sampai dimulai ulang; lihat /help sessions.

-h/--help dan -v/--version bekerja tanpa terminal.

/help tls
---------

TLS terverifikasi adalah bawaan. Nama host atau alamat server serta rantai sertifikat harus valid; tidak ada jalan pintas atau fallback plaintext.

Nomor port tidak mematikan TLS. --plain atau /connect -plain memilih IRC tanpa enkripsi dan tidak dapat memakai kredensial akun/server.

Gunakan nama host dan port TLS tepat dari penyedia. Gagal bisa karena endpoint salah, sertifikat kedaluwarsa/tak dipercaya, atau trust lokal; lihat galat koneksi dahulu.

Secara bawaan TLS memakai trust store sistem. --ca-file FILE atau ca_file= memilih bundel CA PEM khusus, bukan mematok sertifikat leaf.

Bundel CA khusus harus berkas biasa tak kosong, maksimal 16 MiB. Symlink biasa ke berkas CA diizinkan; jalur rahasia/konfigurasi lebih ketat.

Berkas CA dibuka sekali, dibatasi dan ukurannya dicek saat dibaca. FIFO, perangkat dan input nonberkas ditolak; PEM bersandi tak dapat meminta sandi.

Batas ukuran berkas tidak membatasi latensi I/O berkas biasa atau sistem berkas jaringan. Pakai bundel CA tepercaya di penyimpanan sesuai.

--check-config tidak menguji koneksi TLS atau memastikan berkas CA dan sumber kredensial berfungsi. --test-mode tidak menghubungi server.

TLS hanya melindungi koneksi ini. TLS hulu dan riwayat plaintext pada bouncer diatur terpisah.

/help troubleshooting
---------------------

Sibuk setelah SSH putus? Jalankan --sessions, periksa pekerjaan, lalu --detach-session NUMBER dan --resume NUMBER. Hindari --close-session. See /help sessions.

Up tidak memanggil ulang teks: Compose menyunting pesan; Command memanggil perintah diterima. Buka Command dengan / dari log. Pesan terkirim dan perintah sensitif bukan riwayat pemanggilan.

Jika pesan terbungkus tampak terpotong, tampilan input menyisakan baris untuk editor dan menampilkan baris terbaru. Keluar editor atau pilih ulang kanal; baris yang terlihat bukan bukti pesan tiba.

Jika pindah kanal menampilkan teks lengkap, beda tampilan adalah penyebabnya. Jika gangguan berlanjut, catat antarmuka, mode, ukuran terminal, locale, dan langkah aman tanpa sandi atau transkrip pribadi.

Kanal kosong? Periksa tampilan server dan autentikasi. Profil langsung memakai /autojoin list; bouncer memulihkan kanal; gunakan /join atau /part.

Autentikasi gagal? Periksa akun, sumber kredensial, izin berkas, TLS, dan agen GPG. /autoauth status tidak membaca rahasia.

Catch-up tidak tersedia: penanda mungkin terbuang, logging dimulai belakangan atau berhenti, atau log berubah. Lihat /help catchup dan /help logging; berkas log tidak menghidupkan pekerja mati.

Perubahan belum berlaku? Ubah koneksi dengan /connect setelah terputus. Menyimpan berbeda dari autoconnect; preferensi awal perlu proses baru.

Jika peluncuran helper gagal, perbaiki kebijakan SIGCHLD atau pengambilan child otomatis pada peluncur agar klien dapat menunggu proses anaknya.

Gunakan --check-config dan doc/TROUBLESHOOTING.txt. --test-mode hanya menguji antarmuka, bukan DNS, TLS, kredensial, atau bouncer nyata.

/help /autocommands
-------------------

Prepare delayed commands for the next connection
Penggunaan: /autocommands [list|add COMMAND|remove NUMBER|clear|on|off|delay SECONDS|interval SECONDS]

Perintah milik server terpilih. Dijalankan sekali setelah registrasi dan SASL yang diperlukan berhasil.

Jeda bawaan 15 detik, dan paling sedikit 2 detik antarselesainya perintah.

Atur dengan delay 0..300 dan interval 2..60. Koneksi macet tidak memicu rentetan perintah susulan.

Perintah yang didukung: /msg, /join, /nick, /away, /back, dan /whois beserta alias persis yang didokumentasikan.

Maksimal 16 perintah, masing-masing 511 byte UTF-8. Satu perintah harus muat dalam satu pesan IRC; tidak dipecah diam-diam.

Tidak ada shell, IRC mentah, atau perluasan percakapan saat ini. Gabung otomatis tidak mengganti tampilan.

Perubahan berlaku pada koneksi berikutnya. /cancel menghentikan perintah awal yang belum terkirim.

Daftar menyembunyikan teks pesan dan kunci kanal; perintah otomatis tidak masuk riwayat atau tampilan pesan lokal.

Simpan dengan /save. Berkas harus privat (0600 atau 0400); daftar aktif yang berisi perintah memerlukan TLS terverifikasi.

Mode uji tidak menjalankan perintah otomatis. Teksnya disimpan apa adanya di konfigurasi, tanpa enkripsi GPG.

Contoh:
/autocommands add /msg ChanServ op #chat mynick
/autocommands delay 15
/autocommands interval 2
/autocommands list
/save

/help /background
-----------------

Pertahankan koneksi dan lepaskan terminal
Penggunaan: /background

Mengembalikan terminal lalu melepas sesi yang berjalan. Shell menampilkan perintah bernomor untuk melanjutkannya.

Di shell, --sessions mencantumkan tugas privat yang terpasang dan terlepas; --resume melanjutkan satu-satunya tugas terlepas.

Jika ada beberapa tugas, gunakan --resume NUMBER. NUMBER adalah ID tugas, bukan PID; tetap hingga tugas berakhir dan kemudian bisa dipakai ulang.

--detach-session NUMBER melepas terminal terpasang namun mempertahankan proses, koneksi IRC, draf, dan riwayat untuk --resume NUMBER.

--close-session NUMBER mengakhiri seluruh tugas, koneksi IRC, transfer, draf belum disimpan, dan riwayat RAM. Keberhasilan dilaporkan hanya setelah penutupan terverifikasi.

Jika lanjut sesi sibuk setelah terminal SSH hilang, daftar tugas, lepas tugas itu, lalu lanjutkan. Lihat /help sessions.

Pekerja yang tidak merespons atau versi lama tanpa kontrol itu bisa gagal. Memasang biner baru tidak memperbarui proses aktif; mulai ulang setelah pembaruan.

Melanjutkan menampilkan riwayat RAM meski tak ada pesan baru. /set single_session on menolak tugas latar kedua agar --resume tidak rancu.

Untuk mulai tanpa terminal, gunakan --background di shell. Lihat --help untuk opsinya.

Jika background_away aktif dan profil mengizinkan, /background atau kehilangan terminal mengantre AWAY setelah terlepas. Lanjut sesi hanya menghapus status otomatis itu; /away manual tetap ada.

Tambahkan --reconnect untuk mencoba ulang kegagalan sementara. Lihat /help deployment dan /help reconnect.

Tidak perlu multiplexer terminal. Resolver atau pembantu kredensial yang belum selesai bisa memerlukan percobaan ulang.

Menangguhkan proses latar depan biasa menghentikan jaringan. Sesi yang dilanjutkan dapat menangguhkan pengendali terminal sementara pekerjanya tetap terhubung.

Contoh:
/background

/help /connect
--------------

Hubungkan langsung ke server atau gunakan koneksi tersimpan
Penggunaan: /connect [-tls|-plain] [-nick NICK] HOST [PORT] | /connect

Mulai dengan /connect irc.example.org. Tidak perlu membuat profil, alias, atau nomor server dahulu.

Server baru memakai TLS terverifikasi pada port 6697 dan nama login sistem, atau user jika nama itu tidak sesuai.

Server cocok yang sudah ada mempertahankan port, transport, nama panggilan, dan autentikasi yang dikonfigurasi.

Gunakan -nick NICK untuk nama panggilan khusus, atau /nick NICK sebelum terhubung. Sandi bukan argumen posisi.

Gunakan -plain untuk IRC tanpa enkripsi (port bawaan 6667). -tls dan -ssl memilih TLS terverifikasi.

+PORT juga memilih TLS. Port angka biasa tidak mematikan TLS. --tls, --plain, dan --nick juga diterima.

Koneksi dipilih dan membuka tampilan server/MOTD. Koneksi cocok yang sudah aktif dipilih tanpa duplikasi.

Endpoint berbeda mendapat pengaturan autentikasi baru; kredensial dan kanal server lain tidak disalin.

/connect tanpa argumen memakai server terpilih dan pengaturan berikutnya. /saveconf mengingat server bawaan untuk awal berikutnya.

Untuk profil bouncer di host yang sama, pilih profil dengan /server NUMBER, lalu jalankan /connect saja.

Nomor server lama juga diterima demi kompatibilitas. Mode uji tetap offline; edit konfigurasi harus disimpan secara eksplisit.

Contoh:
/connect irc.example.org
/join #chat
/saveconf
/connect
/connect -nick mynick irc.example.org +6697
/connect -plain localhost 6667

/help /dcc
----------

Offer, review and manage direct file transfers
Penggunaan: /dcc [list|NICK PATH|send [-address IPV4] [-port PORT] NICK PATH|accept NUMBER [DIRECTORY]|reject NUMBER|cancel NUMBER]

Tanpa argumen, tampilkan transfer. /dcc NICK PATH menawarkan berkas pada server terpilih.

PATH adalah seluruh teks tersisa, termasuk spasi; jalurnya relatif terhadap direktori saat proses dimulai.

Klien tidak pernah mengubah direktori itu, termasuk saat menelusuri berkas atau berjalan di latar.

Pengiriman singkat mengumumkan IPv4 lokal koneksi IRC. Di balik NAT, pakai -address berisi IPv4 yang dapat diakses dan -port port yang diteruskan.

Tidak meminta alamat dari layanan luar. Koneksi IRC khusus IPv6 memerlukan IPv4 yang diisi secara eksplisit.

DCC adalah koneksi langsung tanpa enkripsi. Rekan menerima IP yang diumumkan; menerima tawaran juga membuka IP kepada rekan.

Tawaran masuk belum dibuka sampai /dcc accept NUMBER. DIRECTORY memakai direktori awal secara bawaan dan harus milik Anda serta privat.

Berkas tujuan yang ada tidak ditimpa; symlink dan berkas khusus ditolak. Mode uji tidak membuka berkas atau soket.

Gunakan /dcc reject NUMBER untuk menolak tawaran atau /dcc cancel NUMBER untuk membatalkan transfer aktif.

Nomor transfer berlaku di semua server proses ini. Menutup server asal membatalkan transfernya; putus IRC tidak membatalkan transfer yang sudah diterima.

Contoh:
/dcc alice file.txt
/dcc list
/dcc accept 1 ./downloads
/dcc send -address 203.0.113.20 -port 5000 alice file.txt
/dcc cancel 2

/help /panel
------------

Buka panel konfigurasi interaktif
Penggunaan: /panel

Pilih 0 (bawaan) untuk preferensi aplikasi, atau panel profil 1..8; panel 1 mengedit profil utama. Ini pilihan panel, bukan ID pekerjaan shell.

Preferensi aplikasi mencakup retensi riwayat, mode kirim, format keluaran, pemberitahuan antrean, dan saran perintah untuk semua server.

Preferensi ini berfungsi tanpa server yang dikonfigurasi. Pilihan akhirnya 1 Simpan (bawaan) dan 2 Terapkan tanpa menyimpan; keduanya tidak menghubungkan.

Panel server hanya berisi pengaturan koneksi, awal, autentikasi, sebutan, dan pengabaian server itu.

Memilih panel apa pun tidak memindahkan percakapan Anda.

Enter mempertahankan nilai yang tampil; '-' mengosongkan bidang opsional. Escape mundur satu pertanyaan; ulangi untuk keluar tanpa menerapkan perubahan.

Tab memilih judul pertanyaan. Tekan ? di sana untuk bantuan opsi dan layarnya; Tab atau Enter melanjutkan jawaban.

Dalam setiap jawaban yang dapat diedit, ? tetap teks literal, termasuk sebagai karakter pertama dan dalam pola wildcard.

Masukkan istilah pantauan dan pola pengabaian satu per satu; entri baru kosong mengakhiri daftar itu.

Masukan kredensial disembunyikan; jawaban penyiapan tidak pernah masuk riwayat perintah. Berkas kredensial yang ada tidak dibaca saat mengedit.

Untuk sumber GPG, pilih Buat baru atau Gunakan yang ada. Pembuatan menawarkan jalur bawaan privat; Enter menerimanya dan menyiapkan direktorinya (0700).

Tujuan lain harus berada di direktori yang sudah ada, milik Anda, dengan mode 0700. Jalur diperiksa sebelum pertanyaan kunci dan kata sandi.

Pembuatan lalu meminta sidik jari lengkap kunci publik lokal dan kata sandi dua kali. Berkas dan tautan simbolis yang ada tidak pernah ditimpa.

Jalur kredensial disimpan sebagai jalur absolut. /autoauth status menampilkan lokasi lengkap yang dikonfigurasi tanpa membaca isinya.

Enkripsi baru dimulai setelah Selesai, menjaga IRC responsif, dan tidak pernah memakai berkas sementara teks polos. Escape membatalkan pekerjaan tertunda.

Jika penyimpanan konfigurasi gagal, hasil enkripsi tetap tersedia untuk percobaan ulang yang disengaja; berkas yang dirujuk konfigurasi tersimpan dipertahankan.

Mode uji tidak menjalankan GPG atau membuat berkas kredensial. Buka kunci privat yang sesuai di luar aplikasi sebelum autentikasi.

Pilihan akhir panel server: 1 Simpan dan hubungkan, 2 Simpan saja (bawaan), 3 Hubungkan sekali, atau 4 Terapkan saja.

Membuka panel atau menjawab pertanyaan awalnya saja tidak menerapkan, menyimpan, atau menghubungkan apa pun.

Sambung sekali menerapkan tanpa simpan; Terapkan saja tidak menyimpan atau menyambung. Sambungan aktif tidak diam-diam mengganti tujuan atau menyambung ulang.

Sambungan gagal tidak membatalkan perubahan yang telah diterapkan atau disimpan lewat tindakan akhir.

Gunakan /quickstart untuk penyiapan server, transport, port, dan nama panggilan yang lebih singkat.

Contoh:

----------

Choose application-wide input, output and presence preferences
Penggunaan: /set send_mode direct|review | /set composer_mode line|fullscreen | /set output_format compact|full | /set queue_notices on|off | /set program_messages on|off | /set persistent_logging on|off | /set single_session on|off | /set default_interface idle|ncurses | /set command_suggestions alphabetical|common|history|frequent|contextual | /set part_message [TEXT] | /set quit_message [TEXT] | /set background_away on|off | /set background_away_message TEXT | /set autoaway_minutes 0..1440 | /set autoaway_message TEXT

composer_mode line memberi satu baris input di bawah chat terbaru; fullscreen memberi editor multi-baris dan panel chat terbaru. Bawaan: line.

part_message dan quit_message ialah alasan keluar IRC bawaan; pesan /part atau /quit eksplisit mengesampingkannya. Nilai kosong menonaktifkan teks bawaan.

background_away mengirim background_away_message setelah /background berhasil atau terminal terlepas. autoaway_minutes mengatur away saat diam; 0 mematikannya.

/unbind F7

/save input

/help /unignore
---------------

Remove one local ignore mask
Penggunaan: /unignore MASK

Setara dengan /ignore remove MASK. Simpan profil terpilih agar perubahan bertahan.

Contoh:
/unignore noisy!*@*

/help /unread
-------------

List unread conversations across servers
Penggunaan: /unread

Baris berisi nomor server, nama percakapan, pesan belum dibaca, dan jumlah sebutan.

Gunakan /server NUMBER lalu /channel atau /pm untuk memilih percakapan.

Contoh:
/unread
/server 1
/pm alice

/help /users
------------

Print the current or named channel's known users
Penggunaan: /users [#CHANNEL]

Ini daftar pengguna berupa teks, bukan pengalih visibilitas. Awalan mode pengguna disertakan jika diketahui.

Daftar terbuka di pembaca terpisah meski kosong. Enter, Escape atau q kembali ke log obrolan terpilih.

Up/Down dan Page Up/Down menggulir daftar. Dalam Help, Enter melanjutkan guliran.

Balasan NAMES yang belum lengkap atau melampaui kapasitas diberi label. Tidak ada permintaan WHOIS.

Contoh:
/users
/users #ircnow

/help /view
-----------

Select a named conversation or numbered channel
Penggunaan: /view NAME|NUMBER

Nomor kanal ada di /channels; nama percakapan pribadi di /ql. Nama server dan sebutan juga diterima.

Gunakan /help daripada memilih buffer panduan internal.

Contoh:
/view #ircnow
/view alice
/view 0

/help /views
------------

List channels (alias of /channels)
Penggunaan: /views

Alias ini memakai nomor kanal; percakapan pribadi tetap ada di /ql.

Contoh:
/views

/help /watch
------------

Manage extra literal mention strings
Penggunaan: /watch [list|add TEXT|remove TEXT]

Sebutan nama panggilan selalu aktif. Add/remove memperlakukan sisa teks secara harfiah, bukan ekspresi reguler.

Tiap server mendukung hingga 32 teks tambahan sepanjang 1..127 byte UTF-8. Gunakan /save agar tetap tersimpan.

Contoh:
/watch list
/watch add release day
/watch remove release day
/mentions

/help /whois
------------

Request nickname information from the server
Penggunaan: /whois NICK

Harus terdaftar. Membuka tampilan server agar balasan terlihat. Tidak ada perintah lokal yang dijalankan.

Contoh:
/whois alice

/help /znc
----------

Control the selected ZNC bouncer
Penggunaan: /znc [COMMAND]

Perlu profil ZNC tersambung yang diatur lewat /panel. Tanpa argumen, meminta Help dari *status.

COMMAND dikirim sebagai satu pesan pribadi berjarak, tanpa gema lokal atau riwayat perintah.

Gunakan /msg *module COMMAND untuk modul ZNC aktif. Balasan modul muncul di tampilan server.

Koneksi IRC langsung tidak dapat memakai pintasan ini. Lihat bantuan bouncer untuk perintahnya.

Contoh:
/znc
/znc ListNetworks
/znc Connect
