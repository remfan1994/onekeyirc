Paket bahasa opsional r52: vipirc-0.7.37

Terapkan hanya pada kode sumber Inggris r1 yang masih asli; jangan timpa r51 atau paket sebelumnya.
Masukkan nama host atau IP server IRC tanpa URL atau port. Untuk ZNC atau soju gunakan /panel.
Pilih none, file (berkas teks privat), gpg (berkas terenkripsi) atau plain (nilai tersembunyi di konfigurasi).
direct = kirim dengan satu Enter; review = tinjau catatan lalu konfirmasi dengan Enter kedua. Untuk semua server.
Nama panggilan atau pola nick!user@host.

  tar -xzf vipirc-0.7.37-english-source-r1.tar.gz
  tar -xzf vipirc-0.7.37-languages-r52.tar.gz
  sh vipirc-0.7.37-languages-r52/apply.sh vipirc-0.7.37
  cd vipirc-0.7.37
  ./configure && make
  VIPIRC_LANG=id ./vipirc --version
