HEADER GLOBAL DAN KENDALI OBROLAN

    F1 vipirc                Aplikasi, pengaturan, bantuan, About, dan lisensi.
    F2 Servers (N)           Sesi server tersimpan atau masih dipertahankan.
    F3 Channels (N)          Kanal tersimpan dari server yang dipilih.
    F4 Queries (N)           Percakapan pribadi pada server terpilih.
    F5 Mentions/unread (M/U) Penyebutan tersimpan / percakapan sumber belum dibaca.
    F6 File transfers (N)    Transfer tersimpan di seluruh server.

Hanya kategori yang berisi sesuatu yang ditampilkan; vipirc selalu tersedia. Kanal yang telah ditinggalkan tetapi masih memiliki riwayat, dan catatan transfer selesai, tetap dihitung. Nomor tombol fungsi tidak bergeser ketika kategori tersembunyi. Tombol pintas kategori tersembunyi tidak menciptakannya; perintah daftar eksplisit masih dapat membuka daftar kosong. TERM menentukan penafsiran tombol; tombol yang dicadangkan terminal harus diteruskan ke klien. Rangkaian yang ditempel tidak pernah mengaktifkan pintasan.

Percakapan memiliki baris tersendiri di bawah header; nama panggilan dalam query tidak menggantikan Queries. Header sempit tetap memperlihatkan kategori terpilih. Settings > Interface > Shortcut labels menyembunyikan label biasa F1..F6; tombol yang tidak terikat tetap berfungsi. Hints mengendalikan petunjuk opsional secara terpisah. Kedua preferensi milik profil utama dan membutuhkan Save agar bertahan.

Tombol panah mengoperasikan isi atau penyunting, bukan bilah atas. Escape dari query membuka Queries dengan query itu dipilih; dari obrolan lain membuka vipirc; dari panel biasa memulihkan obrolan/draf/kursor; Settings dan lisensi kembali ke vipirc. F1 langsung membuka vipirc. Dialog keselamatan dan penangkapan tempelan menerima masukan terlebih dahulu.

Dalam panel vipirc, b/Back kembali ke obrolan; Escape menanyakan Really quit? [Y/N]. Hanya y/Y baru yang mengonfirmasi. Tombol biasa lain membatalkan; tempelan, klik, dan perubahan ukuran tidak dapat mengonfirmasi. Perilaku interupsi/suspensi terminal dijelaskan pada TERMINAL SIGNALS.

Semua daftar menggunakan kendali serupa: Up/Down atau k/j memilih baris, Left/Right atau h/l memilih tindakan, Enter menjalankan. Home/End atau g/G memilih ujung daftar. Open dipilih pada awalnya; mengubah baris mempertahankan tindakan yang telah dipilih. Baris berhenti pada ujung daftar. Baris dan tindakan tetap disorot. Klik item untuk membukanya atau baris tindakannya untuk menjalankan tindakan pada pilihan. Delete menjalankan Close pada baris server/kanal/query dengan perlindungan dan konfirmasi biasa; dalam penyunting Delete menghapus teks.

Panah di obrolan menyunting teks, hjkl menjadi teks literal, Tab/Shift-Tab melengkapi nama panggilan, Page Up/Page Down menelusuri riwayat, dan / pada posisi kursor nol membuka Command. Enter mengirim; /clearinput mengosongkan seluruh draf. Mode mouse juga menampilkan Clear/Send di bawah kolom tetap. Kedua cara mengirim memakai pemeriksaan pesan yang sama. Tempelan obrolan dengan bracketed paste bersifat literal; tab menjadi spasi dan tempelan tidak pernah mengirim. Setelah tempelan berakhir, tombol/klik menunggu layar lengkap terlihat, batch masukan berikutnya, dan jeda tanpa aktivitas. Menahan tombol memperpanjang tunggu. Bingkai sangat kecil atau gagal tidak dihitung; ubah ukuran, lepaskan tombol, lalu bertindak. Daftar/pembaca/dialog keselamatan mengabaikan tempelan. Penyunting aktif di Command/Settings/transfer menerima data menurut aturannya masing-masing.
