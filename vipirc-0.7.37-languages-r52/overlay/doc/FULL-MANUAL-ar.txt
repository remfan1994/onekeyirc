===== SOURCE CHAPTER: READING EXAMPLES =====
كيفية قراءة الأمثلة

الأمثلة التي تبدأ بالكلمة vipirc تُنفَّذ في صدفة الأوامر (shell)، أما الأوامر التي تبدأ بعلامة / فتُدخل في Command. أدخل أمراً واحداً في كل مرة. في ملخصات الصياغة، الكلمات المكتوبة بأحرف كبيرة هي مواضع يجب استبدالها، وما بين [items] اختياري، وتفصل العلامة | بين البدائل.
عند فتح Command تكون العلامة / موجودة مسبقاً. قبل لصق أمر كامل يبدأ بـ / احذف العلامة المسبقة، وراجع النتيجة ثم اضغط Enter. كتلة الأوامر الملصقة ليست برنامجاً نصياً: تتحول فواصل الأسطر إلى مسافات. ويبقى ما يُلصق في chat/watch نصاً للمحادثة.

EXACT COMMAND/CONTROL EXAMPLES (not translated):
vipirc -h

vipirc --test-mode
vipirc --server irc.ircnow.org --channel '#ircnow' --nick tutankh-aten

تعرض الأمثلة الثلاثة الأولى المساعدة والإصدار وتبدأ محاكاة بلا اتصال. أما المثال الأخير فينشئ اتصالا حقيقيا: ضع '#ircnow' بين علامتي اقتباس في الصدفة، واستعمل نقطة TLS الصحيحة التي يقدمها مزود الخدمة. الإعداد الافتراضي هو TLS متحقق منه على المنفذ 6697، ويتطلب الاتصال بالنص المكشوف الخيار --plain.

عند التشغيل التفاعلي تظهر رسالة الترحيب "Not vegetarian? www.bloodguiltcurse.net will change your mind". يغلقها مفتاح يطبع حرفا أو Enter أو Tab أو مفتاح تنقل. تحتفظ إشارات الطرفية المهيأة بوظائفها الموروثة، ولا تغلقها أدوات التحكم الأخرى. إذا لم يحدد خادم، تفتح مساحة عمل غير متصلة. اضبط خادما من Settings أو باستعمال /connect HOST أو --server.

في الواجهة الكاملة، إذا لم يحدد اللقب الأساسي، يطلبه البرنامج ويقترح اسم تسجيل الدخول في النظام. يقبل Enter الاقتراح وتستبدله الكتابة. تستخدم الملفات الشخصية الثانوية المحفوظة والتشغيل غير التفاعلي اسم دخول أو مستخدم صالحا دون سؤال. يتجاوز --nick هذه القيمة، لكن الخادم قد يرفض اللقب.

تعرض نافذة الخادم الأولى التسجيل ورسالة MOTD. تنضم الملفات الشخصية المباشرة إلى القنوات المعدة بعد التسجيل والمصادقة المطلوبة، بينما يستعيد خادم الوساطة bouncer عضوياته الخاصة. يكون حقل المحادثة جاهزا للكتابة. يرسل Enter إلى القناة أو المحادثة الخاصة المحددة؛ ولا يوجد مستلم ضمني لنافذتي الخادم والإشارات إلى المستخدم. يفتح / عند موضع المؤشر صفر واجهة Command. لإدخال شرطة مائلة أولى بوصفها نصا، استخدم //؛ وتبقى الشرطات المائلة الملصقة داخل أقواس نصا حرفيا.

المفاتيح المعتادة: يفتح F1 لوحة vipirc، وF2 قائمة Servers، وF3 قائمة Channels، وF4 قائمة Queries، وF5 قائمة Mentions/unread، وF6 قائمة File transfers. ينقل Escape من المحادثة الخاصة إلى Queries، ومن غيرها إلى vipirc، ومن لوحة عادية إلى المحادثة، ومن Settings إلى vipirc. تحافظ الواجهة على ألوان الطرفية وتبين الأقواس المربعة الغليظة موضع التركيز. راجع GLOBAL HEADER AND CHAT CONTROLS للتنقل بين القوائم.

===== SOURCE CHAPTER: GETTING HELP =====
EXACT COMMAND/CONTROL EXAMPLES (not translated):
vipirc -h
vipirc -v
vipirc --manual
vipirc -i --manual
man vipirc
/help
/manual
/help TEXT

يعرض vipirc -h أو --help ملخص سطر الأوامر؛ ويعرض vipirc -v أو --version رقم الإصدار. يطبع vipirc --manual الدليل الكامل على المخرج القياسي؛ ويطبع vipirc -i --manual مرجع المواضيع والأوامر للواجهة المبسطة. يفتح man vipirc صفحة الدليل المثبتة. في الواجهة الكاملة يفتح /help أو /manual هذا الدليل، ويبحث /help TEXT فيه عن TEXT.

في الوضع الكامل يبحث /help TEXT داخل الدليل ولا يفتح مواضيع المساعدة المبسطة. يوصل /help commands و/help ls إلى قسم COMMAND PROMPT؛ ويفتح /help all الدليل كله؛ ويعمل /view help أيضا. لا تحتاج عبارات البحث إلى اقتباس. يعمل القارئ دون اتصال ويحفظ النافذة والمسودة وموضع المؤشر. هنا يبدأ / البحث؛ أما في قارئ المساعدة أو النتائج المبسط فيفتح / واجهة Command. للتحقق من الأعطال بحسب الأعراض راجع doc/TROUBLESHOOTING.txt.

اضغط ? أثناء التنقل لشرح العنصر والشاشة المحددين. تتضمن المساعدة السياقية رابط About؛ يختار Left/Right أو Tab إجراء، وينفذه Enter، ويعيد Escape إلى الشاشة والعنصر الأصليين بدقة. داخل حقل قابل للتحرير يبقى ? حرفا عاديا. اختر اقتراح Command أولا ثم اطلب مساعدته.

إجراءات الدليل هي Back وSearch وPrevious وNext. يختار Left/Right أو h/l، وينفذ Enter. يمرر Up/Down أو k/j سطرا، وPage Up/Down صفحة، وينتقل Home/End أو g/G إلى البداية والنهاية. يعيد Escape/q/Back إلى لوحة vipirc أو المحادثة السابقة. تفتح F1..F6 الفئات المتاحة، ولا تشمل دورة تبديل النوافذ الدليل. يحرر / أو Search طلب بحث UTF-8 حرفيا بطول أقصاه 256 بايت. يبدأ Enter البحث ويلغيه Escape أثناء تحرير الطلب. يتنقل n/Next وN/Previous بين النتائج مع العودة من النهاية إلى البداية. يتجاهل البحث اختلاف حالة أحرف ASCII ويطابق غيرها حرفيا. لا توجد تعبيرات منتظمة ولا صياغة صدفة ولا سجل للبحث. يتجاهل القارئ ولصق البحث النص الملصق.

تضم F1 الخيارات Server وNick وSettings وManual وCommand وBackground وAbout واتفاقية ترخيص Insha-Allah. يفتح Server/Nick إعدادات الملف الحالي، ويركز Nick على حقل اللقب. يعرض About الإصدار والمساهمين ولقطة محلية عند الطلب تشمل PID ومدة التشغيل ومجاميع CPU وذروة الذاكرة المدعومة وأعداد الخوادم والنوافذ. ذروة الذاكرة ليست الاستهلاك الحالي، ومجاميع CPU ليست نسبة لحظية. يعرض قارئ الترخيص ملف LICENSE.md كاملا. يعيد Escape/Enter/q/Back من About أو الترخيص إلى vipirc.

===== SOURCE CHAPTER: MINIMALIST INTERFACE =====
الواجهة المبسطة

    vipirc -i
    vipirc --idle --test-mode
    /connect irc.ircnow.org
    /join #ircnow
    /saveconf

يستخدم الخيار -i إعدادات vipirc نفسها ودليل الخوادم نفسه. ويكون الاسم المستعار افتراضيا اسم دخول أو اسم مستخدم صالحا. يحفظ الأمر /saveconf التفضيلات والملفات التعريفية السليمة، ويتذكر الاتصال المحدد، بما فيه الملف الثانوي، ليستعمله أمر /connect التالي إذا كتب دون وسيطات. لا يؤدي الحفظ إلى تفعيل الاتصال التلقائي. ويعد /quickstart و/panel دليلين اختياريين.

السجل هو الشاشة المعتادة. يفتح / شاشة Command، وتفتح ? المساعدة السياقية، أما المحارف الأخرى القابلة للطباعة فتبدأ Compose وتبقى في المسودة. يفتح Enter أو Insert شاشة Compose فارغة. في السجل المباشر، يرجع Up صفا محفوظا إلى الوراء، وPage Up صفحة، وينتقل Home إلى أقدم صفحة محتفظ بها؛ أما Down/Page Down/End فتبقى عند نهاية السجل المباشر. لا تعمل Left/Right/Delete/Backspace في هذه الحالة. وفي قارئ السجل السابق، يعيد End أو Escape العرض المباشر.

تعدل مفاتيح الأسهم النص في Compose ولا تسترجع رسائل المحادثة المرسلة. تكمل Tab/Shift-Tab الأسماء المستعارة في Compose وأسماء الأوامر في Command. يحدد Down الاقتراحات في Command، وتتنقل Up/Down بينها، ويعيد Up من أول اقتراح إلى سطر الإدخال. يدرج Enter الاقتراح المحدد، ويلزم ضغط Enter آخر بعد ظهوره لتنفيذ الأمر. يسترجع Up من سطر Command الأوامر المقبولة المطابقة؛ ويعود Down تدريجيا إلى المسودة الأصلية. راجع /help keys و/help commands لمعرفة جميع عناصر التحكم.

يحافظ وضع المحرر أحادي السطر على صف إدخال واحد أسفل نهاية السجل المباشر؛ ويوفر وضع fullscreen محررا متعدد الأسطر مع جزء أصغر للسجل المباشر. لا يؤدي تحديث الشاشة بسبب حركة الشبكة إلى فقد المسودة أو موضع المؤشر. يخرج Escape من المحرر إلى السجل، ويضع Escape في السجل العملية في الخلفية. وفي Review يعيد Escape أو بدء الكتابة المحرر والمسودة والمؤشر نفسها، بينما يؤكد ضغط Enter جديد الإرسال. لا يعمل Ctrl-D ما لم يربط صراحة بوظيفة؛ وتتبع إشارات الطرفية إعداداتها الموروثة. ويظل اللصق المعترف به نصا حرفيا ولا يستطيع إرسال رسالة.

    /set send_mode direct|review
    /set composer_mode line|fullscreen
    /set output_format compact|full
    /save input
    /save output

الافتراضي هو الإرسال المباشر والتحرير في سطر واحد والعرض المختصر [HH:MM:SS] <nick> text. ويتضمن عرض full التاريخ والخادم والوجهة؛ وتحتفظ الإشارات إلى المستخدمين والتشخيصات العابرة للخوادم بالسياق اللازم في كلا التنسيقين. تخص هذه التفضيلات الملف الرئيسي وتسري على جميع الخوادم. ويبقى مطلوبا الإقرار المستقل بحد البايتات والموافقة على إرسال رسائل متعددة.

يسرد /help ls الموضوعات، ويشرح /help /ls أمر القوائم المحلي. استخدم /help COMMAND للصياغة والأمثلة، مع موضوع واحد أو اسم أمر واحد في كل مرة. يقدم /manual وvipirc -i --manual المرجع الكامل للواجهة المبسطة، وهو موجود أيضا في doc/vipirc-idle-manual.txt. تختلف الأوامر وعناصر التحكم عن واجهة ncurses الكاملة. تستخدم المساعدة ونتائج الأوامر الطويلة قارئا منفصلا ذا حدود. تعمل الأسهم وPage Up/Page Down/Home/End للتمرير، ويعود Escape إلى الشاشة السابقة. يمرر Enter صفحات المساعدة لكنه يغلق قائمة /users الناجحة. ويفتح / شاشة Command من القارئ، وتعيد الإلغاء إلى القارئ. تحل نتيجة الأمر الجديد محل الاستجابة السابقة. يحدث المفتاح r في Summary اللقطة الحالية. وتستمر الشبكة في العمل أثناء القراءة.

يبدأ /panel بالقسم 0 Application preferences الذي يشمل السجل وأوضاع الإرسال والتحرير والمخرجات والإشعارات والتسجيل ووضع الجلسة الواحدة واقتراحات الأوامر والواجهة الافتراضية. يعرض في النهاية Save أو Apply without saving؛ ولا ينشئ اتصالا ولا يغير المحادثة. ترقم الواجهتان لوحات الملفات التعريفية 1..8: تعدل اللوحة 1 الملف الرئيسي المسمى server 0 في الوضع الكامل و1 في الوضع المبسط. تعدل هذه اللوحات إعدادات كل خادم، بما فيها هوية bouncer. وفي النهاية تتاح Save and connect وSave only (الافتراضي) وConnect once وApply only. يسأل /quickstart عن الخادم وTLS والمنفذ والاسم المستعار، ويختار Connect once افتراضيا؛ ولا يغير بيانات دخول bouncer القائمة.

يحافظ Enter على الإجابة المعروضة، ويمسح '-' الحقول الاختيارية. يعود Escape خطوة إلى الوراء أو يخرج من السؤال الأول. تحدد Tab عنوانا لطلب المساعدة ?، ثم تستأنف Tab/Enter التحرير. لا تدخل كلمات المرور والإجابات المخفية في سجل الأوامر أبدا. الخيار الأخير وحده يطبق الإعدادات أو يحفظها أو يتصل؛ ولا يعيد توجيه اتصال نشط، كما أن فشل اتصال لاحق لا يلغي تغييرات تمت صراحة. تدعم واجهة vipirc الكاملة هذه الخطوات أيضا؛ ويفتح /settings فيها النموذج الرسومي.

يستخدم /servers في الوضع المبسط الأرقام 1..8، وفي الوضع الكامل الأرقام 0..7. وتمثل Channel 0 شاشة الخادم/MOTD في الواجهتين. يحد إعداد السجل الرئيسي من مقدار السجل الداخلي المحتفظ به عبر جميع المحادثات وفقا للحدود الصارمة المبينة في /help history. ويكون التسجيل الاختياري بنص عادي معطلا افتراضيا. يستخدم DCC أوامر /dcc الصريحة المشتركة دون نماذج رسومية.

===== SOURCE CHAPTER: DEFAULT INTERFACE =====
الواجهة الافتراضية

لحفظ اختيار الواجهة المبسطة، نفّذ الأمرين التاليين من أي واجهة:

    /set default_interface idle
    /save input

يمكن أيضاً استعمال Settings > Interface > Default interface أو /panel > 0. وبدلاً من ذلك، ضع default_interface=idle في قسم [session] الموجود في ملف الإعداد الرئيسي مع الإبقاء على المفاتيح الأخرى. الخيار الافتراضي عند عدم تحديد شيء هو ncurses. يؤثر هذا التفضيل في التشغيل الجديد، بما فيه --background، لكنه لا يبدّل الواجهة الحالية ولا يعيد اتصال IRC.

يختار -i/--idle أو -N/--ncurses الواجهة صراحةً لهذا التشغيل فقط؛ ويسري آخر خيار، ولا يجعل حفظ إعداد غير مرتبط هذا الاختيار دائماً. يظل -n/--nick بحرف n الصغير خيار تحديد الاسم المستعار. لاستعادة الواجهة الكاملة افتراضياً، نفّذ /set default_interface ncurses ثم /save input. لا تملك ملفات تعريف الخوادم الثانوية هذا التفضيل.

يحافظ --resume دون خيار واجهة على واجهة العملية العاملة الموجودة. يطلب -i --resume NUMBER الواجهة المبسطة، ويطلب -N --resume NUMBER واجهة ncurses، من دون إعادة الاتصال أو استبدال العملية العاملة. تحتفظ العمليات القديمة التي لا تدعم التبديل بواجهتها. يؤدي التبديل إلى فقدان المسودات وسجل استدعاء الأوامر الخاصين بالواجهة؛ راجع RUNNING IN THE BACKGROUND. يستخدم onekeyirc واجهته المبسطة دائماً ويرفض -N/--ncurses. قبل التبديل.

===== SOURCE CHAPTER: MINIMALIST WRAPPING AND INPUT HISTORY =====
التفاف الأسطر وسجل الإدخال في الواجهة المبسطة

يحجز Compose أسطراً للإدخال، ويعرض فوقها أحدث الأسطر المرئية بعد التفاف النص؛ وقد تغادر الأسطر الأقدم نافذة العرض الأصغر. لا يُختصر النص المخزّن ولا خطط الإرسال. اخرج من الإدخال أو اختر المحادثة من جديد لفحص الأسطر المحتفظ بها؛ فظهور نسخة محلية من الرسالة لا يثبت وصولها. ويُعاد حساب التخطيط عند تغيير حجم الطرفية مع الحفاظ على المسودة وموضع المؤشر.

تحرّك مفاتيح أعلى/أسفل المؤشر في Compose حتى عند إبقائها مضغوطة. ولا يستدعي الأوامر المقبولة سابقاً إلا مفتاح أعلى في Command؛ فلا تُستعاد رسائل الدردشة المرسلة أو سطور الخدمات الحساسة أو أوامر الانضمام بمفتاح قناة. لا يحتوي ملف .commands إلا على أسماء الأوامر وأعداد استخدامها. راجع COMMAND PROMPT وINPUT EDITING وTROUBLESHOOTING.

===== SOURCE CHAPTER: MINIMALIST CATCH-UP AFTER RESUME =====
استدراك الرسائل بعد استئناف الجلسة في الواجهة المبسطة

في vipirc -i يفتح الأمر /catchup القناة أو المحادثة الخاصة المحددة عند أول سطر IRC من أحدث رسالة أنشأتها وأرسلتها محليا. لكل خادم ولكل قناة أو محادثة خاصة علامة مرجعية مستقلة، ولا توجد علامات مرجعية لعرض حالة الخادم أو عرض الإشارات إليك. بعد استئناف الجلسة، حدد كل محادثة ونفذ /catchup فيها على حدة.

يحاول القارئ أولا استخدام سجل خاص مستوف للشروط. يجب أن يكون التسجيل الدائم مفعلا عند إرسال الرسالة المرجعية، وأن يستمر في العمل بصورة سليمة، وأن يبقى السجل نفسه محتفظا بذلك القيد بعينه في الملف ذاته. فعله عمدا قبل مغادرتك:

    /set persistent_logging on
    /save output

يلتقط قارئ القرص صورة ثابتة لنهاية الملف الحالية، بدلا من تحميل كل ما حدث أثناء الغياب في ذاكرة المحادثة الدائمة. يتحرك Up/Down سطرا مرئيا واحدا، وينتقل PageUp/PageDown صفحة واحدة؛ ويعود Home إلى علامة الرسالة المرسلة، ويصل End إلى أحدث صفحة في الصورة الثابتة، ويعيد Escape العرض إلى المحادثة المباشرة. تواصل رسائل الشبكة الجديدة الوصول من دون تحريك الصورة الثابتة.

إذا لم تعد علامة القرص متاحة ولكن الرسالة المرسلة ما زالت محفوظة في الذاكرة، يفتح الأمر سجل التمرير العادي المحفوظ عند تلك العلامة. في وضع الرجوع هذا، يصل Home إلى أقدم صفحة لا تزال محفوظة، ويعود End أو Escape إلى المحادثة المباشرة، ويمكن أيضا تصفح الرسائل الأقدم التي بقيت في الذاكرة. هذا هو قارئ الذاكرة المعتاد بحدود الاستبعاد المعتادة، وليس أرشيفا مستعادا من القرص.

لا يصلح ملف سجل جرى تدويره أو استبداله، ولا قيد مرجعي تغير محتواه، لاستعادة علامة القرص الأصلية. يكشف فحص القيد التغييرات العرضية، لكنه لا يثبت أصالة البيانات في مواجهة عملية أخرى تعمل بحساب المستخدم نفسه. لا تستخدم رسائل المصادقة الحساسة علامات مرجعية طويلة الأمد. إذا لم تبق علامة مستوفية للشروط على القرص أو في الذاكرة، يشرح /catchup نقص السجل بدلا من الادعاء بأن الاستدراك اكتمل.

تخص العلامة العملية العاملة الجارية. إن فصل الجلسة ثم استئنافها يحافظ على العلامة؛ أما بدء عملية جديدة فلا يعيد بناء العلامات ولا يحمّل ملفات المحادثات القديمة تلقائيا. يتاح /catchup المعتمد على القرص في الواجهة المبسطة فقط، بينما تحتفظ واجهة ncurses الكاملة بسجل محدود في الذاكرة يمكن تصفحه بواسطة PageUp/PageDown.

===== SOURCE CHAPTER: COMMAND-LINE OPTIONS =====
خيارات سطر الأوامر

-i, --idle: اختيار الواجهة المبسطة لهذا التشغيل؛ يشرح --help و--manual هذا الوضع.
-N, --ncurses: اختيار الواجهة الكاملة لهذا التشغيل. يسري آخر خيار صريح للواجهة، من دون تغيير الافتراضي المحفوظ؛ ويظل -n خاصاً باللقب.
-s, --server HOST: اختيار الخادم الأساسي باسم المضيف أو عنوان IPv4/IPv6 رقمي، وليس بعنوان URL.
-p, --port PORT: رقم المنفذ من 1..65535. الافتراضي 6697 مع TLS، أو 6667 عند اختيار IRC غير المشفر صراحة.
-c, --channel LIST: قائمة قنوات الانضمام التلقائي بعد التسجيل لملف اتصال مباشر. تقبل قوائم مفصولة بفواصل أو تكرار الخيار. ضع '#channel' بين علامتي اقتباس في الصدفة؛ أما bouncer فيستعيد عضوية قنواته بنفسه.
-n, --nick NICK: تجاوز لقب ملف الاتصال الفعلي عند بدء التشغيل.
-C, --config FILE: اختيار ملف الإعداد الرئيسي مع فهرس .servers ودليل الملفات الشخصية .d. يجب وجود الملف إلا إذا أنشأه --init-config؛ تُفسر المسارات حرفياً.
--tls: اشتراط TLS المتحقق منه، وهو الافتراضي. ذكر المنفذ وحده لا يعطل TLS.
--plain: اختيار اتصال بنص غير مشفر صراحة؛ تُرفض المصادقة باستخدام بيانات الاعتماد المخزنة.
--ca-file FILE: استخدام سلطات شهادات PEM مخصصة بدلاً من مخزن الثقة للنظام. يلزم ملف عادي غير فارغ لا يزيد عن 16 MiB؛ وتُقبل الوصلة الرمزية المعتادة. لا تظهر مطالبة بكلمة مرور.
--no-connect: منع كل اتصالات البدء والمحاكاة؛ اتصل صراحة لاحقاً.
--background: بدء عملية عامل منفصلة بلا tty أو TERM أو ضغطة مفتاح الترحيب. تُستخدم الواجهة الافتراضية المحفوظة ما لم يتجاوزها -i/-N. احفظ ملفات الاتصال التلقائي أو قدم --server؛ ويعلو --no-connect عليهما. النجاح يعني اكتمال الإعداد المحلي لا نجاح تسجيل الدخول إلى IRC.
--reconnect: إعادة المحاولة عند إخفاقات الشبكة المؤقتة لهذه العملية فقط، دون بدء اتصال أو حفظ تفضيل. فترات الانتظار 5,10,20,40,80,160,300 ثانية؛ تعيد 60 ثانية متصلة في حالة التسجيل التسلسل إلى بدايته. يلغي /disconnect المحاولات ويستأنفها /connect. تبقى أخطاء الشهادة والمصادقة والإعداد والبروتوكول غير متصلة. تُسقط الرسائل المنتظرة. عند اتصال جديد تتكرر المصادقة وأوامر البدء؛ تعيد الملفات المباشرة autojoin بينما يستعيد bouncer عضوية القنوات. تتطلب إعدادات الاتصال المعلقة أمر /connect صريحاً في حالة الانفصال.
--test-mode: محاكاة تفاعلية دون اتصال أو شبكة أو DNS أو قراءة بيانات اعتماد أو حفظها.
--resume [JOB]: إرفاق المهمة المنفصلة الوحيدة التي جرى التحقق منها، أو اختيار رقمها؛ ويُقبل --resume=JOB. تدعم مسارات المقابس المطلقة الصريحة عمليات العامل الأقدم المتوافقة. الاستئناف بلا رقم يحتفظ بواجهتها؛ ويطلب -i/-N واجهة أخرى. يجب أن تستخدم stdin وstdout وstderr طرفية tty تفاعلية واحدة. تعدد المهام أو عدم التحقق يمنع الاختيار التلقائي، والمهمة المرفقة بالفعل مشغولة.
--sessions: عرض مهام الحساب المرفقة والمنفصلة بلا tty أو تحميل للإعدادات.
--detach-session NUMBER: تحرير المتحكم المتحقق منه مع إبقاء العامل وحالته، ثم استئنافه بواسطة --resume NUMBER. كما يُقبل --detach-session=NUMBER.
--close-session NUMBER: إنهاء العامل كله بما فيه جلسات IRC والنقل والمسودات والتاريخ في الذاكرة. تظل ملفات الإعداد والسجلات. يلزم التحقق من التنظيف قبل إعلان النجاح؛ وقد ينتهي حد الانتظار قبل اكتمال الإنهاء، لذا أعد فحص --sessions. ويُقبل --close-session=NUMBER.
--init-config: إنشاء ملف إعداد خاص دون استبدال الموجود أو الملفات المنشأة بالتزامن. قد يبقى الملف المكتمل رغم الإبلاغ عن خطأ في المزامنة أو التنظيف.
--check-config: التحقق من الإعداد والتجاوزات والفهرس والملفات المحفوظة ثم الخروج. لا يفتح الأسرار ولا يشغّل GPG ولا يختبر CA/TLS ولا يثبت الوصول أو تسجيل الدخول.
--manual: طباعة الدليل الكامل للواجهة المختارة من دون طرفية.
-h, --help: طباعة مساعدة CLI من دون طرفية.
-v, -V, --version: طباعة الإصدار والنسبة والترخيص من دون طرفية.

تقبل الخيارات الطويلة صيغة --name=value، ويمكن تجميع الخيارات القصيرة بالطريقة المعتادة. تنهي -- قائمة الخيارات؛ ولا تُستخدم وسائط موضعية. تتقدم قيم CLI على الإعداد المحفوظ، ثم القيم الافتراضية. عند البدء العادي تُطبق التجاوزات غير المتعلقة بالمضيف على الملف الافتراضي المتذكر؛ ويختار --server الصريح الملف الأساسي. يعمل --init-config/--check-config على الأساسي. إذا تعذر العثور على الافتراضي المتذكر، أصلحه أو حدد --server قبل تجاوز الحقول الأخرى.

إذا كان --server يشير إلى مضيف مختلف دون اعتبار لحالة الأحرف، تُمسح مصادر الاعتماد والمصادقة وCA المخصصة وهوية bouncer وخيار الغياب التلقائي والقنوات وأوامر البدء الموروثة. أعد ضبط المضيف الجديد صراحة. تحفظ التجاوزات للمضيف نفسه أو --nick وحده إعدادات الملف. يختار --config مختلف مساحة عمل منفصلة.

--resume و--sessions و--detach-session و--close-session عمليات إدارة مستقلة: لا تدمجها بعضها ببعض أو مع خيارات الإعداد والاتصال والبدء. يمكن أن تبقى أعلام الواجهة المدعومة في اسم مستعار. لا يُجمع --background مع تلك العمليات أو --init-config أو --check-config، ولا يُجمع --test-mode مع --init-config/--check-config (رمز خطأ الاستخدام 2).

===== SOURCE CHAPTER: OFFLINE TEST MODE =====
EXACT COMMAND/CONTROL EXAMPLES (not translated):
vipirc --test-mode
vipirc --test-mode --config /absolute/config.ini --no-connect

تستخدم المحاكاة الواجهة الحقيقية والمحرر والمرشحات ومعالجة البروتوكول والطوابير ذات الصلة، ولكن دون مقابس شبكة أو DNS أو قراءة كلمات مرور وملفات CA أو GPG أو حفظ. أسماء المضيفين المعدة مجرد تسميات. لكل ملف شخصي محاك مستقل، ويضيف New server محاكيا آخر. لا يطلب البرنامج الخادم أو اللقب الناقصين؛ وإذا لم تهيأ قنوات تكون قناتا التجربة الافتراضيتان #test-one و#test-two.

تبدأ المحاكاة بعد الترحيب بصرف النظر عن autoconnect المحفوظ؛ ويمنع --no-connect بدءها. يوقف /disconnect المحاكي المحدد ويبدأه /connect. للشبكة الحقيقية اخرج وأعد التشغيل دون --test-mode. لا يحتاج المحاكي المحلي المكتوب بلغة C إلى خدمة خارجية أو Python.

تقع أحداث كل ثانيتين: رسائل محادثة وإشارات إلى المستخدم وسلاسل مراقبة ومحادثة خاصة وتغييرات قائمة الأعضاء. تتناوب سلاسل watch المخصصة بمعدل واحدة في كل دورة طولها 16 ثانية. يولد /msg ردا محاكيا يحمل علامة توضح ذلك، وكذلك JOIN/PART/NICK/WHOIS/TOPIC/AWAY. ولا تحاكي هذه الوظيفة كل قواعد الخادم أو قبول القنوات المحمية بمفتاح أو SASL أو التسليم الفعلي.

جرب التفاف السطور والتحرير بين السطور وتغيير حجم الشاشة واللصق والتحذيرات والتأكيدات والإشارات والقوائم. عرض DCC التجريبي موجود في الذاكرة فقط: تعمل المعاينة والرفض والإلغاء، لكن Send/Accept مرفوض قبل أي وصول إلى ملف أو مقبس. إغلاق خادم ثانوي لا يغير إلا حالة التشغيل. الكتابة إلى الإعدادات وملفات العدادات معطلة؛ عدل الإعدادات خارج التطبيق وأعد التشغيل لأي تغيير دائم.

يفحص --check-config على نحو مستقل صياغة الملفات المحفوظة وقيمها. ولا يثبت أي من الوضعين عمل DNS أو TLS أو بيانات الاعتماد أو التوافق الحقيقي مع bouncer.

الشريط العلوي العام والتحكم في المحادثة

    F1 vipirc                التطبيق والإعدادات والمساعدة وAbout والترخيص.
    F2 Servers (N)           جلسات الخوادم المعدة أو المحفوظة.
    F3 Channels (N)          القنوات المحفوظة للخادم المحدد.
    F4 Queries (N)           المحادثات الخاصة للخادم المحدد.
    F5 Mentions/unread (M/U) الإشارات المحفوظة / المحادثات الأصلية غير المقروءة.
    F6 File transfers (N)    سجلات النقل المحفوظة عبر جميع الخوادم.

تظهر الفئات التي تحتوي على عناصر فقط، وتبقى vipirc ظاهرة دائما. وتظل القنوات التي غادرتها ولها سجل، وكذلك سجلات النقل المكتمل، محسوبة. لا تتغير أرقام مفاتيح الوظائف الثابتة عندما تختفي فئات. ولا ينشئ اختصار فئة مخفية تلك الفئة؛ ويمكن لأوامر القوائم الصريحة فتح قوائم فارغة. يحدد TERM طريقة تفسير المفاتيح؛ ويجب تمرير المفاتيح التي تحجزها الطرفية إلى العميل. ولا تفعل التسلسلات الملصقة أي اختصارات.

للمحادثة صف خاص تحت الشريط العلوي؛ ولا يحل الاسم المستعار في المحادثة الخاصة محل Queries. وتحافظ الأشرطة الضيقة على ظهور الفئة المحددة. يخفي Settings > Interface > Shortcut labels تسميات F1..F6 المعتادة؛ وتبقى المفاتيح غير المربوطة عاملة. ويتحكم Hints في الإرشادات الاختيارية على حدة. تخص التفضيلات الملف الرئيسي وتتطلب Save لتبقى بعد إعادة التشغيل.

تعمل مفاتيح الأسهم في محتوى الشاشة أو المحرر، لا في الشريط العلوي. يفتح Escape من المحادثة الخاصة قائمة Queries مع تحديد تلك المحادثة؛ ويفتح من المحادثات الأخرى vipirc؛ ويعيد من اللوحات العادية المحادثة والمسودة والمؤشر؛ وتعود Settings وشاشة الترخيص إلى vipirc. ويفتح F1 شاشة vipirc مباشرة. تعالج مربعات تأكيد السلامة والتقاط اللصق الإدخال أولا.

في لوحة vipirc يعيد b/Back إلى المحادثة، ويسأل Escape: Really quit? [Y/N]. لا يؤكد الخروج إلا ضغط جديد على y/Y. تلغي المفاتيح العادية الأخرى العملية؛ ولا يمكن للصق أو النقر أو تغيير الحجم تأكيدها. وتتبع إشارات المقاطعة والإيقاف المؤقت قواعد TERMINAL SIGNALS.

تتشابه عناصر التحكم في القوائم: تختار Up/Down أو k/j صفا، وتختار Left/Right أو h/l إجراء، وينفذه Enter. وتنتقل Home/End أو g/G إلى الأطراف. يكون Open محددا في البداية، وعند تبديل الصف يبقى الإجراء المختار. ويتوقف تحديد الصف عند حدود القائمة. يبقى الصف والإجراء مظللين معا. انقر على عنصر لفتحه أو على صف إجراءاته لتنفيذ الإجراء على الاختيار. يستدعي Delete الإجراء Close في صفوف الخوادم والقنوات والمحادثات الخاصة مع الحماية والتأكيد المعتادين؛ ويحذف النص داخل المحررات.

تعدل الأسهم النص في المحادثة، وتكتب hjkl نصا حرفيا، وتكمل Tab/Shift-Tab الأسماء المستعارة، وتستعرض Page Up/Page Down السجل، ويفتح / شاشة Command عندما يكون المؤشر في الموضع صفر. يرسل Enter الرسالة؛ ويمسح /clearinput المسودة كاملة. ويعرض وضع الفأرة أيضا Clear/Send أسفل حقل الإدخال الثابت. يخضع مسارا الإرسال للفحوص نفسها. يكون لصق المحادثة المحدد بنمط bracketed paste حرفيا؛ وتتحول علامات الجدولة إلى مسافات ولا يؤدي اللصق إلى الإرسال. وبعد انتهاء اللصق تنتظر المفاتيح والنقرات ظهور شاشة كاملة، ودفعة إدخال لاحقة، وفترة هدوء. ويزيد استمرار الضغط على المفاتيح مدة الانتظار. لا تحتسب الإطارات الصغيرة جدا أو التي فشل رسمها؛ غير حجم النافذة ثم ارفع الضغط عن المفاتيح قبل التصرف. تتجاهل القوائم والقارئات ومربعات السلامة اللصق. وتقبل محررات Command وSettings والنقل النشطة البيانات وفقا لقواعد كل منها.

إكمال الأسماء المستعارة

يكمل Tab الاسم المستعار الموجود عند مؤشر الدردشة. وتنتقل ضغطات Tab اللاحقة دورياً بين الأسماء المطابقة بالترتيب الأبجدي وفق قواعد حالة الأحرف؛ وينتقل Shift-Tab إلى الخلف. تجري المطابقة وفق قواعد ASCII أو strict RFC1459 أو RFC1459 التي يعلنها الخادم. لا يحتاج ذلك إلى استعلام شبكي أو إرسال رسالة. وينهي التحرير العادي دورة الإكمال الجارية.

في بداية المسودة يُضاف ': '، وبعد كلمة لاحقة تُضاف مسافة. إذا جرى الإكمال داخل مسودة، تبقى علامات الترقيم والكلمات التالية كما هي. لا تُفسَّر القنوات وعناوين URL على أنها بادئات أسماء مستعارة. إذا كان المرشح سيتجاوز حد البايتات أو المحارف، تُترك المسودة كلها دون تغيير. وإذا تجاوز الميزانية الأصغر لرسالة IRC، يظهر التحذير المبكر المعتاد؛ ولا يرسل الإكمال أي رسالة.

تستخدم القناة قائمة أعضائها الحالية. وتستخدم المحادثة الخاصة اسم الطرف الآخر واسمك المستعار. وتستخدم عرضا الخادم والإشارات الأشخاص المعروفين من القنوات المنضم إليها والمحادثات الخاصة على هذا الخادم. لا تُقترح أسماء مستخدمي خوادم أخرى. تسري تغييرات الأعضاء عند الإكمال التالي من دون تخزين قائمة مستخدمين إضافية.

===== SOURCE CHAPTER: COMMAND PROMPT =====
موجّه الأوامر

افتح Command من F1 > Command أو باستعمال /، أو بكتابة / حين يكون مؤشر الدردشة عند الموضع صفر. تبقى مسودة الدردشة ومؤشرها مستقلين ومحفوظين. الشرطة المائلة في موضع آخر أو ضمن لصق الدردشة المحمي تُعد نصاً حرفياً. ينفذ Enter/Run إرسال الأمر، ويعيد Escape/Cancel إلى الشاشة التي فتحت Command، بما فيها Summary. الإدخال الفارغ لا يفعل شيئاً. تعود الأوامر المقبولة إلى الدردشة ما لم تفتح شاشة أخرى؛ وتبقى الأوامر غير الصحيحة أو المرفوضة قابلة للتعديل.

توفر Settings > Interface > Command suggestions خمسة ترتيبات: Commonly used (قائمة منتقاة افتراضياً تتغير مع حالة الاتصال والواجهة)، Recent history (أسطر أوامر كاملة مقبولة، الأحدث أولاً)، Most used (عدد مرات الأوامر القياسية في الملف المحفوظ)، Alphabetical (أسماء الأوامر المنفذة)، وContextual (تقديم نتائج الشاشة التي فتحت Command مع إبقاء المطابقات الأخرى).

اكتب بادئة اسم الأمر دون اعتبار لحالة الأحرف لتصفية المقترحات؛ ولا يُتنبأ بالوسائط. يختار Down المقترحات، ويتنقل Up/Down بينها؛ ويعيد Up من أول سطر إلى الإدخال. إن Enter على مقترح يُدرجه فقط ولا ينفذه: يحتفظ اختيار الفهرس بالوسائط الموجودة، بينما يُدرج اختيار التاريخ السطر كله. راجعه وعدله ثم اضغط Enter بصورة منفصلة بعد ظهوره. لا يمكن لضغطات Enter الإضافية في دفعة الإدخال نفسها تشغيله. تفتح ? على مقترح محدد المساعدة ثم تعيد الاختيار؛ أما ? في حقل الإدخال فهي حرفية.

يحذف Delete سطر Recent المحدد أو يعيد عداد Most used إلى الصفر، ولا يحذف أمراً مدعوماً. يتنقل Page Up/Page Down أو عجلة الفأرة في المقترحات. الصفوف غير المرئية في الطرفيات الضيقة لا يمكن تحديدها. يكمل Right في نهاية بادئة الاسم الأمر أو ينتقل بين البدائل؛ والنقر على المقترح يدرجه. لا يتنقل Tab في الرأس ولا يشغّل أمراً. إكمال الألقاب خاص بالدردشة.

يسترجع Up من حقل الإدخال الأوامر المقبولة الموافقة للبادئة الأصلية؛ ويعيد Down التنقل نحو الأحدث ثم إلى المسودة الأصلية. تُطابق الوسائط byte-for-byte. لا تُسجل الأوامر الفاشلة. يحتفظ التاريخ بما لا يزيد عن 64 إدخالاً/64 KiB لكل خادم، ويحذف التكرارات المتتالية المتطابقة ويطرد الأقدم. يستمر الاسترجاع ما دامت هذه الواجهة والخادم مفتوحين؛ وتغيير الواجهة أو إنهاء العامل يُسقطه.

عداد الاستخدام الدائم منفصل: يحوي CONFIG_PATH.commands حتى 96 اسماً قياسياً وعدداً محدوداً، دون وسائط أو أهداف أو نص دردشة. يتيح الملف المحفوظ تحديثات تلقائية خاصة وذرية بعد قبول أمر أو إعادة تعيين عداد؛ وتظل أعداد الملفات غير المحفوظة في الذاكرة حتى Save. لا يمنع ملف العداد المفقود أو التالف بدء التشغيل. لا يقرأ Test mode الأعداد ولا يكتبها؛ ولا يحفظها ملف الإعداد الرئيسي.

تُستبعد أوامر join ذات المفتاح ورسائل الخدمات والمصادقة المعروفة كلياً من الاسترجاع، بما فيها الرسائل البريئة الموجهة إلى خدمات حساسة معروفة. لا يستطيع الترشيح اكتشاف كل سر محتمل؛ فلا تكتب الأسرار في الدردشة العادية. انظر BOUNCER CONNECTIONS لضوابط bouncer.

اللصق في Command بيانات فقط: يتحول CR/LF/Tab إلى مسافات، ويُبلغ عن عناصر التحكم غير المدعومة أو تجاوز الحجم، ويبقى Enter/Run جديد ضرورياً. لا اقتباس للصدفة ولا استبدال ولا تسلسل أوامر ولا تشغيل للصدفة. تستهلك وسائط TEXT/PATH بقية النص حرفياً؛ اقتبس #channel في صدفة حقيقية فقط لا داخل هذه الأوامر. تظل /msg و/me و// خاضعة لحدود الرسائل وإيقاع الإرسال والموافقة الإلزامية على التجزئة مع الاختيار الافتراضي No. // دردشة حرفية ولا تدخل تاريخ الأوامر. تملأ إجراءات Join/New مسبقاً /join أو /pm.

===== SOURCE CHAPTER: CONNECTION AND STARTUP COMMANDS =====
أوامر الاتصال وبدء التشغيل

يتصل /connect مع خياراته مباشرة بالمضيف HOST، بينما يعيد /connect دون وسائط استخدام الملف المختار الذي حُفظ أو طُبق. يسلك /server HOST [PORT] المسار المباشر نفسه. يختار /server NUMBER ملفاً دون اتصال، ويفتح /server وحده عرض الخادم/MOTD. يضيف /server add HOST [PORT] [NICK] ملفاً منفصلاً غير محفوظ. تتحكم /server connect NUMBER و/server disconnect NUMBER و/disconnect [NUMBER] بالاتصالات المرقمة. يغلق /server close NUMBER ملفاً ثانوياً مع إبقاء ملفه الفعلي على القرص.

تستخدم الوجهات الجديدة TLS متحققاً منه على المنفذ 6697 ولقباً أو اسم مستخدم صالحاً للدخول، ولا ترث بيانات الاعتماد أو القنوات. تحفظ الوجهة المطابقة وسيلة النقل والمنفذ واللقب والمصادقة وتختار اتصالاً نشطاً موجوداً بدل مضاعفته. عندما تشترك ملفات bouncer في المضيف نفسه، اختر NUMBER الصحيح ثم شغّل /connect المجرد. لا يحفظ أي أمر اتصال إعداداته ضمنياً. فتحات الخوادم في الوضع الكامل 0..7 (الأساسي 0) وفي المبسط 1..8 (الأساسي 1). لا تغير أوامر الاتصال أو الفصل الاختيار الحالي. استعمل أرقام /servers الخاصة بالواجهة، لا أرقام منتقي /panel المختلفة.

تسبق خيارات /connect الوسيط HOST. الخيار -ssl مرادف -tls؛ ويطلب +PORT استخدام TLS، ولا يعطله أبداً رقم منفذ عادي. تُقبل أيضاً صيغ --tls و--plain و--nick؛ ويستخدم الاتصال الجديد غير المشفر 6667. كلمات المرور ليست وسائط موضعية. يغلق Close الملف الثانوي ويحذف مرجعه من الفهرس والمسودات والتاريخ وعمليات النقل، لكنه يترك ملفه على القرص.

يغير /autoconnect بدء التشغيل التالي لا الاتصال الجاري. يُعد /autojoin قنوات الملف المباشر لأمر /connect صريح تالٍ من دون انضمام أو مغادرة الآن؛ ويعرض استعلامه التسجيل والعضوية النشطة والمعلقة. تحافظ محاولات إعادة الاتصال الآلية على إعدادات التشغيل؛ أما /connect بعد الفصل فيأخذ التعديلات المطبقة. ينفذ /join بعد التسجيل مباشرة. يستعيد bouncer عضوية القنوات بنفسه ويرفض تعديل autojoin؛ كما يرفض تغيير /autoauth، واستعمل Settings أو /panel عوضاً عنه.

يُعد /autoauth مصادقة SASL فقط عبر TLS متحقق منه. يعرض Status محلياً مسارات الاعتماد الحالية والمعلقة كاملة دون قراءة الملفات؛ وتخفيها مخرجات Settings المعتادة. يحتوي الاستعلام في الوضع الكامل على Refresh/Back ويحتفظ بالمسودات. يمثل PATH بقية النص حرفياً مع المسافات. توضع الأسرار المباشرة في ملف إعداد خاص أو Settings لا في الأوامر.

يكتب /save المجرد الملف الفعلي المختار بما في ذلك الخيارات المعلقة. ويكتب كل من /save input و/save output الملف الأساسي الذي يحتوي تفضيلات التطبيق؛ فهما اسمان بديلان وليسا حفظاً جزئياً للمدخل أو المخرج. تتضمن العملية تغيرات الاتصال الأساسي المعلقة. يكتب /save all الملفات السليمة، ويُذكر /saveconf أيضاً بالملف الافتراضي المختار لأمر /connect لاحق. لا يفعّل الحفظ autoconnect. كل ملف خاص ويُكتب ذرياً، لكن مساحة العمل كلها ليست معاملة واحدة: يبقى النجاح السابق بعد فشل لاحق. لا تُستبدل الملفات غير المقروءة. لا يحفظ Test mode مطلقاً.

/set autoconnect on|off اسم بديل للتوافق في الوضع الكامل. يعمل /set لتفضيلات التطبيق في الواجهتين؛ وتؤثر إعدادات الإرسال والتحرير والإخراج في الوضع المبسط. يفتح /panel الإعدادات الموجهة في كليهما، ويسأل /quickstart عن أربعة عناصر اتصال أساسية. يفتح /settings نماذج في الوضع الكامل وتقريراً في المبسط.

يطلب /list [MASK] [OPTIONS] دليل قنوات الشبكة بعد التسجيل. يُرسل MASK وحده إلى الخادم؛ وتعمل --min-users/--max-users و--name و--topic مرشحات محلية. تتحكم --sort channel|users|topic و--asc/--desc و--limit N بالعرض؛ الافتراضي ترتيب عدد المستخدمين تنازلياً، وتعني --limit 0 عدم تحديد عدد المعروض ضمن ذاكرة مؤقتة سعتها 8192 مدخلاً. يمكن لـ/list show تغيير الترتيب والحد دون طلب آخر، ويمسح /list clear الذاكرة المؤقتة. أما /ls و/cl فتسرد العروض المحلية فقط.

عند انقطاع الاتصال أو رفض الخادم الصريح لطلب LIST، تبقى النتائج الجزئية مخزنة ولكن يُحرر الطلب. أعد /list بعد التسجيل أو امسح بواسطة /list clear؛ ولا تُعد النتائج الناقصة دليلاً كاملاً لقنوات الشبكة.

يستعمل متصفح الوضع الكامل Up/Down أو j/k للتنقل بين الصفوف، وLeft/Right أو h/l لاختيار عمود الفرز، وs لعكس الترتيب، وPage Up/Page Down وg/G للملاحة، وEnter للانضمام، وr لتكرار الطلب، و/ لفتح Command، وEscape للعودة. النقر على عمود يفرزه. في الوضع المبسط يطبع /list show الذاكرة المؤقتة، ويقدم /summary ملخصاً مستقلاً لمساحة العمل المحلية.

===== SOURCE CHAPTER: SESSION SUMMARY =====
يفتح /summary لقطة محلية لحالة العميل الجاري بكامله في قارئ منفصل قابل للتمرير. يعمل دون اتصال ويجمع النتائج حسب الخادم. تعرض اللقطة حالة الاتصال واللقب والقناة 0 ونوافذ القنوات التي انضم إليها المستخدم أو غادرها والمحادثات الخاصة وعدد غير المقروء والإشارات وطوابير الإرسال وأوامر البدء المعلقة ونقل الملفات وحالتها الحالية. تستبعد المجاميع نسخة موجز الإشارات لكي لا تحسب الرسالة الأصلية مرتين. وقد تكون الإشارة غير مقروءة أيضا؛ فلا تجمع هاتين القيمتين.

لا يغير فتح الملخص أو تحديثه المحادثة ولا يحدد الرسائل مقروءة ولا يرسل طلبا إلى الشبكة ولا يستبدل المسودة. يعرض أعداد الطوابير دون كشف النصوص المنتظرة أو الأوامر التلقائية أو بيانات الاعتماد. إنه وصف للحالة الحالية لا تفسير لمحتوى المحادثة.

في الواجهة الكاملة استخدم Up/Down أو k/j وPage Up/Page Down وHome/End أو g/G. اضغط r أو R أو فعل Refresh بلوحة المفاتيح أو انقر عليه للحصول على لقطة جديدة. يعيد Escape أو Back إلى موضع البدء. في vipirc -i يحدث r قارئ النتائج. إذا فشل التحديث تبقى اللقطة السابقة. تستمر الشبكة في العمل أثناء القراءة. يفتح / واجهة Command، والإلغاء يعيد إلى اللقطة نفسها. يعرض ? مساعدة الملخص وقارئه.

===== SOURCE CHAPTER: SETTINGS =====
الإعدادات

يفتح F1 > Settings أو /settings إعدادات الواجهة وجميع ملفات تعريف الخوادم وخيار New server من دون تبديل المحادثة الحالية. تعرض الصفوف حالة الاتصال التلقائي والحفظ. تشمل حقول الخادم النقل والهوية والانضمام التلقائي للقنوات والاتصال التلقائي ومصادر كلمات مرور الحساب والخادم (PASS) وسلطة الشهادات الخاصة (CA)، وكذلك نوع الباونسر واسم مستخدمه وشبكته وعميله وحالة الغياب التلقائي، والسجل والإشارات وقواعد التجاهل. يتضمن قسم Interface الخيارات User list وMouse وHints وShortcut labels والإشعارات والتسجيل ووضع الجلسة الواحدة واقتراحات الأوامر والواجهة الافتراضية.

    Edit    Apply    Save    Back    Cancel

تختار Up/Down أو k/j الحقول، وتختار Left/Right أو h/l الإجراء، وينفذه Enter. تنتقل Home/End أو g/G إلى طرفي القائمة. يبدل Edit قيمة منطقية أو يفتح خيارا أو يحرر نصا أو رقما. لا يؤدي Enter داخل المحرر إلا إلى تجهيز القيمة؛ وتتحقق Tab/Shift-Tab منها وتجهزها قبل الانتقال. تبقى المدخلات غير الصالحة قابلة للتعديل. الحروف المكتوبة في المحرر نص عادي. يؤدي إفراغ حقل watch/ignore موجود إلى حذفه، وينشئ Add حقلًا آخر ضمن الحدود المحددة.

يتحقق Apply من التفضيلات النشطة وقواعد watch/ignore والاتصال التلقائي ويطبقها، ثم يبقى في Settings مع تحديد Edit. تظل حقول الاتصال، بما فيها هوية الباونسر، معلقة إلى أن ينفذ المستخدم Connect صراحة بعد قطع الاتصال. لا يحفظ Apply شيئا ولا يعيد الاتصال ولا يغير وجهة جلسة نشطة. تؤثر /nick و/join و/part في الاتصال الجاري. يكتب Save ملف التعريف الفعال بصلاحيات خاصة وبطريقة ذرية ثم يطبق الإعدادات؛ ويحافظ /save كذلك على الخيارات المعلقة. ينشئ أول Save لخادم ثانوي ملف تعريف معزولا ومدخلا في فهرس الخوادم.

يحدث Interface Apply جميع مواضع الخوادم الحالية والمستقبلية. ويكتب Interface Save التهيئة الأساسية قبل تطبيق التغييرات. إذا فشل Interface Save أو منع، بقيت جميع الجلسات بلا تغيير. لا تستطيع مفاتيح الواجهة في ملف تعريف ثانوي تجاوز إعدادات الملف الأساسي عند بدء التشغيل. يظل السجل مستقلا لكل خادم في الوضع الكامل. ولا يؤثر اختيار الواجهة الافتراضية إلا في التشغيل الجديد.

يخفي Hints الإرشادات الاختيارية مع إبقاء العناوين وعناصر التحكم والأخطاء وتأكيدات السلامة. ويخفي Shortcut labels البادئات المعتادة F1..F6. كلا الخيارين مفعل افتراضيا ويحفظ ضمن [interface]. ولا يرتبطان بألوان الطرفية العادية أو بالخط العريض الذي يميز العنصر المحدد.

يؤدي تغيير Server إلى قيمة مختلفة بصرف النظر عن حالة الأحرف إلى مسح المصادقة الموروثة وauth user وجميع مصادر كلمات مرور الحساب/PASS وإعدادات autojoin من النموذج الذي يجري تجهيزه. ويؤدي تغيير نوع الباونسر إلى مسح بيانات الاعتماد والأوامر الموروثة؛ أدخل القيم المقصودة بعد ذلك. تظل الجلسة النشطة كما هي. لا تقرأ الملفات ولا تفك شفرتها أثناء التحرير؛ وتخفى كلمات المرور النصية المدخلة مباشرة مع الاحتفاظ بالمسافات داخلها. يحدد Transport استخدام TLS موثق أو نص غير مشفر باختيار صريح، بصرف النظر عن تشفير كلمات المرور أثناء التخزين.

يعيد Back المستخدم إلى الصفحة الرئيسية في Settings. يغلق Cancel/Escape النموذج بأكمله حتى من حقل أو نافذة منبثقة، ويلغي التغييرات التي لم تطبق، ثم يعود إلى vipirc. تظل التفضيلات والخيارات المعلقة التي سبق تطبيقها ومسودات المحادثات محفوظة. يجيز وضع الاختبار Apply داخل الذاكرة، لكنه يرفض Save. ويحافظ إنشاء خادم أو الاتصال به من Settings على المحادثة النشطة المحددة.

لا يعمل اللصق المحدد (bracketed paste) إلا في حقل نشط، ويدرج النص دون اعتماده، ويحول علامات الجدولة إلى مسافات. ترفض CR/LF/Escape ورموز التحكم غير المدعومة. ويتجاهل اللصق في القوائم ونوافذ الاختيار. راجع النص ثم اضغط Enter لتجهيز القيمة. أما /panel فهو مسار إرشادي مستقل قائم على الأسئلة والأجوبة كما يرد في قسم MINIMALIST INTERFACE.

تخصيص ارتباطات المفاتيح

لا توجد مفاتيح مخصصة معينة افتراضيا. يفتح App > Key bindings أو /bindings جدول الارتباطات في واجهة vipirc الكاملة. يحدد Add/Edit اسم المفتاح والإجراء المحلي، ويحذف Remove صفا. يطبق Apply التغييرات في الذاكرة، بينما يحفظ Save إعدادات الخادم الأساسي في ملف التهيئة أيضا. يلغي Escape/Cancel التعديلات التي لم تطبق بعد. تبقى مسودات المحادثة محفوظة. وللجدول أدوات تحكم مستقلة لا تؤثر فيها الارتباطات المخصصة.

في كلتا الواجهتين، يعرض /bindings keys و /bindings actions الأسماء المتاحة. من أمثلة الخيارات التي يختارها المستخدم بنفسه: /bind F7 summary و /bind Alt-c command؛ أدخل كل مثال في أمر منفصل. يزيل /unbind F7 ارتباطا واحدا، ويمسح /unbind all جميع الارتباطات المخصصة. يحفظ /save input التغييرات لجميع ملفات تعريف الخوادم. في وضع -i يعرض /bindings الجدول وتعدله أوامر /bind و /unbind.

المفاتيح المدعومة: F1..F12, Ctrl-A..Z, Alt-a..z/0..9, Up, Down, Left, Right, Home, End, PageUp, PageDown, Insert, Delete, Backspace, Tab, Shift-Tab, Enter, Escape. الأسماء المكافئة: Ctrl-H/Backspace, Ctrl-I/Tab, Ctrl-J/Ctrl-M/Enter, Ctrl-[/Escape. تستخدم أحرف Alt بايتات الأحرف الصغيرة من الطرفية. تكون الأولوية لاعتراض الطرفية أو مضاعف الجلسات للمفاتيح ولتعيينات الإشارات؛ ولا يعاد تعيين أي مفتاح إشارة.

الإجراءات المتاحة: compose, command, bindings, help, manual, summary, servers, channels, queries, unread, mentions, transfers, settings, quickstart, next, prev, clearinput, cancel, background, quit. لا توجد وحدات اختصار لتنفيذ أوامر اعتباطية أو إرسال رسائل تلقائيا. في الواجهة الكاملة، يتطلب الأمر المستعاد ضغط Enter جديدا للإقرار به ثم ضغط Enter منفصلا بعد مهلة لتنفيذه. إذا أغلق الهدف الأصلي يمنع Run.

لا تعمل الإجراءات المخصصة إلا في المحادثة الرئيسية أو إدخال الأوامر؛ ولا تعمل أثناء اللصق أو في حقول كلمات المرور أو الإعداد الأولي أو القراء أو مربعات التأكيد. يظل اللصق غير المؤطر في حكم الكتابة العادية. تحتفظ قارئات الاختصارات المبسطة بالمسودة وموضع المؤشر؛ وترفض تغيير الهدف أو المحرر إذا كانت المسودة غير فارغة. يحذف clearinput المسودة الحالية عمدا.

يحفظ القسم [hotkeys] من ملف التهيئة الأساسي صفوفا على صورة KEY=action، ولا يحتوي صفوفا افتراضية. يؤدي وجود قيود مجهولة أو مكررة أو تتجاوز الحد إلى رفض تحميل الجدول كله رفضا ذريّا. يدعم البرنامج 64 قيدا بحد أقصى. راجع doc/HOTKEYS.txt لتعليمات الحفظ وحدود الطرفية والأمثلة.

===== SOURCE CHAPTER: TERMINAL SIGNALS =====
إشارات الطرفية

يُتجاهل Ctrl-D المدخَل فعلياً ما لم يُربط صراحةً بحقل الإدخال الرئيسي للدردشة أو الأوامر؛ ويمكنه أيضاً إلغاء سؤال الخروج من F1. لا يستطيع Ctrl-D الملصق الإجابة عن ذلك السؤال. للخروج المعتاد استخدم /quit في Command. تظل تعيينات إشارات الطرفية المخصصة ذات أولوية على معالجة المفاتيح العادية.

تُورَث معالجة إشارات الطرفية افتراضياً. لا يعيّن العميل Ctrl-C أو Ctrl-Z؛ ولا يعملان إلا إذا ربطتهما الطرفية بإشارات وكانت معالجتها مفعّلة. تُحفَظ مفاتيح المقاطعة والخروج والتعليق المخصصة. لتفعيل معالجة الإشارات صراحةً، اضبط التفضيل التالي في الإعداد الرئيسي وابدأ عملية عميل جديدة:

    [input]
    use_signals=true

القيمة الافتراضية false تحفظ حالة تفعيل الإشارات أو تعطيلها الموروثة. لا يغيّر هذا الإعداد تعيينات مفاتيح الطرفية. يعيد العميل إعدادات الطرفية الأصلية عند التعليق أو الخروج.

عند التفعيل، تنهي إشارة المقاطعة البرنامج من دون حفظ المسودات. وتعليق عملية عادية في المقدمة يوقف نشاطها الشبكي وقد يسبب انتهاء المهلة؛ ويستأنفها fg. أما في عمل مُدار أو مُستأنف فيتوقف متحكم المقدمة فقط بينما تواصل العملية العاملة الاتصال بالشبكة؛ راجع RUNNING IN THE BACKGROUND.

التشغيل في الخلفية

يحافظ الأمر /background أو الخيار F1 > Background على اتصالات IRC وعمليات نقل الملفات المقبولة والمسودات والمحفوظات الموجودة في الذاكرة، مع إعادة الطرفية إلى حالتها السابقة. ويطبع أمر الاستئناف المرقم، مثل vipirc --resume 1. عند أول فصل للواجهة تنشأ عملية عاملة ونقطة اتصال محلية خاصة، أما الفصل اللاحق فيحتفظ بالرقم والحالة ونقطة الاتصال. ولا توجد نقطة الاتصال هذه ولا العملية المساعدة الإضافية في وضع التشغيل الأمامي العادي.

عند الاستئناف يعيد البرنامج قراءة قدرات الطرفية وأبعادها وإعداد اللغة على المضيف نفسه وبحساب Unix نفسه. يجب أن تستخدم stdin/stdout/stderr الطرفية التفاعلية tty نفسها. تدير عملية تحكم أمامية واحدة الإشارات وتغييرات الحجم، ولا يمكن وصل أكثر من طرفية واحدة في الوقت نفسه. يوضح القسم SESSION RECOVERY AND UPGRADES اختيار المهام وحالات انشغال الاتصال.

للتشغيل دون مراقبة، احفظ أولا ملفات تعريف الخوادم التي تريد اتصالها التلقائي، ثم شغّل vipirc --background --reconnect --config /absolute/config.ini. لا يفعّل --background الاتصال التلقائي، بينما يمنعه --no-connect. يدل النجاح على اكتمال الإعداد المحلي فقط. ولا حاجة إلى tty أو TERM حتى تلتحق طرفية بالجلسة. تجهز نقطة الاتصال الخاصة قبل بدء العمليات المساعدة لاستعلام DNS وقراءة بيانات الاعتماد. يحتفظ --resume دون خيار واجهة بالواجهة التي تعمل بها العملية؛ أما تحديد -i/-N صراحة فيغيّر الواجهة دون إعادة الاتصال بالشبكة أو استبدال العملية العاملة. يحتفظ تبديل الواجهة بتاريخ المحادثات وعمليات النقل المقبولة، لكنه يتخلص من المسودات وطلبات مراجعة الإرسال المعلقة وسجل الأوامر والنماذج التي لم تطبق. أكمل المسودات المهمة أو انسخها قبل التبديل. والفصل ثم الاستئناف بالواجهة نفسها يحفظ هذه الحالة المحلية. وقد تقتصر العمليات العاملة القديمة على واجهتها الأصلية.

تحتفظ إشارات الطرفية المضبوطة بوظائفها. تعليق عملية التحكم في جلسة مستأنفة يوقف واجهتها مؤقتا بينما تواصل العملية العاملة الاتصال بالشبكة؛ ويعيد fg التفاعل معها. أما تعليق عملية عادية تعمل في المقدمة فيوقف نشاطها الشبكي مؤقتا. راجع TERMINAL SIGNALS بشأن تعيينات الإشارات الموروثة، وSESSION RECOVERY بشأن فقد الطرفية.

قد يستدعي الفصل الأول إعادة المحاولة ريثما تنتهي العمليات المساعدة لاستعلام DNS أو بيانات الاعتماد. إن تجاهل SIGCHLD أو جمع العمليات الفرعية المنتهية تلقائيا يمنع إنشاء أول عملية عاملة في الخلفية والعمليات المساعدة؛ يجب على البرنامج المشغّل أن يترك العمليات الفرعية قابلة للانتظار حتى انتهاء عملها. ولا ينشئ الفصل المتكرر لمهمة تدار بالفعل عملية عاملة جديدة.

الدليل ومقبس الاتصال خاصان بالمالك. يفحص البحث 64 موضعا كحد أقصى خلال مهلة إجمالية مقدارها 1500 ms، ولا يحذف إلا المدخلات التي ثبت تقادمها ولم يعد لها قفل مدة حياة قائم. ولا يرسل إشارات إلى PID جرى تخمينه. وتبقى المهام التي لا تستجيب غير متحقق منها. تمنع فحوص الهوية ونسخة العملية إعادة توجيه الاتصال إلى عملية مختلفة إذا أعيد استخدام رقم مهمة أثناء التسليم. وتظل أي عملية أخرى تعمل بصلاحيات الحساب نفسه ضمن حدود الثقة. يمنع single_session=true إنشاء عملية عاملة ثانية في نطاق vipirc، لكنه لا يحدد عدد الخوادم داخل العملية الأولى.

لا تُحفظ حالة العملية العاملة على القرص: فعند إعادة تشغيل الجهاز أو الخروج أو إنهاء العملية تضيع المسودات وعلامات الاسترجاع والمحفوظات الموجودة في الذاكرة. ولا تحفظ السجلات الاختيارية إلا نص المحادثة. ويمكن تشغيل وضع الاختبار في الخلفية بنقطة الاتصال المحلية دون تفعيل شبكة IRC/DCC. ولا حاجة إلى برنامج لتعدد جلسات الطرفية.

استعادة الجلسات والترقيات

تمثل مهمة shell واحدة عملية عاملة واحدة للعميل مع جميع اتصالات IRC وعمليات النقل والمسودات والمحفوظات التي تحتفظ بها. يختلف رقم المهمة عن PID الخاص بنظام التشغيل وعن رقم الخادم المعروض داخل العميل.

لاستعادة مهمة ما زالت طرفية SSH القديمة متصلة بها:

    vipirc --sessions
    vipirc --detach-session 1
    vipirc --resume 1

اختر NUMBER من القائمة الحالية. يحرر --detach-session عملية التحكم التي تم التحقق منها، وينتظر حالة الفصل، ويُبقي العملية العاملة وحالة IRC قائمتين. لا يختار --resume دون رقم إلا مهمة واحدة منفصلة تم التحقق منها؛ فإذا وجدت مهام متعددة أو لم يكتمل التحقق من بعضها، لزم اختيار المهمة صراحة. ولا يستولي هذا الأمر على طرفية ما زالت متصلة. تبقى أرقام المهام ثابتة حتى خروج العملية، ثم يجوز إعادة استخدامها.

إغلاق جلسة من shell

استخدم هذا الإجراء فقط عندما تريد إنهاء المهمة بأكملها:

    vipirc --sessions
    vipirc --close-session 1

ينهي الإغلاق كل اتصالات IRC وعمليات النقل التابعة للعملية العاملة، ويتخلص من المسودات غير المحفوظة والمحفوظات الموجودة في الذاكرة. وتبقى الإعدادات المحفوظة وملفات السجل النصية العادية الموجودة سابقا. وتقبل أيضا الصيغتان --close-session=1 و--detach-session=1. لا تتطلب أوامر الإدارة هذه طرفية تفاعلية ولا تقرأ ملف الإعدادات. لا تجمعها مع --resume أو --sessions أو مع بعضها أو مع --config أو خيارات الاتصال. ويمكن أن تبقى خيارات الواجهة المدعومة ضمن اسم مستعار دون تغيير المهمة المختارة.

يستخدم العميل نقطة الاتصال الخاصة بالمالك، ويتحقق من ملكية الطرف المقابل ومن رمز هوية العملية العاملة المختارة. يدل النجاح على تأكيد اكتمال تنظيف موارد التطبيق وتحرير قفل المهمة الأصلي؛ وليس مجرد قبول الطلب، ولا إثباتا مستقلا على انتهاء العملية في نظام التشغيل. للطلبات مهلة محددة. لا يحذف الفشل أو انتهاء المهلة نقطة اتصال عملية لا تزال حية، ولا يرسل إشارة إلى PID مخمن. وإذا قبل الطلب قبل انقضاء المهلة فقد يكتمل لاحقا؛ تحقق مرة أخرى باستخدام --sessions.

قد تعجز عملية عاملة عالقة في الكتابة إلى طرفية مفتوحة لا يقرأ أحد خرجها عن معالجة طلب التحكم حتى تصبح الكتابة ممكنة أو تغلق الطرفية. وقد تستلزم العملية المتوقفة تماما تدخلا على مستوى نظام التشغيل بعد التعرف إلى العملية الحقيقية. وتعني حالة الإغلاق غير الصفرية أن اكتمال الإجراء لم يتأكد.

استعادة الجلسة بعد انقطاع SSH

يؤدي فقد الطرفية أو عملية التحكم في مهمة سبق وضعها تحت الإدارة إلى فصل العملية العاملة. وتبقى الاتصالات والحالة المحفوظة عند حدوث قطع اتصال أو خطأ، أو stdin EOF/EIO، أو فشل stdout، أو EOF في عملية التحكم، أو SIGHUP. وفي الواجهة الكاملة، تعاد توجيه مخرجات العملية العاملة القديمة قبل تنظيف curses عندما تفقد الطرفية أو يطلب الإغلاق من خارجها؛ وتعيد عملية التحكم الأمامية إعدادات tty الخاصة بها.

أما العملية الأمامية العادية التي لم تصبح قط مهمة مدارة فتظل تنتهي بالطريقة المعتادة عند تلقي SIGHUP. ابدأ باستخدام --background أو نفذ /background أولا إذا احتجت إلى مهمة قابلة للاستئناف. ولا يغير العميل سياسة مهلة الخمول في عميل SSH أو خادمه. وقد تظل عمليات رسم الطرفية المتزامنة عالقة إذا بقيت الطرفية مفتوحة دون قراءة مخرجاتها.

تحديث عملية عاملة أثناء التشغيل

إن تثبيت نسخة جديدة أو إعادة ترجمة البرنامج لا يستبدل الشفرة داخل عملية عاملة بالفعل. احفظ الإعدادات المطلوبة، ثم اخرج من المهمة أو أغلقها عن قصد، وتحقق من النسخة المثبتة باستخدام --version، وابدأ مهمة جديدة. اتبع الإجراء نفسه عند تثبيت التحديثات الأمنية. تبقى ملفات السجل، لكن المسودات وسجل الأوامر وعلامات استرجاع المحادثة لا تبقى.

قد تفتقر العملية القديمة إلى أدوات الفصل أو الإغلاق الجديدة، أو إلى إمكانية تغيير الواجهة. احتفظ بملفها التنفيذي المتوافق حتى تتوقف، إذا كنت تحتاج إليه للاتصال بها والخروج باستخدام أدواتها الحالية. ولا يعد فشل عملية إدارية قديمة نجاحا لمجرد اختفاء نقطة اتصال. تظل ملفات الإعدادات الموجودة صالحة للنسخة الحالية، لكن الملف التنفيذي الأقدم قد يرفض المفاتيح التي حفظتها نسخة أحدث صراحة.

راجع doc/SESSION-CONTROLS.txt للإجراء نفسه وdoc/OPENBSD-VPS.txt لإعداد التشغيل دون مراقبة على المضيف. إن تثبيت أرشيف الشفرة المصدرية هذا لا يوقف ولا ينشر أي شيء تلقائيا على مضيف بعيد.

===== SOURCE CHAPTER: SERVERS AND UNREAD ACTIVITY =====
الخوادم والنشاط غير المقروء

تعرض واجهة ncurses الكاملة خانات الخوادم 0..7، والخادم الأساسي هو 0. تتشارك الخوادم حلقة أحداث واحدة، لكن لكل منها بيانات اعتماد وهوية وقنوات ومحادثات خاصة وإشارات وقوائم مستخدمين وسجل ومسودات مستقلة. يفتح F2 أو /servers الإجراءات التالية:

    Open    New    Connect    Disconnect    Close    Away    Back

يشرح قسم GLOBAL HEADER AND CHAT CONTROLS التنقل المشترك بين القوائم. يعرض Open رسالة MOTD الخاصة بالخادم (القناة 0) مع إبقاء المسودات ومواضع المؤشرات. ينفذ Connect/Disconnect إجراءه على الصف المحدد. يبدل Away حالة الغياب التي أقرها الخادم المسجل مستخدما الرسالة الافتراضية Away. يفتح New (وكذلك n) استمارة؛ ويعيد Back/Escape العرض إلى المحادثة.

لا يمكن إغلاق الخادم الأساسي 0. يحتفظ Disconnect بالواجهات والمسودات وعمليات نقل DCC المقبولة. يتطلب Close في الخوادم الثانوية تأكيدا دائما، والإجابة الافتراضية No؛ وهو يمحو ذاكرة ذلك الخادم ويلغي عروض الملفات وعمليات النقل ويحذف مرجعه من الفهرس، لكنه يبقي ملف تعريفه. إذا أغلق الخادم الثانوي المحدد تعود الواجهة إلى الأساسي. في وضع الاختبار، يغير Close حالة التشغيل فقط.

تحتوي استمارة New على Server و Port و Transport و Nickname و Autojoin و Autoconnect؛ وإجراءاتها Edit و Add و Connect و Advanced و Cancel. يعرض Advanced الهوية ومصادر المصادقة وخيارات CA قبل أول اتصال. يهيئ Enter قيمة الحقل مؤقتا، ويلغي Escape الاستمارة. تستخدم ملفات التعريف الجديدة TLS6697 والهوية login/default مع تعطيل autoconnect، ولا ترث أسرارا أو شهادات CA أو قنوات أو قوائم watch/ignore. تشترك الملفات في تفضيلات التطبيق وحدها. ينشئ Add حالة غير متصلة حتى إن كانت خانة autoconnect محددة؛ وينشئ Connect الحالة ويتصل فورا. يحدد كلا الإجراءين الخادم الجديد ويتطلبان Save صريحا للحفظ الدائم.

تظهر الصفوف new N !M للدلالة على النشاط والإشارات غير المقروءة، ويقف الرقم المعروض عند 999+ دون تغيير العدادات الداخلية. يصفّر فتح محادثة عدادات مصدرها وحده؛ ولا يجعل عرض قائمة تغطيها النص الجديد مقروءا. لا تتضمن المجاميع نسخ Mentions و Help. لا تزيد الأصداء المحلية للرسائل الصادرة عداد غير المقروء. يجعل الاطلاع على Mentions خلاصته مقروءة بصورة مستقلة، مع إبقاء عدادات المحادثات الأصلية.

يجمع F5 أو /unread الإشارات المحفوظة أولا ثم المحادثات غير المقروءة، حسب الخادم. تعرض الإشارات النص الكامل بعد لف السطور مع الطوابع الزمنية؛ وتحدد القيود الأصلية Server/Channel/Query. الإجراءات هي Open و Clear mentions و Back. يحدد Open المصدر؛ ويمكن إعادة فتح محادثة خاصة أغلقت اعتمادا على الاسم المستعار المسجل دون إرسال أي رسالة أو استعادة السجل المحذوف. لا يعاد الانضمام إلى القنوات المغلقة ويبلغ المستخدم بالخوادم غير المتاحة. تعتمد الملاحة على هوية المصدر الثابتة، لا على موضع الصف أو نصه.

يمسح Clear mentions أو /mentions clear نسخ الإشارات عبر جميع الخوادم دون تغيير سجلات المحادثات أو عدادات غير المقروء أو المسودات أو الطوابير. وقد تصل إشارات جديدة في الحال. تتصفح مفاتيح الصفحات الإشارة الطويلة المحددة قبل الانتقال إلى قيد آخر. يحدد /mentions دون معاملات خلاصة الخادم الحالي فقط.

===== SOURCE CHAPTER: VIEWS AND USERS =====
لكل خادم نافذة خادم/MOTD برقم 0 وقنوات ومحادثات خاصة لها ترقيم مستقل وإشارات وقوائم أعضاء. تحدد الترويسات الخادم، وتعرض نافذته التسجيل وMOTD والأخطاء. تحتفظ الإشارات بمصدر الرسالة ومرسلها والنص كاملا ضمن حدود البروتوكول. تلتف السطور الطويلة على الشاشة دون تقصير النص المحفوظ.

/sl أو /servers يفتح قائمة الخوادم؛ و/cl أو /channels القنوات؛ و/ql أو /queries المحادثات الخاصة. يختار /server نافذة MOTD، ويختار /channel NUMBER أو #NAME قناة، ويختار /pm NICK|NUMBER محادثة خاصة. يتنقل /next و/prev بين النوافذ. يعرض /summary لقطة لمساحة العمل، ويجمع /unread المصادر والإشارات، ويطلب /list دليل الشبكة. الصياغة الدقيقة في COMMAND REFERENCE INDEX.

يظهر /users قائمة أعضاء القناة أو يخفيها؛ وتتحكم on/off/up/down في ظهورها وتمريرها. تستخدم Settings > Interface التفضيل الرئيسي نفسه. في الطرفيات الصغيرة قد تختفي اللوحة الجانبية حتى يتوافر حيز. تستند العضوية وبادئات الصلاحية إلى أحداث JOIN/PART/QUIT/NICK/KICK/NAMES الواردة من الخادم، لا إلى تخمينات محلية. لا توجد قائمة أعضاء قناة في نافذة الخادم أو المحادثة الخاصة.

تنشئ الرسائل الخاصة الواردة دون طلب نافذة جديدة فقط عندما يكون عدد النوافذ الخاصة أقل من ثمان؛ وتبقى الرسائل اللاحقة مرئية مع سياقها في الخادم أو الإشارات. يستطيع /pm أو /msg إنشاء مزيد ضمن حد 32 نافذة. يمسح /clear الذاكرة المحتفظ بها للنافذة دون حذف سجلها من القرص، بينما يمسح /clearinput المسودة المستقلة.

===== SOURCE CHAPTER: CHANNEL CHOOSER AND CLOSING CONVERSATIONS =====
EXACT COMMAND/CONTROL EXAMPLES (not translated):
Open    Join    Part    Close    Back

يعرض F3 أو /channels (/cl, /views) المدخل 0 الخاص بالخادم/MOTD ونوافذ القنوات المحتفظ بها بما فيها القنوات التي غودرت. ينطبق التنقل المعتاد في القوائم؛ الإجراءات هي Open وJoin وPart وClose وBack.

يفتح Join واجهة Command وقد جهز فيها /join، مع الحفاظ على المسودات. يغادر Part القناة مع الاحتفاظ بالتاريخ، بينما يزيل Close النافذة. ينفذ p إجراء Part وc إجراء Close ويفتح o إجراء Join. يختار /channel NUMBER أو #NAME نافذة محتفظا بها؛ ويستخدم /view NUMBER ترقيم القنوات و/view NAME اسم النافذة. قد تتغير الأرقام بعد الإغلاق، فاستخدم القائمة الحالية.

يغادر Close أولا أي قناة ما زال المستخدم فيها، ويحذف تاريخها ومسودتها ويلغي رسائل تلك الوجهة المعلقة في الطابور؛ وقد يكمل إرسال رسالة قيد النقل. تتطلب المسودة غير الفارغة تأكيدا، والقيمة الافتراضية No. لا يمكن إغلاق نافذتي الخادم والإشارات؛ ويوقف /disconnect اتصال الخادم. يغلق /close [NAME|NUMBER] القناة أو المحادثة المحددة أو المحادثة الحالية. لا يمكن مغادرة القناة 0. يعيد Back/Escape إلى المحادثة.

===== SOURCE CHAPTER: QUERY LIST =====
قائمة المحادثات الخاصة

يعرض F4 أو /ql (/queries) محادثات هذا الخادم الخاصة وحدها، مرقّمة ابتداءً من 1 وبشكل مستقل عن القنوات. تنطبق أدوات التنقل المعتادة في القوائم، مع الإجراءات التالية:

    Open    New    Close    Back

يفتح New حقل Command مع إعداد /pm مسبقاً؛ وفي القائمة الفارغة يفعل Open فوق New query... الشيء نفسه. يغلق c وتفتح o/n إجراء New. يتطلب إغلاق مسودة غير فارغة تأكيداً، ويكون No الخيار الافتراضي. يفتح /pm NICK|NUMBER أو /query NICK|NUMBER محادثة أو يختارها دون إرسال، حتى عند انقطاع الاتصال. يرسل /msg NICK TEXT رسالة صراحةً؛ ويغلق /close NICK المحادثة حسب الاسم.

يفتح Escape من محادثة خاصة قائمة Queries مع اختيار المحادثة الحالية مهما كانت طريقة فتحها؛ ويعيد Escape/Back من القائمة المحادثة مع مسودتها. يبقى اسم المحادثة في سطرها ولا يحل محل فئة الترويسة.

===== SOURCE CHAPTER: MENTIONS AND WATCH STRINGS =====
الإشارات والسلاسل النصية المُراقَبة

تُراقَب كنيتك الحالية تلقائياً. تتبع المطابقة قواعد تحويل حالة الأحرف وحدود الأسماء المستعارة التي يعلنها خادم IRC. ويؤدي تغيير الكنية إلى تحديث هذه المطابقة التلقائية.

    /watch add project name
    /watch remove project name
    /watch list

القيم المخصصة أجزاء نصية حرفية، وليست تعابير نمطية أو أنماط صدفة. تُطبَّق قواعد حالة الأحرف والرموز الخاصة بـ IRC/ASCII؛ ويجب أن تتطابق المحارف غير ASCII تطابقاً تاماً. يُسمح بما يصل إلى 32 قيمة مخصصة، طول كل منها 127 بايت UTF-8. استعمل /save أثناء التشغيل المعتاد لحفظ التغييرات في الإعداد المحدد؛ وفي وضع الاختبار تبقى في الذاكرة. وتُحفَظ الإشارات في الذاكرة ضمن حدود المحفوظات، وليست أرشيف إشعارات دائماً ولا سجلاً على القرص. تعرض الطوابع الزمنية تاريخ ووقت الاستلام المحليين بصيغة YYYY-MM-DD HH:MM:SS.

===== SOURCE CHAPTER: CONVERSATION COMMANDS =====
أوامر المحادثة

يطلب /join CHANNEL [KEY] الانضمام إلى قناة واحدة مع مفتاح اختياري. يغادر /part [CHANNEL] [MESSAGE] قناة مع سبب PART؛ ويغلق /close [NAME|NUMBER] عرض قناة أو محادثة خاصة، حيث NUMBER رقم قناة. يفتح /pm NICK|NUMBER عرضاً خاصاً أو ينتقل إليه دون إرسال. يرسل /msg TARGET TEXT نصاً إلى لقب أو قناة، ويبعث /me TEXT فعل IRC في المحادثة الحالية. يطلب /nick NICK لقباً جديداً، ويضبط /away [MESSAGE] الغياب ويمحوه /back، ويطلب /whois NICK معلومات اللقب. يستعلم /topic المجرد عن موضوع القناة، ويطلب /topic TEXT موضوعاً جديداً. يدير /connect و/disconnect الاتصالات؛ ويفتح /dcc أو /transfers شاشة النقل المشتركة. يوقف /cancel الرسائل المنتظرة، ويواصل /background العمل ويعيد إلى الصدفة، ويُنهي /quit [MESSAGE] جلسات جميع الخوادم. تتحكم /settings و/save و/saveconf و/set autoconnect on/off بالتفضيلات والحفظ وبدء التشغيل.

يرسل /away MESSAGE رسالة AWAY قياسية واحدة. حد النص هو حد بايتات السطر الجاري ناقص 8، أي عادة 504 بايت من أصل حد 512. تُرفض الرسائل الأطول وعناصر التحكم ولا تُجزأ أبداً. يمحو /away بلا نص و/back حالة الغياب. يلزم التسجيل. لا تتغير العلامة إلا بعد إقرار الخادم، وتُصفّر عند الفصل وإعادة الاتصال. يرسل إجراء Away من قائمة الخوادم النص Away أو يمحو غياباً أُقر به، مع الاحتفاظ بالعرض والمسودة. يجب اتصال الخادم المنفصل أولاً. عدل المرسلين المتجاهلين في حقول Ignore ضمن Settings أو بالأمرين المحليين /ignore و/unignore.

يقبل /join قناة واحدة ورمز KEY واحداً على الأكثر. يجب أن يتألف المفتاح من ASCII قابل للطباعة بلا مسافات أو نقطتين أو فواصل، وأن يقع JOIN كله ضمن حد سطر الشبكة. لا يُسجّل المفتاح ولا يُحفظ؛ يُضاف اسم القناة وحده إلى autojoin. أعد إدخال المفتاح عند إعادة الاتصال أو التشغيل إذا لزم. تؤكد المحاكاة دون اتصال تغييرات away وتقبل مفتاح انضمام مؤقتاً، لكنها لا تختبر مفتاح القناة الحقيقي أو سياسة السماح بالدخول.

الخادم هو الذي يحدد الصلاحيات وتوفر الألقاب وقبول العضوية وإمكان تغيير الموضوع. قبول الأمر محلياً لا يضمن قبول الخادم أو وصول الرسالة إلى مشارك آخر. تنتظر رسائل الدردشة قليلاً ويُرسل كل سطر بعد سابقه بفاصل لا يقل عن 1.2 ثانية. يزيل /cancel الرسائل التي لم تُرسل بعد من الخادم المحدد عبر جميع القنوات والمحادثات الخاصة؛ ولا يمحو المسودة أو نصوصاً أُرسلت بالفعل. قد يكتمل إرسال جارٍ. في الملفات المباشرة يحدث /join و/part اختيار autojoin؛ ويحفظه /save للمرات القادمة ما لم تتغلب عليه خيارات Settings المعلقة. يستعيد bouncer العضويات بنفسه. يحذف /part كذلك النصوص المنتظرة لتلك القناة مع إبقاء عرضها وتاريخها؛ وقد يكتمل الإرسال الجاري قبل PART. النص بعد اسم القناة هو سبب PART؛ وإن غاب اسم القناة فهو سبب القناة المحددة. يستخدم [presence] part_message عند غياب السبب الصريح، وكذلك عند إغلاق قناة منضم إليها.

يستخدم /quit MESSAGE النص سبباً لأمر IRC QUIT قدر الإمكان في جلسات الخوادم النشطة. من دون نص يُستخدم [presence] quit_message؛ وإذا كانت القيمة فارغة يُرسل QUIT مجرداً. زمن الإغلاق محدود ولا ينتظر شبكة معطلة بلا نهاية.

الغياب التلقائي منفصل عن /away اليدوي. عند تشغيل background_away، يُدرج نجاح Background أو فقدان الطرفية الذي عولج رسالة AWAY المضبوطة فقط بعد انفصال الطرفية. يمحو Resume تلك الحالة التلقائية فقط. يطبق autoaway_minutes السلوك نفسه بعد خمول الإدخال المحلي؛ وتعطل القيمة 0 المؤقت. تمنع ملفات bouncer هذه التغييرات ما لم تُفعّل [bouncer] automatic_away=true. يظل /away اليدوي قائماً حتى /back أو /away دون رسالة. لا تُعد حركة IRC الواردة نشاطاً محلياً للمستخدم.

===== SOURCE CHAPTER: LOCAL IGNORE FILTERS =====
EXACT COMMAND/CONTROL EXAMPLES (not translated):
/ignore
/ignore list
/ignore MASK
/ignore add MASK
/unignore MASK
/ignore remove MASK
/ignore clear
/ignore add NICK
*!*@*.example

تعمل هذه الأوامر المحلية حتى دون اتصال. يعرض /ignore أو /ignore list قائمة الأنماط؛ ويضيف /ignore MASK أو /ignore add MASK نمطا؛ ويزيل /unignore MASK أو /ignore remove MASK نمطا؛ ويحذف /ignore clear الأنماط كلها. للألقاب المسماة حرفيا list أو add أو remove أو clear استخدم /ignore add NICK.

يقبل البرنامج ما لا يزيد على 32 نمطا، طول كل منها حتى 127 بايت ASCII. يجب أن يطابق النمط البسيط لقبا صالحا مطابقا تماما. تتطلب أحرف البدل الشكل الكامل nick!user@host بثلاثة أجزاء غير فارغة، مثل *!*@*.example. داخل كل جزء يطابق * صفرا أو أكثر من البايتات، ويطابق ? بايتا واحدا. البايتات الأخرى المسموحة حرفية؛ لا توجد أصناف تعبيرات منتظمة أو قواعد هروب أو توسيع صدفة. يستخدم Nick قواعد مقارنة حالة الأحرف في IRC، ويتجاهل user وhost حالة أحرف ASCII. الفراغات ومحارف التحكم وغير ASCII غير صالحة. تقارن الإزالة الأنماط المخزنة وفق هذه القواعد، ولا توسع أحرف البدل لحذف أنماط أخرى.

ترشح فقط رسائل PRIVMSG/NOTICE الواردة من مستخدمين، قبل إنشاء إشارات أو محادثات خاصة. يجب أن يحمل المصدر بادئة مستخدم صريحة. قد يطابق نمط اللقب فقط مع نقص بيانات user/host، بينما يتطلب النمط الكامل الأجزاء الثلاثة. تبقى إشعارات الخادم المباشرة وحالة البروتوكول والعضوية ظاهرة، كما يبقى التاريخ السابق. هذا ترشيح محلي وليس حظرا من الخادم. تعدل Settings القائمة نفسها، ويطبق Apply التغيير فورا. يحفظها /save أو Settings Save في الوضع العادي، أما --test-mode فيحتفظ بالتعديلات في الذاكرة. تكرر الإعدادات السطر mask= في قسم [ignore].

EXACT COMMAND/CONTROL EXAMPLES (not translated):
/autocommands [list|add COMMAND|remove NUMBER|clear|on|off]
/autocommands delay SECONDS       0..300
/autocommands interval SECONDS    2..60
/autocommands add /msg ChanServ OP #room mynick
/save

يمكن لكل ملف شخصي تنفيذ ما يصل إلى 16 أمرا حرفيا بعد نجاح التسجيل وSASL الإلزامي. التأخير الافتراضي 15 ثانية، ثم فاصل لا يقل عن ثانيتين بين الأوامر المكتملة. لا ينتج الاتصال المتعثر دفعة مفاجئة من الأوامر المتراكمة.

تدار الأوامر بواسطة /autocommands [list|add COMMAND|remove NUMBER|clear|on|off]، و/autocommands delay SECONDS بحد 0..300، و/autocommands interval SECONDS بحد 2..60، وتحفظ بواسطة /save. مثال: /autocommands add /msg ChanServ OP #room mynick.

الأوامر المدعومة هي /msg و/join و/nick و/away و/back و/whois وأسماؤها البديلة الدقيقة الموثقة. لا يتجاوز الأمر 511 بايت UTF-8 ويجب أن يتسع في سطر IRC واحد. لا يوجد تقسيم خفي أو صدفة أو IRC خام أو حلقات أو استبدال للمحادثة الحالية. يقبل /join قناة واحدة ومفتاحا مؤقتا اختياريا. تخفي القوائم نص الرسائل والمفاتيح؛ ولا يضيف التنفيذ أوامر إلى التاريخ المحلي أو صدى محليا أو ينشئ محادثات خاصة. تصل الردود عادة، ولا تبدل الانضمامات التلقائية المحادثة المحددة.

تسري التعديلات عند الاتصال التالي. يوقف /cancel أوامر البدء المتبقية ورسائل الطابور لكنه لا يسترجع بايتات أرسلت أو هي قيد الإرسال. يلغي إغلاق وجهة أو مغادرتها بقية التسلسل الذي يخصها. يؤدي الفشل إلى إلغاء الأوامر اللاحقة مع بيان موضع الفشل دون كشف النص السري. يبدأ الاتصال الجديد تسلسلا جديدا؛ وتنفذ ملفات bouncer الشخصية أيضا أوامر البدء الصريحة. لا ينفذ شيء في الوضع غير المتصل.

يحوي قسم [autocommands] المفاتيح enabled وdelay_seconds وinterval_seconds وأسطر command= متكررة. كل البايتات بعد = حرفية، بما فيها المسافات و# و; و=. أي قائمة غير فارغة، حتى لو عطلت، تتطلب ملف إعدادات عاديا مملوكا للمستخدم بصلاحيات 0600/0400؛ وتتطلب القائمة غير الفارغة المفعلة TLS متحققا منه. تبدأ الملفات الجديدة بقائمة فارغة، ويؤدي تغيير الوجهة إلى مسح قائمة موروثة لم تعدل. احفظ عن قصد: تخزين الاعتماد بواسطة GPG لا يشفر هذه الأوامر في الإعدادات.

===== SOURCE CHAPTER: PROGRAM AND QUEUE NOTIFICATIONS, QUERY NUMBERS, AND ALIASES =====
يخفي /set queue_notices off إشعارات الطابور والإرسال المتدرج الاعتيادية في جميع الواجهات والخوادم، ويعيدها /set queue_notices on. في الواجهة المبسطة لا يظهر الإقرار الاعتيادي الزائد بعد إرسال راجعه المستخدم صراحة حتى لو كانت إشعارات الطابور مفعلة. وبصورة مستقلة يخفي /set program_messages off الرسائل المحلية منخفضة الأولوية مثل إلغاء المسودة ومسح الإدخال والحفاظ على المسودة وإشعارات النجاح أو الإلغاء المماثلة. تظل الأخطاء وتحذيرات حد البايت وتأكيدات الإرسال مرئية. القيمة الافتراضية لكلا الإعدادين true. يحفظ /save output أو /saveconf إعدادات [output] العامة، وهي موجودة أيضا في /panel Application preferences وإعدادات Interface الرسومية.

يرقم /ql المحادثات الخاصة مستقلة بدءا من 1. يختار /query 2 أو /pm 2 المدخل الثاني؛ ويمكن استعمال اللقب بدلا من الرقم. يؤدي إغلاق محادثة إلى إعادة ترقيم ما بعدها، ولا يرسل فتح المحادثة أي رسالة. تظل القناة 0 تعرض رسائل الخادم وMOTD.

تشمل الأسماء البديلة الدقيقة الشائعة /j و/leave و/message و/privmsg و/nickname و/names و/nicks و/conn و/disc و/unaway و/detach و/saveconfig و/configure و/preferences. تخضع للقواعد نفسها المتعلقة بالتحقق من الأوامر والإكمال والخصوصية. تؤدي الكتابة المجهولة إلى خطأ بدلا من تخمين إجراء لتنفيذه.

تظهر تغييرات العضوية وMOTD وWHOIS والدعوات والأخطاء المعتادة في رسائل مقروءة تحتوي معلومات مفيدة من الخادم. لا تضيف ردود الهوية والقدرات الداخلية سجلات بروتوكول مكررة إلى المحادثة. تبقي الردود غير المعروفة نص الخادم دون افتراض أن الرمز الرقمي وحده تفسير للرد.

===== SOURCE CHAPTER: FILE TRANSFERS =====
نقل الملفات

يفتح F6 أو /dcc أو /transfers قائمة عمليات النقل في مساحة العمل كلها، مع تحديد خادم IRC الذي نشأت منه كل عملية. تعمل مفاتيح التنقل المعتادة في القوائم. الإجراءات المتاحة هي:

    Accept    Reject    Send...    Cancel transfer    Back

تتطلب شاشة المراجعة 12 سطراً و20 عموداً على الأقل. يعيد Escape من متصفح الملفات أو الحقل إلى النموذج، ومن النموذج أو القائمة إلى المحادثة، مع الحفاظ على المسودات وعمليات النقل المقبولة. لا يُدعم سوى DCC SEND التقليدي النشط عبر IPv4؛ فلا توجد دردشة CHAT أو استئناف للنقل أو نقل سلبي أو عكسي أو قبول تلقائي أو اكتشاف للعناوين أو إعداد لتحويل المنافذ. الحجم الأقصى للملف 4,294,967,295 بايت. لا تُفتح الملفات المستلمة ولا تُنفذ تلقائياً.

DCC اتصال مباشر غير مشفر، منفصل عن TLS الخاص باتصال IRC، ولا يوفر مصادقة تشفيرية لهوية الطرف الآخر. يكشف العرض عنوان IPv4 المعلن، ويكشف قبوله عنوان IP الخاص بالمستلم للطرف المقابل. تحقق من المرسل ونقطة الاتصال والملف المقصود والحجم بالبايت قبل قبول أي عرض.

لا يفتح العرض الوارد أي ملف أو مقبس قبل الموافقة الصريحة. يفتح Accept من القائمة نموذج مراجعة فيه Directory/Save as وخيارات Edit/Accept/Cancel. لا يؤدي Enter في الحقل إلا إلى تجهيز القيمة؛ ولا يبدأ النقل إلا باختيار Accept في النموذج. لا يُدرج اللصق البيانات إلا في محرر نشط ولا يستطيع قبول العرض. لا ينشئ Reject أي ملف.

في الواجهة الكاملة يكون مجلد الاستلام المقترح $XDG_DATA_HOME/vipirc/downloads إذا كان مساره مطلقاً، وإلا فيكون $HOME/.local/share/vipirc/downloads إذا كان HOME مطلقاً. وإن لم يتوفر أي منهما فأدخل مساراً صريحاً. لا تُنشأ المجلدات الأصلية المفقودة بصلاحيات 0700 إلا عند Accept. يجب أن يكون المجلد الأصل المباشر ملكاً للمستخدم وخاصاً، ويُنشأ الملف الجديد بصلاحيات 0600. تُرفض الملفات الموجودة والروابط الرمزية و'..'. يجب أن يكون اسم الملف الأساسي ظاهراً وغير مخفي، وألا يحتوي على فواصل المسار أو محارف التحكم أو تنسيق الاتجاه ثنائي الاتجاه أو علامات الاقتباس. يمكن لأسماء الملفات الموضوعة بين علامتي اقتباس في البروتوكول أن تتضمن مسافات. لا يُحذف الجزء المستلم من ملف فشل نقله أو ألغي إلا إذا ظل هو الملف نفسه الذي أُنشئ أصلاً، ولا يُحذف ملف حل محله.

يفتح Send... الحقول Nickname وSource file وAdvertised IPv4 وListen port مع Edit/Browse وOffer وCancel. توفر المحادثة الخاصة اسماً افتراضياً للطرف المقابل، ويحدد النموذج خادم IRC المعني. لا يبدأ مقبس الاستماع ولا يُضاف العرض إلى قائمة الإرسال المنظم عبر الخادم المسجل إلا باستخدام Offer. يجب أن يكون المصدر ملفاً عادياً موجوداً، بلا روابط رمزية أو '..'. يختار المنفذ 0 منفذاً متاحاً، ويجب أن تكون المنافذ المحددة صراحة ضمن 1..65535. قد تتطلب NAT عنوان IPv4 معلناً يمكن الوصول إليه وتحويل المنفذ؛ ولا تُستدعى خدمة UPnP أو خدمة لاكتشاف العنوان العام.

يبدأ Browse من مجلد تشغيل البرنامج: تختار الأسهم عنصراً، ويفتح Enter مجلداً أو يختار ملفاً، ويرجع parent/Backspace إلى المجلد الأعلى، ويقبل Type path اسم ملف بمسار مطلق، ويلغي Escape العملية دون تغيير المصدر. يملأ الاختيار النموذج دون إرسال عرض أو تغيير cwd للعملية. تفحص كل دورة 64 مدخلاً كحد أقصى؛ وتحتفظ القائمة بـ512 مدخلاً وتتوقف بعد فحص 4096. استخدم Type path للعناصر غير المعروضة. تُستبعد الروابط الرمزية والأسماء غير الآمنة، وتُفحص البيانات الوصفية مجدداً عند الاختيار أو تقديم العرض.

    /dcc alice file.txt
    /dcc send -address 203.0.113.10 -port 5000 alice file with spaces.txt
    /dcc list
    /dcc accept 1 /home/me/private-downloads
    /dcc reject 2
    /dcc cancel 3

استبدل عنوان IP التوضيحي بعنوان يمكن الوصول إليه. يمثل PATH بقية نص الأمر حرفياً، بما فيها المسافات، من دون علامات اقتباس خاصة بالصدفة. تشير المسارات النسبية إلى cwd عند بدء البرنامج، حتى بعد نقله إلى الخلفية أو تصفح الملفات. العنوان المعلن افتراضياً هو IPv4 المحلي لمقبس IRC؛ وتتطلب اتصالات IRC المحصورة في IPv6 تحديد IPv4 صراحة، وقد يتطلب NAT ذلك أيضاً. يستخدم أمر accept من دون DIRECTORY مجلد البدء مع اختبارات الخصوصية نفسها. يعرض /dcc بلا معاملات القائمة في الواجهة المبسطة. تشترك الواجهتان في مدير النقل والحدود والإلغاء.

عند استخدام SSH تتبع جميع المسارات والعناوين والاتصالات المضيف الذي يعمل عليه vipirc، لا الحاسوب المحلي الذي يعرض الطرفية. يستمر النقل المقبول عند تبديل المحادثة أو الشاشة وبعد IRC Disconnect. يؤدي إغلاق خادم المنشأ إلى إلغاء عملياته، ويوقف الخروج من البرنامج جميع العمليات. يزيل الفشل أو الإلغاء أو انتهاء المهلة عرضاً لم يُرسل بعد من الطابور، لكنه لا يستطيع استرجاع عرض أُرسل بالفعل أو جارٍ إرساله.

حدود مساحة العمل هي 8 عروض معلقة و4 عمليات نقل نشطة أو مستمعة أو جارٍ اتصالها و12 سجلاً محفوظاً. عند امتلاء السجلات فقط، تُعاد الاستفادة أولاً من أقدم السجلات المكتملة أو الفاشلة؛ ولا يُعاد استخدام ID خلال تشغيل واحد. تنتهي صلاحية العروض بعد 5 دقائق، ويتوقف النقل بعد دقيقتين دون تقدم. يستخدم بث البيانات مخازن محدودة الحجم وإشعارات استلام تراكمية من 32 بت. يسمح وضع الاختبار بمراجعة عينة في الذاكرة ورفضها أو إلغائها؛ ويُرفض Send/Accept قبل أي عملية على ملف أو مقبس.

===== SOURCE CHAPTER: INPUT EDITING =====
تحرير الإدخال

    Enter                 إرسال النص أو مراجعته.
    Left/Right            مجموعة المحارف السابقة أو التالية.
    Up/Down               التنقل بين أسطر الإدخال الملتفة، لا استدعاء سجل المحادثة.
    Home/End              بداية النص الكامل أو نهايته.
    Backspace/Delete      حذف مجموعة المحارف السابقة أو الحالية.
    Tab/Shift-Tab         إكمال اسم المستخدم التالي أو السابق.
    Escape                فتح Queries من محادثة خاصة، وإلا فتح vipirc.
    /clearinput           مسح المسودة بأكملها، بما فيها النص خارج الشاشة.

تفتح F1..F6 اللوحات المتاحة. الأحرف المكتوبة في المحادثة، بما فيها hjkl، نص حرفي وليست اختصارات تنقل. يرسل Enter الذي تضغطه الرسالة؛ ولا تدخل فواصل الأسطر المقصودة إلا عبر bracketed paste، وتتحول علامات الجدولة الملصوقة إلى مسافات. تؤدي كتابة / عندما يكون المؤشر في الموضع صفر إلى فتح حقل Command مستقل مع حفظ المسودة؛ أما الشرطات المائلة اللاحقة أو الملصوقة فهي نص عادي.

المسودة مخزن نصي منطقي واحد: التفاف السطر على الشاشة لا يضيف أي أحرف، ويعبر Backspace حدود الأسطر المرئية، وتحافظ إعادة تحجيم الطرفية على النص والمؤشر. يحجز الحقل الثابت floor(B/W)+1 سطراً وفق ميزانية الحمولة B والعرض المتاح W، ضمن المساحة الفعلية للطرفية. لا تغير الكتابة أو الحذف ارتفاع الحقل، بل تُمرر المسودة الطويلة داخله. ويعاد حساب الارتفاع عند تغير العرض أو ميزانية البروتوكول أو أبعاد الطرفية. لحقل Command مساحة مستقلة، ولا يستبدل /msg أو /me مسودة المحادثة.

ينتظر Escape المفرد الخام نحو 500 ms؛ وتتيح سلسلة المفاتيح غير المكتملة 1000 ms بين بايتات المتابعة فيما يستمر عمل الشبكة. تعمل المفاتيح التي اكتمل فك ترميزها فوراً. إذا تأخرت علامة بداية اللصق عن مهلة Escape الأولى فقد تُعامل بوصفها Escape؛ وقد يؤدي ذلك في سجل الواجهة المبسطة إلى نقل العميل إلى الخلفية. بعد بدء التقاط اللصق، تظل علامات الإغلاق معروفة حتى بين قراءات مجزأة متباعدة بلا حد محدد. ولا تستطيع المفاتيح التالية إلغاء المسودة أو تبديل النمط قبل حد المراجعة المرئي أو فترة الإدخال الهادئ.

يتطلب الإدخال UTF-8 صالحاً أو نمط إعداد محلي ASCII جرى اختياره صراحة؛ انظر FILES AND ENVIRONMENT. يتحرك الحرف الأساسي مع العلامات التالية عديمة العرض أو يُحذف معها كوحدة؛ ولا يتوفر التقسيم الكامل لعناقيد Unicode الكتابية. تظهر علامة بديلة مرئية للرسوم غير المدعومة. حدود المسودة 8192 قيمة Unicode قياسية أو 16384 بايت UTF-8، أيهما يتحقق أولاً. تُرفض الترميزات ومحارف التحكم غير الصالحة. تبقى فواصل الأسطر الملصوقة مرئية وتؤثر في خطة الإرسال؛ وتحدد ميزانية IRC الأصغر التحذيرات وتقسيم الرسائل.

التحكم بالفأرة

تكون الفأرة مفعلة افتراضياً إذا دعمتها curses وTERM والطرفية. يبدل /mouse الحالة، ويحدد /mouse on|off الوضع صراحة، وتغير Settings > Interface تفضيل mouse في قسم [interface] من الإعدادات الرئيسية وتحفظه. تعمل لوحة المفاتيح دون فأرة أيضاً، ويجب أن تمرر الطرفية أو مضاعف جلسات SSH أحداث الفأرة.

يفتح النقر على فئة الترويسة تلك الفئة؛ وينقل النقر في المحادثة المؤشر؛ ويمسح Clear المسودة بأكملها؛ ويرسل Send الرسالة بعد الفحوص المعتادة. يختفي Clear/Send عند عدم توفرهما. تعرض أسماء المستخدمين في المحادثة أو القائمة Whois/Query؛ ويختار النقر على #channel القناة أو ينضم إليها. تحدد هوية العنصر المعروض لحظة النقر الإجراء، لا عنصر يحل محله لاحقاً في الموضع نفسه. لا تُفتح الروابط URL أو محتويات الحافظة تلقائياً.

يفتح النقر على صف عنصر الخادم أو القناة أو المحادثة الخاصة؛ ويطبق النقر على الإجراء ما اختير. تغير عجلة الفأرة العنصر المحدد من دون تغيير الإجراء. وعند التاريخ أو قائمة المستخدمين، تمرر ثلاثة أسطر مرئية أو ثلاثة مستخدمين. تحتفظ Settings وtransfers بعناصر التحكم الخاصة بحقولهما وإجراءاتهما. تحتاج المحادثة إلى 9 أسطر و20 عموداً على الأقل؛ وتبقي الترويسات الضيقة التركيز مرئياً.

لا تؤكد الفأرة نوافذ التحذير المبكر من طول الرسالة أو تقسيم الإرسال؛ استخدم الاختيارات بلوحة المفاتيح. يتطلب Command Run/Cancel إجراءً جديداً بعد اللصق. لا تستطيع سلاسل النقر أو فواصل الأسطر الملصوقة تنشيطه، ولا يعاد استخدام نقرات التخطيط السابق في شاشة فتحت حديثاً.

===== SOURCE CHAPTER: MESSAGE LENGTH AND FLOOD PREVENTION =====
طول الرسائل والوقاية من الإغراق

الحد المعتاد لسطر IRC هو 512 بايت بما في ذلك CR/LF، وليس 512 حرفا ظاهرا على الشاشة. تستهلك القيمة القياسية الواحدة في UTF-8 ما بين 1..4 بايت، وقد يتكون الرمز المعروض من عدة قيم. كما يشغل الأمر والوجهة وهوية المرسل التي يضيفها الخادم جزءا من المساحة. في الرسالة :nick!user@host PRIVMSG target :text تحسب مساحة المحتوى كما يلي:

    B = L - (len(nick) + len(user) + len(host)
             + len(target) + len("PRIVMSG") + 9)

تقاس الأطوال بالبايت. تكون L مساوية 512 أو قيمة LINELEN أصغر معترف بها. وتخصم رسائل الإجراءات أيضا حجم الغلاف الخاص بها. تستخدم حدود متحفظة قبل معرفة الهوية. وقد يؤدي تغيير الهوية أو الوجهة إلى تغيير B؛ ولا يفترض vipirc قبول أسطر أطول.

يعرض محرر ncurses الكامل تحذيرا عند بلوغ سطر منطقي القيمة B أو عندما تتطلب المسودة عدة رسائل. لا يؤدي Enter/Escape إلا إلى تأكيد متابعة التحرير دون إرسال شيء. ولا تستطيع المفاتيح الأخرى إغلاق التحذير، مع حماية من تكرار الضغط. ويعاد تفعيل التحذير إذا انخفض طول النص دون الحد.

أما المحرر المبسط فيمنع إضافة مزيد من النص عند الحد حتى يسمح Enter صراحة بمتابعة التحرير؛ ولا يرسل هذا الضغط شيئا. يمكن استخدام Backspace/Delete لتقصير النص، ويستخدم Escape للإلغاء. تحسب /msg و /me و // وفق الحمولة الفعلية للرسالة، بخلاف الأوامر المحلية غير المرتبطة بها. يبقى النص الملصق كاملا ضمن حدود التخزين، ويجري فحصه بعد استقباله.

يسأل وضع ncurses الكامل عن موافقة مستقلة قبل إرسال مسودة تحتاج إلى تقسيمها على عدة رسائل:

    This text needs N IRC messages. Send all to TARGET? [y/N]

لا يرسل النص إلا عند الإجابة y؛ أما Enter/n فيرفض الإرسال ويحافظ على النص. يعرض الوضع المبسط Review: يؤكد ضغط جديد على Enter الإرسال، ويعيد Escape المستخدم إلى التحرير. ويشترط كلا الوضعين موافقة صريحة على التقسيم حتى في وضع direct. يحافظ التقسيم على قيم UTF-8 كاملة وعلى مقاطع نصية غير فارغة؛ وتفصل نهايات الأسطر الصريحة الرسائل، وتتجاوز الأسطر الفارغة. تبقى الأوامر في سطر واحد؛ اكتب المحادثة متعددة الأسطر في محرر المحادثة.

ترسل رسائل المحادثة بفاصل لا يقل عن 1.2 ثانية من خلال طابور سعته 64 رسالة. يزيل /cancel الأعمال التي لم ترسل بعد، لكنه لا يستطيع استرجاع رسالة قيد الإرسال أو وصلت بالفعل. تعالج أوامر البروتوكول مثل PONG على نحو منفصل. وقد تفرض الشبكة حدودا أشد أو ترفض النص؛ ولا يعد القبول أو الصدى المحلي دليلا على التسليم للطرف الآخر.

===== SOURCE CHAPTER: CONFIGURATION =====
الإعدادات

أنشئ نقطة بدء خاصة قابلة للتعديل بالأمثلة التالية، ثم حرر الملف وتحقق منه:

    vipirc --init-config --server irc.ircnow.org --channel '#ircnow'
    vipirc --check-config

يصف كل ملف ملفاً شخصياً واحداً؛ ويختار --config الإعداد الرئيسي وفهرس الخوادم المحفوظة المجاور له. تتشارك حتى ثمانية ملفات عملية واحدة، وتكوّن المسارات الرئيسية المنفصلة مساحات عمل مستقلة. تقدم الأمثلة المشحونة و--init-config الصياغة الكاملة. مخطط المفاتيح أدناه مرجع وليس كتلة جاهزة للصق: كل سطر فعلي من key=value يجب أن يكون منفرداً.

الإعدادات الافتراضية هي send_mode=direct وcomposer_mode=line وcommand_suggestions=common وformat=compact وdefault_interface=ncurses. تحفظ تفضيلات التطبيق في الملف الأساسي وتطبق على جميع الخوادم؛ أما connection/auth/bouncer وقوائم watch وignore وأوامر البدء فتخص كل ملف. قسم [hotkeys] فارغ افتراضياً ويقبل حتى 64 سطراً من KEY=action.

يختلف لقب IRC عن username. إن كان لقب الملف الأساسي التفاعلي فارغاً تظهر مطالبة تقترح اسم حساب الدخول. يُستمد username افتراضياً من الحساب؛ وrealname وصف لحقل USER وليس بالضرورة الاسم القانوني. channel قائمة autojoin لملف مباشر مفصولة بفواصل دون مسافات؛ وفراغها يعني عرض الخادم. يستعيد bouncer عضوية القنوات بنفسه.

في SASL المباشر، يتطلب auth=sasl قيمة auth_user ومصدراً واحداً بالضبط لـpassword. يختار PASS الخاص بالخادم مصدراً واحداً مستقلاً لـserver_password. وجود أكثر من مصدر للاعتماد نفسه خطأ بلا بديل احتياطي، وكلاهما يشترط TLS متحققاً منه. يتطلب bouncer أن يكون auth_user فارغاً ويشتق بيانات دخوله. تبقى الأسرار المكتوبة داخل الملف نصاً واضحاً؛ قواعد الملفات وGPG تحت AUTHENTICATION.

يقبل history_lines بين 50..5000 سطر لكل عرض، والافتراضي 500، مع حد نص قدره 8 MiB لكل خادم قد يطرد أسطراً أبكر. للوضع المبسط حدان إجماليان أيضاً: 2048 سجل و512 KiB. تقبل القيم المنطقية بحروف صغيرة true/false وyes/no و1/0. تؤدي الأقسام أو المفاتيح المجهولة والقيم غير الصالحة أو الكبيرة جداً إلى خطأ مع رقم السطر عند الاقتضاء. أغلب المفاتيح المكررة تأخذ آخر قيمة؛ وتُجمع إدخالات watch/ignore/autocommand المتكررة حتى حدودها.

الأسطر التي تبدأ بـ# أو ; بعد الفراغات الأولية هي تعليقات؛ ولا توجد تعليقات في نهاية أسطر القيم. تُزال الفراغات الخارجية من القيم العادية. لا توجد صيغة اقتباس أو هروب أو توسيع متغيرات أو علامة tilde أو تنفيذ للصدفة. فضّل المسارات المطلقة الحرفية. يرفض Apply/Save فراغات ASCII الخارجية في الحقول المعتادة كي لا تتغير بعد إعادة القراءة؛ وتبقى الفراغات الداخلية مسموحة عندما تكون صحيحة.

تحافظ الأسطر password= وserver_password= و[autocommands] command= على كل بايت بعد = عدا نهاية السطر، بما في ذلك المسافات و= و# و;. لا تُضف علامات اقتباس أو تعليقاً في السطر نفسه. كلمة المرور الفارغة تعني عدم وجود مصدر؛ أما المسافات وحدها فغير فارغة. عناصر التحكم والأسطر الجديدة في كلمة المرور غير صالحة.

يعيد /save كتابة الإعدادات المدعومة، بما فيها الخيارات المعلقة، ويستبدل التعليقات والتنسيق؛ احتفظ بملاحظاتك منفصلة. تُحمّل تعديلات الملفات عند بدء عملية جديدة، لا عبر --resume. يُمنع Save في test mode. تُنشأ الملفات بصلاحية 0600 داخل دليل نهائي مملوك للمستخدم بصلاحية 0700؛ ويجب أن يكون ملف الإعداد الموجود مملوكاً له وغير قابل للكتابة من الآخرين. تُرفض الوصلات الرمزية بما فيها مكونات المسار، وكذلك '..'. أي كلمة مرور مضمّنة غير فارغة أو قائمة أوامر بدء حتى لو كانت معطلة تتطلب ملفاً عادياً مملوكاً للمستخدم بصلاحية 0600/0400. يُستبدل كل ملف ذرياً، لكن مساحة العمل كلها ليست معاملة واحدة.

يمنع single_session=true تشغيل عامل vipirc مدار ثانٍ، لا عدة خوادم ضمن العامل نفسه. افتراضيات presence في المخطط؛ وتعطل autoaway_minutes=0 مؤقت الخمول. تمحو العودة التلقائية الغياب الذي أنشأه العميل فقط، ولا تمحو /away اليدوي. غياب bouncer التلقائي معطل افتراضياً بصورة مستقلة.

تُقبل المفاتيح القديمة [interface] keymap=original|vim وfocus_style=reverse|brackets لكن يجري تجاهلها وحذفها عند Save؛ وأي قيم أخرى غير صالحة. تبقى الملاحة المعتادة وإبراز التركيز بأقواس عريضة. يشرح /keymap هذا التوافق ولا يختار تعيين أزرار. يمكن إخفاء إشعارات queue/program مستقلة، فيما تظل الأخطاء وتأكيدات السلامة المطلوبة ظاهرة.

===== SOURCE CHAPTER: HISTORY, LOGGING AND PRIVACY =====
السجل والتسجيل والخصوصية

توجد أنواع منفصلة من السجلات:

    المحادثات والإشارات المحتفظ بها: ذاكرة محدودة للعرض.
    استدعاء الأوامر السابقة: أسطر أوامر مقبولة في الذاكرة بعد ترشيح الأسرار.
    عدد مرات استخدام الأوامر: الأسماء القياسية والعدادات في CONFIG_PATH.commands.
    نسخة نصية اختيارية: سجلات نصية غير مشفرة في ملف .log لكل ملف تعريف محفوظ.
    إعادة عرض bouncer: رسائل يقدمها الوسيط وفق سياسته الخاصة.

يحافظ Detach/resume على ذاكرة الجلسة الحية. وتنهيها /quit أو --close-session أو تعطل العملية أو إعادة تشغيل الجهاز. تحمل العملية الجديدة الإعدادات المحفوظة وعدادات الأوامر الاختيارية، لكنها لا تستورد ملفات النصوص القديمة كسجل حي للمحادثات ولا تعيد إنشاء علامة catch-up السابقة. يمسح /clear السجل المحتفظ به في العرض الحالي من الذاكرة دون حذف النسخة النصية الموجودة على القرص أو سحب رسالة IRC.

لتفعيل النسخة النصية نفذ /set persistent_logging on ثم احفظ باستخدام /save output، أو اختر Settings > Interface > Persistent logging. تكون الميزة معطلة افتراضيا، وتنطبق على جميع الخوادم، مع ملف مستقل لكل ملف تعريف محفوظ. وتظل فحوص خصوصية المسارات والملفات الواردة في CONFIGURATION سارية.

يتوقف كل سجل عند 16 MiB، ولا تجري تدوير الملفات أو حذفها تلقائيا. يؤدي المسار غير الآمن أو القفل المشغول أو فشل الكتابة إلى تعطيل التسجيل لملف التعريف المتأثر مع إظهار خطأ، مع استمرار المحادثة. أرشف الملف القديم ثم أوقف التسجيل وأعد تفعيله للمتابعة. وقد يؤدي تدوير السجل إلى إبطال علامة catch-up القديمة؛ أرسل رسالة جديدة مؤهلة قبل الاعتماد على الاستعادة الدائمة بعد غياب لاحق.

تستبعد الرسائل المعروفة الخاصة ببيانات الاعتماد والخدمات ونسخها الحساسة تحت الأسماء المستعارة الحالية أو القديمة، بما في ذلك وجهات الخدمات المؤهلة. ومع ذلك قد تدخل المحادثات العادية أو صياغات الخدمات غير المعروفة أو الأسرار الملصقة يدويا في السجل، وقد تحتفظ الخدمة البعيدة بنسختها. يمنع إيقاف التسجيل إضافة سجلات جديدة دون حذف القديمة. أذونات الملفات الخاصة ليست تشفيرا ولا تحمي من برنامج آخر يعمل تحت حساب Unix نفسه. كما قد تؤخر الملفات العادية على وحدات تخزين بطيئة أو شبكية عمليات الإدخال والإخراج.

تسمى النسخة النصية المحفوظة CONFIG_PATH.log، وتوجد في دليل يملكه المستخدم بوضع أذونات مطابق تماما لـ 0700. ويجب أن يجتاز كل جزء من المسار فحوص منع الروابط الرمزية والعبور إلى الدليل الأب. ويجب أن يكون الملف المفتوح عاديا ومملوكا للمستخدم وله رابط ثابت واحد فقط ووضع أذونات مطابق تماما لـ 0600. ترفض معالجة الملفات والأقفال غير الحاجبة أنابيب FIFO أو السجلات المشغولة؛ وينطبق حد 16 MiB على كل ملف تعريف محفوظ.

===== SOURCE CHAPTER: SAVED SERVER PROFILES =====
ملفات تعريف الخوادم المحفوظة

بالنسبة إلى المسار الأساسي P، يسرد الفهرس المجاور P.servers ما يصل إلى سبعة ملفات تعريف ثانوية داخل الدليل الخاص P.d. وفي المسار الافتراضي تكون الملفات config.ini.servers والدليل config.ini.d بجوار config.ini. تتكون صيغة الفهرس من [servers] ثم إدخالات متكررة من نوع profile=ID. وتأخذ الأسماء المنشأة شكل server-<24 رمزا سداسيا عشريا بحروف صغيرة>.ini. يمكن أن يتكون المعرف اليدوي من 1 إلى 63 حرفا من ASCII أو رقما أو شرطة سفلية أو واصلة أو نقطة؛ ويجب أن يكون أول رمز حرفا أو رقما، ويمنع تكرار نقطتين متتاليتين. ولا تقبل أجزاء مسارات الأدلة أو المسارات الاعتباطية بصفتها معرفات لملفات التعريف.

لا ينشئ Servers > New أي ملف. وينشئ أول /save صريح أو Settings Save ملف تعريف منفصلا بأذونات 0600 داخل دليل بأذونات 0700 ويسجله في الفهرس. وتحدث عمليات الحفظ اللاحقة ملف تعريف ذلك الخادم. ولا تؤدي كتابة ملف تعريف ثانوي إلى استبدال الإعدادات الأساسية. وتحمى تحديثات الفهرس أثناء بدء التشغيل بقفل. تظهر أخطاء واضحة للمدخلات غير الصالحة؛ وتظل ملفات التعريف السليمة قابلة للاستخدام.

يزيل Close الإشارة إلى ملف التعريف الثانوي من الفهرس مع الاحتفاظ بملفه. ولا يمكن إغلاق الملف الأساسي. يفحص --check-config الملف الأساسي والفهرس والملفات المشار إليها دون إنشاء اتصال. وعند بدء التشغيل العادي تطبق خيارات تجاوز الاتصال التي لا تغير اسم المضيف على الخادم الافتراضي المحفوظ؛ أما --server فيختار الملف الأساسي صراحة. ويطبق --init-config و --check-config خيارات التجاوز الخاصة بهما على الملف الأساسي أيضا. يمنع --no-connect الاتصال التلقائي لجميع الملفات عند البدء. وفي وضع الاختبار يعطل Save ويؤثر Close في الحالة الجارية فقط.

===== SOURCE CHAPTER: AUTOMATIC CONNECTION, JOIN, AND AUTHENTICATION =====
الاتصال التلقائي والانضمام والمصادقة

لكل ملف تعريف محفوظ إعداداته المستقلة للاتصال التلقائي والانضمام المباشر إلى القنوات وبيانات الاعتماد. احفظ إعدادات البدء المطلوبة عبر Settings أو الأوامر. يبدأ الخيار --server المحدد صراحةً للملف الرئيسي اتصالاً، وتبدأ ملفات autoconnect المحفوظة بصورة مستقلة. يمنع --no-connect جميع اتصالات البدء. ويبدأ /connect أو Servers > Connect اتصالاً صراحةً. لا يرث أي ملف جديد أسرار ملف آخر.

لإعداد حساب شبكة مباشر، استخدم:

    [connection]
    tls=true
    auth=sasl
    auth_user=your_registered_account
    password_gpg_file=/home/yourname/.config/vipirc/sasl.gpg

اختر مصدراً واحداً بالضبط لكل بيانات اعتماد مستقلة:

    حساب SASL                     PASS للخادم
    password_gpg_file              server_password_gpg_file
    password_file                  server_password_file
    password                       server_password

المصدر *_gpg_file مشفّر؛ و*_file ملف خاص بنص صريح؛ والقيم المضمّنة في الإعداد نص صريح حرفي. لا يعتمد الاختيار على تخمين امتداد الملف، ولا توجد محاولة بمصدر بديل عند الفشل. تُحفَظ المسافات في بداية القيم المضمّنة ونهايتها، وكذلك الرموز # و; و=؛ فلا تضف علامات اقتباس أو تعليقات. يجب أن يكون ملف الإعداد المحتوي على أسرار مضمّنة ملفاً عادياً يملكه المستخدم بصلاحيات 0600/0400؛ ويحفظ Save الملفات الجديدة بصلاحيات 0600. تبقى القيم في إعداد الجلسة عند الحاجة إليها لإعادة الاتصال أو الحفظ.

يجب أن تكون كلمة المرور النصية أو الناتجة من فك التشفير سطراً واحداً غير فارغ، يمكن أن ينتهي بـ LF/CRLF، ومن دون بايتات تحكم: حد SASL هو 1024 بايت وحد PASS العادي 503 بايت. يجب أن يكون كلا نوعي الملفات عادياً ومملوكاً للمستخدم بصلاحيات 0600/0400، وألا يحتوي المسار على روابط رمزية أو المكوّن '..'. لا تُقبل كلمة المرور خياراً لسطر الأوامر CLI. راجع BOUNCER CONNECTIONS لقيود المصادر وهويات خوادم الوساطة.

تحتوي الملفات المشفرة على رسالة OpenPGP واحدة محمية السلامة بحجم لا يزيد على 65536 بايت. يجب أن يدعم برنامج gpg الاختياري الموجود في PATH الخيارات الثابتة (GnuPG 2.2.20 أو أحدث). يُشغّل مباشرة بعد التحقق من TLS ومن دون shell، مع حد للمخرجات ومهلة خمس ثوانٍ. لا يُنشأ ملف مؤقت لكلمة المرور الصريحة، ولا تُطلب عبارة مرور المفتاح داخل التطبيق؛ وتستمر الجلسات الأخرى. توقف المصادقةَ بياناتُ اعتماد فاشلة أو مقفلة أو غير صالحة أو كبيرة جداً أو تجاوزت المهلة.

يستخدم البرنامج المساعد --no-options و--batch و--no-tty و--pinentry-mode error و--no-autostart، مع تعطيل جلب المفاتيح واستيرادها وdirmngr. جهّز المفتاح أو افتح قفله خارج vipirc:

    gpg --output /dev/null --decrypt /absolute/password.gpg

ثم أعد محاولة /connect. يحتوي هذا الأمر على مسار، لا على كلمة مرور. يجب أن يستطيع الوكيل الموجود فك التشفير دون تفاعل؛ فقد تختلف الملفات وPATH ومجلد GnuPG وذاكرة الوكيل بين جهاز SSH وجلساته.

يفحص --check-config اختيار مصادر الاعتماد وخصوصية الإعداد دون فتح الأسرار أو تشغيل GPG. ولا يقرأ --test-mode الاعتمادات أو يفك تشفيرها مطلقاً؛ تُحلَّل القيم المضمّنة ولكن لا تُستخدم. لا يثبت أي من الفحصين صلاحية بيانات اعتماد حقيقية.

لا يُرسل SASL PLAIN الإلزامي إلا بعد التحقق من TLS وتأكد دعم الخادم. وعند الفشل يتوقف الاتصال قبل الانضمام التلقائي المباشر إلى القنوات، بدلاً من المتابعة دون مصادقة. لا ينشئ العميل حسابات شبكة. تختلف أوامر خدمات الأسماء المستعارة باختلاف الشبكة؛ وتستخدم مصادقة الحساب المباشر التلقائية SASL. تختلف كلمة PASS للخادم عن حساب الاسم المستعار؛ وتُضبط مصادقة خادم الوساطة للاتصال العلوي بصورة منفصلة.

===== SOURCE CHAPTER: BOUNCER CONNECTIONS =====
الاتصال عبر خوادم الوساطة BOUNCER

اختر ZNC أو soju من Settings أو /panel، ثم أدخل اسم مضيف المزوّد ومنفذ TLS، واسم مستخدم خادم الوساطة، والشبكة العليا الموجودة مسبقا، واسم عميل ثابت اختياريا. احفظ ملف تعريف مستقلا لكل شبكة. إذا تشاركت ملفات تعريف مضيفا واحدا، فحدد رقم الخادم قبل تنفيذ /connect بلا معاملات.

يدعم القسم [bouncer] القيم type=none|znc|soju و username و network و client و automatic_away. حقلا username و network إلزاميان، و client اختياري. لا يسمح كل مكون إلا بحد أقصى 63 محرفا من ASCII: حروف وأرقام ونقاط وشرطات سفلية وواصلات. أدخل مكونات الهوية كلّا على حدة ولا تضع كلمة المرور إلا في مصدر كلمات المرور المخصص لها.

يتطلب ZNC القيمة auth=none و auth_user فارغا، وعدم وجود مصدر SASL، ومصدرا واحدا بالضبط لكلمة مرور الخادم. يبني الهوية username/network أو username@client/network ويضيف كلمة المرور ضمن PASS. يجب أن تتسع حمولة 503 بايت للهوية والفواصل وكلمة المرور معا، ولذلك تقل المساحة المتاحة لكلمة المرور. يتطلب soju القيمة auth=sasl و auth_user فارغا ومصدرا واحدا لكلمة مرور المصادقة، ولا يسمح بمصدر PASS. يشتق هوية SASL على صورة username/network أو username/network@client. يشترط كلاهما اتصال TLS تم التحقق منه. اضبط الشبكة العليا ومصادقة NickServ على خادم الوساطة بشكل مستقل.

تستعيد خوادم الوساطة العضوية في القنوات، فلا يعاد تنفيذ autojoin المحلي وترفض تعديلات /autojoin. يغير /join و /part العضوية. وترفض تعديلات /autoauth أيضا؛ استخدم Settings أو /panel لتغيير الهوية والمصادر بصورة متسقة. تظل أوامر البدء الصريحة تنفذ، لذا راجع أي أوامر موروثة من ملف اتصال مباشر قبل إعادة استخدامه. يتوقف تغيير حالة الغياب تلقائيا عند الخمول أو العمل في الخلفية ما لم تكن automatic_away=true؛ وتبقى أوامر /away و /back اليدوية متاحة.

    /znc
    /znc ListNetworks
    /soju
    /soju network status

تتطلب هذه الاختصارات نوع خادم الوساطة الموافق لها. معاملات الأوامر نص خدمات حرفي يجب أن يسع رسالة IRC واحدة، وتخضع لوتيرة الإرسال العادية. يتوجه /msg *status و /msg *module إلى ZNC، ويتوجه /msg BouncerServ إلى soju. يحدد الخادم البعيد الأوامر المتاحة؛ ابدأ بطلب المساعدة الخاصة به.

يستبعد نص التحكم من الصدى المحلي واسترجاع الأوامر والسجلات الدائمة. وتظل نسخ إعادة التشغيل المعروفة لرسائل الخدمات الصادرة محجوبة حتى مع الأسماء المستعارة القديمة. تظهر الردود في عرض الخادم دون تسجيل دائم. يبقى النص المكتوب في المحرر ظاهرا، أما التسجيل على الطرف البعيد فمستقل.

يحافظ السجل المدفوع المعروف على الطوابع الزمنية UTC الأصلية ويوجه الرسائل الخاصة الصادرة إلى مستلميها. لا تؤدي إعادة التشغيل إلى تشغيل CTCP/DCC أو إنشاء إشارات جديدة أو تغيير الحالة المباشرة. التخزين محدود؛ وتعرض أنواع الدفعات غير المعروفة بحذر دون التأثير على الحالة. لا يوجد متصفح أرشيف عند الطلب ولا اكتشاف تلقائي للشبكات ولا إنشاء تلقائي لملف تعريف لكل شبكة.

يحمي TLS الاتصال بين العميل وخادم الوساطة فقط. يجب تهيئة TLS والمصادقة والوصول والاحتفاظ بالسجلات في الشبكة العليا بصورة منفصلة. راجع doc/BOUNCERS.txt و examples/bouncer-znc.ini و examples/bouncer-soju.ini. لا تثبت نتائج الاختبارات المضبوطة التوافق مع كل مزود فعلي أو كل إصدار.

===== SOURCE CHAPTER: TLS AND CUSTOM TRUST =====
TLS وجهات الثقة المخصصة

يتحقق TLS الموثق من اسم المضيف أو العنوان الرقمي المطلوب ومن سلسلة الشهادات. ولا توجد طريقة لتجاوز التحقق أو الرجوع بصمت إلى اتصال نصي غير مشفر؛ ولا يؤدي رقم المنفذ وحده إلى تعطيل TLS. استخدم نقطة الاتصال الدقيقة التي يحددها المزود. يختار --ca-file FILE أو [connection] ca_file=FILE سلطات شهادات PEM بدلا من مخزن الثقة الافتراضي لمكتبة TLS؛ وهذا اختيار لجهات ثقة مخصصة، وليس تثبيتا للشهادة النهائية.

يجب أن تكون حزمة شهادات CA المخصصة ملفا عاديا غير فارغ بحجم <=16 MiB. يسمح بالروابط الرمزية العادية التي تشير إلى ملفات CA العادية، خلافا لمسارات الإعدادات وبيانات الاعتماد. يفتح المحمل الملف مرة واحدة بأعلام غير حاجبة، ويقرأ من واصف ملف ثابت ضمن الحد المسموح، ويرفض تغير الحجم الذي يكتشفه. وترفض أنابيب FIFO والأجهزة والمدخلات غير العادية. يحافظ محلل PEM المحدود الذاكرة على بيانات الثقة الخاصة بالشهادات وقوائم CRL المدعومة، ولا يمكنه طلب كلمة مرور.

لا تحد هذه الفحوص من زمن انتظار إدخال وإخراج الملفات العادية أو أنظمة الملفات الشبكية. استخدم تخزينا مناسبا موثوقا. لا يختبر --check-config تحميل CA أو مصافحة TLS، كما أن المحاكاة دون اتصال لا تشغل TLS. تحقق من أخطاء الشهادات قبل تغيير جهات الثقة؛ وترفض بيانات الاعتماد المرسلة نصا دون تشفير. يحمي TLS هذا الاتصال وحده، وليس المحادثة بتشفير شامل من طرف إلى طرف ولا اتصال bouncer بالشبكة العليا. ويظل DCC غير مشفر.

===== SOURCE CHAPTER: SECURITY AND RESOURCE BOUNDS =====
الأمان وحدود الموارد

يتحقق TLS من سلسلة الشهادات ومن اسم المضيف أو العنوان الرقمي المطلوب. ولا يسمح بتجاوز فحص الشهادة أو خفض مستوى الحماية بصمت. لا يتاح IRC غير المشفر إلا بإعداد صريح؛ وعندئذ يمكن للمراقبين على مسار الاتصال قراءة حركة IRC، ولا يمكن استخدام الأسرار المحفوظة. يحمي TLS اتصال العميل بالخادم ولا يوفر خصوصية مشفرة من طرف إلى طرف للمحادثة.

يرفض التشغيل الفعلي اختلاف معرفات المستخدم أو المجموعة الحقيقية والفعالة، ويعطل ملفات تفريغ الذاكرة قبل قراءة الإعدادات. كما يعطل Linux إمكانية تفريغ ذاكرة العملية. يعمل العميل كعملية عادية دون عزل sandbox من نظام التشغيل؛ وتبقى العمليات الأخرى التي تعمل تحت الحساب نفسه ضمن نطاق الثقة.

تتطلب أوامر المصادقة الخاصة المعروفة TLS موثقا حتى لو أدخلت في شكل نص رسالة عادية أو قسمت إلى خطة إرسال أو وضعت في الطابور. ولا يمكن للتعرف الآلي تمييز كل صيغة جديدة للأسرار بطريقة موثوقة؛ فلا تضع بيانات الاعتماد في المحادثة أو وسائط الصدفة.

بيانات IRC الواردة غير موثوقة. تنقى تسلسلات التحكم والتنسيق غير الآمن قبل العرض. لأحجام مخازن الإدخال والشبكة حدود ثابتة. لا ينفذ العميل النص الوارد، ولا يفتح URL، ولا يشغل أوامر الصدفة، ولا يحمل سكربتات أو إضافات، ولا يرد تلقائيا على طلبات CTCP. وتعرض رسائل الإجراءات كنص. تتطلب عروض DCC SEND مراجعة وقبولا صريحين لكل ملف على حدة؛ ولا يشفر TLS اتصالاتها المباشرة.

الحدود في هذا الإصدار:

    جلسات الخوادم لكل عملية                         8
    العروض لكل خادم، بما فيها المدمجة               32
    المستخدمون المحفوظون لكل قناة                 4096
    عبارات الإشارة المخصصة لكل خادم                 32
    أقنعة التجاهل لكل خادم                          32
    رسائل المحادثة المنتظرة لكل خادم                64
    إدخالات سجل الأوامر لكل خادم                    64
    نص سجل الأوامر لكل خادم                     64 KiB
    نص المحادثات المحتفظ به لكل خادم             8 MiB
    القيم القياسية Unicode لكل مسودة              8192
    بايتات UTF-8 لكل مسودة                       16384
    عروض DCC المعلقة في مساحة العمل                 8
    عمليات نقل DCC النشطة في مساحة العمل            4
    سجلات DCC المحتفظ بها في مساحة العمل           12

ينطبق حد السجل على كل خادم، لا على الذاكرة الكلية للعملية. ومع ثماني جلسات يمكن أن يصل النص المحتفظ به إلى 64 MiB. تخصص حالة الخوادم عند الحاجة؛ فلا تحجز الجلسات القليلة ذاكرة ثمانية سجلات كاملة مقدما. وتستهلك المكتبات وبيانات العروض وقوائم المستخدمين والإدخال والنقل ذاكرة إضافية. يبقى سجل المحادثة في الذاكرة فقط ما لم يفعل التسجيل الدائم الاختياري. وعرض الإشارات المنفصل ليس أرشيفا دائما؛ وقد تسجل المحادثات المصدر المؤهلة. الإعدادات وبيانات الاعتماد والسجلات النصية غير المشفرة ملفات محلية تستطيع البرامج الأخرى ذات امتيازات الحساب نفسه قراءتها. ولا يستطيع أي عميل ضمان الأمان في مواجهة كل خادم خبيث أو جهاز طرفي أو نظام تشغيل أو مكتبة تعرضت للاختراق.

===== SOURCE CHAPTER: CREATING ENCRYPTED PASSWORD FILES =====
إنشاء ملفات كلمات مرور مشفرة

لإنشاء بيانات اعتماد GPG استخدم /panel من أي واجهة. اختر الخادم، ثم اختر gpg مصدراً للمصادقة أو كلمة مرور الخادم، ثم اختر create. يعرض الخيار مساراً مطلقاً في مجلد بيانات الاعتماد المجاور للإعداد المحدد. بالنسبة إلى الإعداد الرئيسي الافتراضي:

    ~/.config/vipirc/credentials/account-password.gpg

تستخدم كلمة PASS للخادم الاسم server-password.gpg. تُتجاوز الأسماء الموجودة ويُقترح بدلاً منها أسماء مرقّمة. تعرض اللوحة المسار المطلق الحقيقي؛ وعلامة ~ في المثال توضيحية وليست صيغة حرفية للإعداد. يقبل Enter المكان المقترح، وقد يجهّز المجلدات الخاصة بصلاحيات 0700. مجرد مشاهدة الاقتراح لا تنشئ شيئاً. يتطلب المسار المخصص مجلداً أباً خاصاً موجوداً مسبقاً يملكه المستخدم؛ ولا تتغير صلاحيات المجلدات الموجودة باستخدام chmod. يُفحص المسار وتوافر gpg محلياً قبل طلب المفتاح وكلمة المرور. أدخل البصمة السداسية العشرية الكاملة المكوّنة من 40 أو 64 رقماً لمفتاح تشفير موجود أصلاً في حلقة مفاتيح GPG المحلية، ثم أدخل كلمة المرور المخفية وأعد إدخالها. تبقى الملفات المشفرة الموجودة قابلة للاختيار. تُخزَّن المسارات المدخلة في اللوحة بصيغتها المطلقة؛ لذلك لا يغيّر مجلد بدء التشغيل معناها. لا يُنزّل أي مفتاح أو يُنشأ، ولا يُنشأ ملف لكلمة مرور صريحة.

لا تبدأ عملية التشفير ونشر النص المشفر الجديد المطلوب صراحةً بصلاحيات 0600 إلا عند اختيار Save أو Apply أو Connect النهائي. ويمكن لـ Apply only وConnect once إنشاء النص المشفر مع ترك الإعداد غير محفوظ. تُرفض الملفات الموجودة والروابط الرمزية. لكل عملية مساعدة مهلة خمس ثوانٍ، وتستمر الواجهة في معالجة أحداث الشبكة. إذا فشل التشفير لا تُطبّق الإعدادات، ويُعرض المسار المعني والسبب دون إظهار السر أو مخرجات البرنامج المساعد. يميّز Finish بين الوجهات المقترحة والملفات التي أُنشئت فعلاً. عند النجاح يوجّه إلى /autoauth status للاطلاع على المسارات الكاملة؛ وإذا فشل الحفظ أو اكتمل النشر جزئياً تبقى المواقع المعنية في شاشة المراجعة القابلة للتمرير. ويمكن إعادة محاولة حفظ الإعداد دون إعادة التشفير. لا يحذف الإلغاء إلا الملفات الجديدة التي لم تتغير في تلك المحاولة؛ وتُحتفظ الملفات التي تشير إليها إعدادات محفوظة. يعود Escape سؤالاً واحداً إلى الخلف ويلغي الإنشاء المعلّق؛ ويؤدي إغلاق الإعداد إلى مسح المدخلات المخفية. يرفض وضع عدم الاتصال الإنشاء قبل أي وصول إلى GPG أو حلقة المفاتيح أو الملفات. وللفك لاحقاً، افتح قفل المفتاح الخاص خارج التطبيق عند الحاجة.

===== SOURCE CHAPTER: FILES AND ENVIRONMENT =====
الملفات والبيئة

موقعا التهيئة الأساسية الافتراضيان:

    $XDG_CONFIG_HOME/vipirc/config.ini
    $HOME/.config/vipirc/config.ini

تأخذ XDG_CONFIG_HOME الأولوية إذا لم تكن فارغة، ويجب أن تكون مسارا مطلقا. تستخدم HOME بديلا، وتستعمل معلومات قاعدة بيانات حسابات المستخدمين إذا تعذر الحصول على مسار مطلق للمجلد المنزلي من HOME. يحدد --config FILE تهيئة أساسية أخرى ومساحة العمل المجاورة لملفات تعريف الخوادم المحفوظة. تؤخذ المسارات المكتوبة في التهيئة حرفيا، دون توسيع للمتغيرات أو للعلامة ~ أو بواسطة الصدفة. توضح المتغيرات أعلاه فقط كيفية اختيار المسارات الافتراضية. وتظل الصدفة توسع الوسائط وتتعامل مع علامات الاقتباس كالمعتاد قبل تمرير وسائط سطر الأوامر.

بالنسبة إلى المسار الأساسي P، يخزن P.servers معرفات ملفات التعريف المحفوظة والخيار الاختياري [servers] default=PROFILE_ID الذي تديره /saveconf. يحتوي P.d/ ملفات التعريف الثانوية. قد تتضمن كل تهيئة محفوظة ملف .commands بعدادات الأوامر المعيارية ونص سجل .log اختياريا. يتطلب إنشاء تهيئة أو ملف تعريف ثانوي تنفيذ Save صراحة؛ أما عدادات الأوامر المقبولة فتحدث تلقائيا في مساحة عمل محفوظة موجودة. إذا كان ملف التعريف الافتراضي المحفوظ في الذاكرة مفقودا أو غير قابل للقراءة، يظهر تنبيه ولا يعاد توجيه الاتصال بصمت.

تقترح الواجهة الكاملة $XDG_DATA_HOME/vipirc/downloads مجلدا افتراضيا لاستقبال DCC إذا كانت XDG_DATA_HOME مسارا مطلقا، وإلا تقترح $HOME/.local/share/vipirc/downloads عندما تكون HOME مطلقة. لا ينشأ المجلد المقترح إلا بعد قبول صريح. يستخدم الأمر /dcc accept NUMBER من دون DIRECTORY مجلد بدء العملية، ويشترط أن يكون ملكا للمستخدم وخاصا. لا يغير اختيار مسار أو استعراضه مجلد بدء العملية.

تستخدم PATH للعثور على البرنامج الاختياري gpg. لا تستدعى صدفة لتنفيذه، ويعد البرنامج جزءا من البيئة المحلية التي يجب الوثوق بها. تفسر GnuPG المتغير GNUPGHOME لتحديد بيئة المفاتيح والوكيل. ولا يوسع العميل GNUPGHOME داخل مسارات بيانات الاعتماد. عند الاستخدام البعيد عبر SSH، تكون البيئة والملفات الخاصة بالمضيف الذي يشغل vipirc هي المستخدمة.

يصف TERM إمكانات الطرفية لـ ncurses، ولا يختار ترميز النص. تحدد LANG وLC_CTYPE وLC_ALL الإعدادات المحلية (locale). استخدم إعداد UTF-8 محليا مثبتا ومتوافقا مع الطرفية لتحرير Unicode وحساب عرض الحروف. تساعد الأوامر locale وlocale charmap وlocale -a على فحص المضيف؛ وتختلف أسماء الإعدادات المحلية بين الأنظمة.

ترجمة الواجهة: اضبط VIPIRC_LANG عند تشغيل vipirc على id (الإندونيسية) أو ms (الملايوية) أو tr (التركية) أو es (الإسبانية) أو pt (البرتغالية) أو fr (الفرنسية) أو de (الألمانية) أو ru (الروسية) أو it (الإيطالية) أو ar (العربية). تقبل أيضا قيم مثل id_ID.UTF-8. يستخدم وضعا ncurses و-i الفهرس اللغوي نفسه، وتكون الإنجليزية لغة الرجوع الافتراضية. تحتفظ العملية المنفصلة بلغة العرض التي اختيرت عند بدء تشغيلها. تبقى أوامر IRC المسبوقة بشرطة مائلة ومفاتيح التهيئة وقيم التحكم باللغة الإنجليزية. تترجم هذه النسخة بعض عناصر الواجهة، وليس كل صفحات المساعدة أو تحذيرات الأمان أو الأخطاء. راجع doc/LOCALIZATION.md.

يحترم إعداد LC_CTYPE النشط. يؤدي الإعداد المحلي غير الصالح أو غير UTF-8 إلى اختيار وضع الطرفية ASCII صراحة، ويظهر ذلك في شاشة الترحيب. يرفض إدخال غير ASCII مع رسالة حالة؛ وتعرض نقاط الرمز الواردة خارج ASCII على هيئة '?' دون تغيير النص الشبكي المخزن. لا يخمن العميل الترميزات القديمة ولا يحولها ولا يفرض إعدادا محليا. اختر إعداد UTF-8 مثبتا وأعد التشغيل لاستخدام Unicode. تبقى ASCII مجموعة فرعية من UTF-8 ذات البايت الواحد؛ ولا يغير SSH حدود عدد بايتات IRC.

===== SOURCE CHAPTER: EXIT STATUS =====
رموز الخروج

0     إكمال عادي أو خروج تفاعلي.
1     فشل تشغيلي، مثل فشل التهيئة أو الحفظ أو التحكم في الجلسة.
2     خيارات أو إعدادات غير صالحة، أو عدم وجود طرفية للاستخدام التفاعلي.
130   قاطعت SIGINT شاشة الترحيب بعد تنظيف الطرفية.
131   قاطعت SIGQUIT شاشة الترحيب بعد تنظيف الطرفية.

يؤكد نجاح --background إعداد العملية العاملة محلياً فقط، ولا يثبت تسجيل الدخول إلى خادم IRC البعيد. وإذا فشل إغلاق الجلسة فهذا يعني أن اكتمال الإغلاق لم يُتحقق منه؛ افحص --sessions مجدداً، فقد يكتمل طلب مقبول في وقت لاحق.

===== SOURCE CHAPTER: PLATFORMS, BUILD, AND LICENSE =====
المنصات والبناء والترخيص

تشمل الأنظمة المستهدفة Linux وبيئة Linux في ChromeOS وأنظمة BSD. يتطلب البناء C11 وواجهات POSIX وGNU/BSD getopt_long ومكتبة curses ذات المحارف العريضة وملفات تطوير TLS المتوافقة. لا يحتاج العميل إلى بيئة تشغيل لغة برمجة. ويُستخدم Python 3 للاختبارات وإنشاء الوثائق؛ وتتيح الملفات المصدّرة المرفقة البناء والدردشة عادةً من دونه. راجع INSTALL للاعتماديات.

    ./configure
    make
    make check-offline
    make check
    make install PREFIX="$HOME/.local"

راجع INSTALL للاعتماديات والبناء، وSECURITY.md لنموذج الأمان والحدود، وتقرير التحقق من الإصدار للأنظمة التي اختُبرت فعلاً. يتطلب تشغيل BSD الأصلي تحققاً مستقلاً؛ فاستهداف قابلية النقل لا يُثبت اختبار جميع الأنظمة الشبيهة بـ Unix. يشغّل make check-offline اختبارات CLI/PTY من دون مقبس شبكة؛ وتشمل مجموعة make check الأوسع خوادم تجريبية محلية عبر loopback.

هذا تطبيق تابع لـ ThatIAm.vip (www.thatiam.vip)، صممه remfan1994. تتوفر الشيفرة المصدرية بموجب اتفاقية IALA (Insha-Allah License Agreement) المرفقة، ونصها الكامل في LICENSE.md. وتحتفظ المكتبات المرتبطة بتراخيصها الخاصة؛ راجع NOTICE. كُتب التنفيذ لهذه المواصفات من دون نسخ تنفيذ عميل IRC آخر أو لغة إعداداته.

الوثائق والتحقق

ملف MANUAL.txt في المجلد الجذر هو المرجع المعتمد للواجهة الكاملة من vipirc؛ ويطابقه doc/manual.txt وتضمّنه src/manual.c. يعرضه vipirc --manual وvipirc(1). ويقدّم vipirc -i --manual وdoc/vipirc-idle-manual.txt المرجع المبسّط. تتوفر أيضاً /help و/manual في الواجهتين.

يرشد README.md إلى الإعداد والوثائق؛ ويشرح INSTALL البناء؛ ويبيّن SECURITY.md حدود الأمان. يوضح CONTRIBUTING.md سير التعديل والمراجعة، ويحدد doc/SOURCE-MAP.txt مواضع الشيفرة، ويفهرس tests/README.md الاختبارات، ويشرح DESIGN.md الثوابت. يربط doc/TROUBLESHOOTING.txt الأعراض بخطوات الفحص؛ وتغطي doc/BOUNCERS.txt وdoc/SESSION-CONTROLS.txt وdoc/OPENBSD-VPS.txt العمليات. استبدل أسماء الخوادم والحسابات والمسارات المطلقة الواردة في الأمثلة قبل استخدامها.
