PLATAFORMAS, COMPILAÇÃO E LICENÇA

Os alvos incluem Linux, o ambiente Linux do ChromeOS e os sistemas BSD. Compilar requer C11, interfaces POSIX, GNU/BSD getopt_long, curses de caracteres largos e ficheiros de desenvolvimento TLS compatíveis. O cliente dispensa um ambiente de execução de linguagem. Python 3 é utilizado nos testes e na geração de documentação; as exportações incluídas permitem compilar e conversar normalmente sem Python. Consulte INSTALL para as dependências.

    ./configure
    make
    make check-offline
    make check
    make install PREFIX="$HOME/.local"

Consulte INSTALL para compilar, SECURITY.md para o modelo de segurança e os limites, e o relatório de validação da versão para as plataformas efetivamente testadas. A execução nativa em BSD exige validação própria: a intenção de portabilidade não prova testes em todos os sistemas Unix. make check-offline executa testes CLI/PTY sem socket de rede; make check inclui servidores simulados na interface local.
