ПЕРЕНОС СТРОК И ИСТОРИЯ ВВОДА В МИНИМАЛИСТСКОМ РЕЖИМЕ

Compose резервирует строки для ввода, а над ними показывает последние визуальные строки с переносами; старые строки могут выходить за пределы уменьшенной области. Сохранённый текст и планы отправки не обрезаются. Выйдите из поля ввода или снова выберите беседу, чтобы посмотреть сохранённые строки: локальное эхо не подтверждает доставку. При изменении размера терминала расположение пересчитывается с сохранением черновика и курсора.

В Compose клавиши Вверх/Вниз перемещают курсор даже при удержании. Только Вверх в Command вызывает ранее принятые команды; отправленные сообщения, секретные строки служб и подключения к каналам с ключом не вызываются. Файл .commands содержит только имена и счётчики. См. COMMAND PROMPT, INPUT EDITING и TROUBLESHOOTING.
