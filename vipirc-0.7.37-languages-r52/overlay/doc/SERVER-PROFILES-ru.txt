СОХРАНЕННЫЕ ПРОФИЛИ СЕРВЕРОВ

Для основного пути P соседний каталог P.servers содержит не более семи дополнительных профилей в закрытом каталоге P.d. По умолчанию это config.ini.servers и config.ini.d рядом с config.ini. Формат каталога: [servers] и повторяющиеся записи profile=ID. Автоматические имена имеют вид server-<24 строчных шестнадцатеричных символа>.ini. Идентификатор, заданный вручную, может содержать от 1 до 63 букв ASCII, цифр, подчеркиваний, дефисов или точек; первый символ должен быть буквой или цифрой, две точки подряд запрещены. Компоненты пути и произвольные пути не допускаются в качестве ID профиля.

Servers > New не создает файл. Первое явное /save либо Settings Save создает отдельный профиль с режимом 0600 в каталоге режима 0700 и вносит его в каталог профилей. Последующие сохранения обновляют этот профиль. Сохранение дополнительного профиля никогда не заменяет основную конфигурацию. Изменения каталога при запуске выполняются под блокировкой. Недопустимые записи вызывают видимые ошибки; исправные профили остаются доступными.

Close убирает ссылку на дополнительный профиль из каталога, сохраняя его файл. Основной профиль закрыть нельзя. --check-config проверяет основной профиль, каталог и упомянутые в нем профили без подключения. При обычном запуске переопределения соединения, не меняющие хост, применяются к запомненному серверу по умолчанию; явный --server выбирает основной профиль. --init-config и --check-config также применяют свои переопределения к основному. --no-connect запрещает начальные подключения для всех профилей. В тестовом режиме Save отключен, а Close изменяет только текущее состояние.
