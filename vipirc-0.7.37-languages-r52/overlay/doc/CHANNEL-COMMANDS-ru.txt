Практическое руководство vipirc / onekeyirc - Помощь
==================================================

ЧЕРНОВОЙ ПЕРЕВОД. Пишите команды и параметры точно как показано.
Точные правила безопасности - в английских MANUAL.txt и SECURITY.md.

/help clear
-----

Очищает ограниченную историю этой вкладки в RAM. Не выходит с канала, не отключается, не отзывает сообщения и не удаляет старый лог.

Ранее выведенную прокрутку сохраняет и контролирует сам терминал.

В чате Up назад, Page Up страницу, Home к началу; Down/Page Down вперёд. Новое не сдвигает страницу чтения. End/Escape к потоку; навигация не открывает ввод.

/help ignore
------

Принимает ник или маску nick!user@host с шаблонами * и ?. Совпавшие сообщения и уведомления скрываются локально.

Игнорирование не создаёт личных чатов и упоминаний. Состояние протокола, уведомления сервера и членство работают.

Сохраните маски этого сервера командой /save.

/help join
----

Нужна регистрация. Ключ — один печатаемый токен ASCII; он не сохраняется ни в файле, ни в истории команд.

При прямом соединении канал добавляется в текущий автозаход; при сохранении приоритет у ожидающих изменений /autojoin.

Команда /autojoin задаёт следующее явное соединение прямого профиля без входа сейчас. Bouncer сам ведёт список каналов.

/help part
----

Без канала выходит из выбранного канала. Текст после канала — причина PART; без канала текст относится к выбранному.

Без явной причины берётся part_message, если настроено. Текущая запись автозахода удаляется.

Очередь сообщений канала отменяется; один начатый кадр может завершиться. /close закрывает вкладку.

/help topic
-----

Нужны регистрация и вход на канал. Без текста запрашивает тему, иначе дословно отправляет TEXT.

Сервер решает, позволяют ли ваши права менять тему канала.

/help quit
----

Пытается отправить MESSAGE как причину IRC QUIT на каждом активном сервере; без MESSAGE использует quit_message. Затем восстанавливает терминал и выходит.

Используйте /background, чтобы соединения продолжали работать.
