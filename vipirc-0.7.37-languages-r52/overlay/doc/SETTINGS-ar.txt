دليل عملي لـ vipirc / onekeyirc - الإعدادات
=======================================================

ترجمة أولية. اكتب الأوامر والخيارات كما هي تماما.
للتفاصيل الأمنية الكاملة راجع MANUAL.txt وSECURITY.md بالإنجليزية.

/help set
---------

direct هو الافتراضي: يرسل Enter النص، وتلزم موافقة إذا احتاج الأمر رسائل IRC متعددة.

يضيف review خطوة مراجعة مقصودة قبل وضع الرسائل العادية في الطابور.

output_format compact هو الافتراضي: يعرض الحوار المحدد [HH:MM:SS] <nick> النص.

يضيف output_format full الخادم والتاريخ والهدف لكل سطر. يحتفظ compact بمصدر الإشارات والتشخيصات من الخوادم الأخرى.

يخفي queue_notices off إشعارات الطابور العادية. في الوضع المبسط لا تتكرر رسالة التأكيد بعد المراجعة. تبقى الأخطاء وتأكيد الرسائل المتعددة ظاهرين.

يخفي program_messages off إشعارات محلية ثانوية مثل إلغاء المسودة أو مسح الإدخال أو الاحتفاظ به. تبقى الأخطاء وتأكيدات الأمان ظاهرة.

persistent_logging on: سجل .log خاص (0600) بمجلد 0700. معطل افتراضياً. حد 16 MiB: أرشف ثم بدّل off/on. الملف غير الآمن/المشغول يوقف السجل لا الحوار.

يسمح single_session on بمهمة خلفية واحدة لهذا العميل، فيصبح --resume بلا رقم واضحاً. يمكن استخدام خوادم IRC متعددة في الجلسة.

يحدد default_interface الواجهة عند التشغيل الجديد إن كان مدعوماً، ولا يبدل الحالية. يحفظ /save input الاختيار.

يختار command_suggestions الترتيب الأبجدي أو الشائع أو الأخير أو الأكثر استخداماً أو المناسب لشاشة المنشأ.

يضع composer_mode line سطر إدخال تحت الحوار المباشر؛ يوفر fullscreen محرراً متعدد الأسطر وجزءاً للحوار. الافتراضي: line.

يوفر part_message وquit_message سببي خروج IRC الافتراضيين؛ يعلوهما نص /part أو /quit الصريح. القيمة الفارغة تلغي النص الافتراضي.

يرسل background_away الرسالة background_away_message بعد /background الناجح أو فقد الطرفية. يضبط autoaway_minutes الغياب للخمول؛ 0 يعطله.

يُمسح تلقائياً فقط وضع away الذي أنشأه العميل بعد العودة أو الإدخال الحقيقي. لا يُغير أو يُمسح /away اليدوي.

Common هو الافتراضي. يقدم Contextual أوامر القناة والمحادثة والخادم والعميل دون إخفاء المطابقات الأخرى.

يستخدم Common ترتيباً منتقى مفيداً. يتذكر Contextual الشاشة الأصلية، ومنها قارئ الملخص العام.

هذه تفضيلات للعميل في كل الخوادم. احفظها عبر /save input أو /save output.

يعدل /panel ثم 0 هذه التفضيلات وحد سجل المحادثات العام.
