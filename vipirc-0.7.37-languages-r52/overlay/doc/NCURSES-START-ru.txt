ПОЛНЫЙ ИНТЕРФЕЙС VIPIRC: ПЕРЕВЕДЕННЫЕ ФРАГМЕНТЫ РУКОВОДСТВА
Избранные разделы MANUAL.txt: примеры, запуск, справка, панели, ввод и мышь. Это не полный перевод руководства.

Команды и параметры сохраняют исходное написание:
    vipirc -h
    vipirc -v
    vipirc --test-mode
    vipirc --server irc.ircnow.org --channel '#ircnow' --nick tutankh-aten

Как читать примеры
------------------
Примеры, начинающиеся с vipirc, выполняются в оболочке. Команды с / вводятся в представлении Command. Вводите по одной команде; СЛОВА_ЗАГЛАВНЫМИ обозначают параметры, [элементы] необязательны, а | разделяет варианты.

В поле Command знак / уже введен. Перед вставкой полной команды /command удалите этот знак. Вставленный блок команд не считается сценарием: переводы строк заменяются пробелами. Вставка в чат остается обычным текстом.

Начало соединения
-----------------
Без указанного сервера vipirc открывает рабочую область без соединения. --server выбирает сервер; /connect HOST также подключает. По умолчанию используется проверенный TLS на порту 6697. Для открытого соединения нужен --plain; укажите правильный адрес провайдера.

Начальный экран показывает регистрацию на сервере и MOTD. В полном интерактивном режиме при отсутствии основного ника программа запрашивает его, предлагая локальное имя пользователя. Сервер может отклонить ник.

Шесть основных панелей
----------------------
F1 открывает панель приложения, F2 Servers, F3 Channels, F4 Queries, F5 Mentions/unread, F6 File transfers. Пустые категории могут быть скрыты, но номера функциональных клавиш не меняются.

Escape из личного диалога открывает Queries; из другого чата - панель приложения; из обычной панели возвращает в чат. Для выхода через панель приложения требуется новое нажатие y/Y после вопроса.

Справка и навигация
-------------------
/help или /manual открывает полное руководство в vipirc. /help TEXT выполняет поиск; в просмотрщике / начинает поиск, n и N переходят между совпадениями, Escape возвращает назад. Поиск буквальный, без регулярных выражений.

В списках Up/Down или k/j перемещают по элементам, Left/Right или h/l выбирают действие, Enter выполняет его. Home/End или g/G переходят к краям списка. ? вне поля редактирования открывает контекстную справку.

    vipirc --manual
    /help
    /help TEXT
    /mouse on|off

Редактирование, отправка и вставка
----------------------------------
Чат сразу готов к вводу. Enter отправляет сообщение в выбранный канал или личный диалог. Знак / в начале пустого черновика открывает отдельную строку Command; // отправляет буквальный знак / в начале сообщения.

Left/Right перемещают курсор по группам символов. Up/Down переходят между перенесенными строками ввода, а не между отправленными сообщениями. Home/End ведут к началу/концу черновика; Backspace/Delete удаляют группы символов.

Черновик хранится в одном логическом буфере: перенос на экране не добавляет новую строку, изменение размера терминала сохраняет текст и курсор. Tab/Shift-Tab дополняют ники. /clearinput очищает весь черновик, включая невидимую часть.

Вставка с управляющими маркерами остается буквальным текстом и сама не подтверждает отправку. Длинное сообщение может требовать согласия на длину или отдельного согласия на несколько отправок. Перед Enter проверьте показанный результат.

Мышь и безопасность
-------------------
Мышь необязательна. При поддержке можно щелкать по категориям, чату и элементам списка; терминал должен передавать события мыши. /mouse on|off управляет режимом. URL и содержимое буфера обмена не открываются автоматически.

Внешний вид недоверенного сообщения не доказывает личность автора. Похожие символы Unicode и смешанные направления письма могут обмануть. Оригинальные MANUAL.txt и SECURITY.md на английском остаются главным источником.
