ПЛАТФОРМЫ, СБОРКА И ЛИЦЕНЗИЯ

Целевые системы включают Linux, среду Linux на ChromeOS и семейство BSD. Для сборки нужны C11, интерфейсы POSIX, GNU/BSD getopt_long, curses с широкими символами и совместимые файлы разработки TLS. Клиенту не нужна языковая среда выполнения. Python 3 используется для тестов и генерации документации; готовые экспортированные файлы позволяют собирать и использовать чат без Python. Зависимости описаны в INSTALL.

    ./configure
    make
    make check-offline
    make check
    make install PREFIX="$HOME/.local"

Сведения о сборке и зависимостях находятся в INSTALL, о модели безопасности и ограничениях — в SECURITY.md, о реально испытанных платформах — в отчёте проверки выпуска. Нативная работа на BSD требует отдельной проверки: намерение обеспечить переносимость не доказывает испытаний на всех Unix-подобных системах. make check-offline запускает тесты CLI/PTY без сетевого сокета; более широкий make check также использует локальные имитаторы серверов через loopback.

Это приложение ThatIAm.vip (www.thatiam.vip), разработанное remfan1994. Исходный код предоставляется по прилагаемому соглашению IALA (Insha-Allah License Agreement), полный текст — LICENSE.md.
