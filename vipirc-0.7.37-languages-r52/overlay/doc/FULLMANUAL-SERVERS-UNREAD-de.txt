SERVER UND UNGELESENE AKTIVITÄT

Der vollständige ncurses-Modus führt Serverplätze 0..7 auf; der primäre Server ist 0. Sie verwenden eine gemeinsame Ereignisschleife, besitzen jedoch getrennte Zugangsdaten, Identitäten, Kanäle, Privatdialoge, Erwähnungen, Teilnehmerlisten, Verläufe und Entwürfe. F2 oder /servers öffnet folgende Aktionen:

    Open    New    Connect    Disconnect    Close    Away    Back

Die allgemeine Listennavigation ist unter GLOBAL HEADER AND CHAT CONTROLS beschrieben. Open zeigt die MOTD dieses Servers (Kanal 0), ohne Entwürfe oder Cursorpositionen zu verändern. Connect/Disconnect wirkt auf die ausgewählte Zeile. Away schaltet den vom registrierten Server bestätigten Abwesenheitsstatus mit der Standardmeldung Away um. New (auch n) öffnet ein Formular; Back/Escape kehrt zum Chat zurück.

Server 0 kann nicht geschlossen werden. Disconnect erhält Ansichten, Entwürfe und angenommene DCC-Übertragungen. Close für einen sekundären Server verlangt immer eine Bestätigung mit voreingestelltem No; es verwirft den Arbeitsspeicher dieses Servers, bricht Angebote und Übertragungen ab, entfernt seinen Katalogverweis und behält seine Profildatei. Beim Schließen des ausgewählten sekundären Servers wird zum primären gewechselt. Im Testmodus ändert Close nur den Laufzeitzustand.

New enthält Server, Port, Transport, Nickname, Autojoin und Autoconnect sowie Edit, Add, Connect, Advanced und Cancel. Advanced zeigt Identitäts-, Authentifizierungsquellen- und CA-Einstellungen vor der ersten Verbindung. Enter übernimmt ein Feld vorläufig; Escape bricht das Formular ab. Neue Profile verwenden TLS6697, die Identität login/default und deaktiviertes autoconnect; sie übernehmen keine Geheimnisse, CA-Einstellungen, Kanäle oder watch/ignore-Listen. Nur Anwendungsvoreinstellungen werden geteilt. Add erzeugt unabhängig vom Häkchen bei autoconnect einen getrennten Server; Connect erzeugt und verbindet ihn sofort. Beide wählen den neuen Server aus und benötigen ein ausdrückliches Save für dauerhafte Speicherung.

Zeilen zeigen new N !M für ungelesene Aktivität und Erwähnungen an; die Anzeige endet bei 999+, ohne interne Zähler zu verändern. Beim Öffnen einer Unterhaltung werden nur deren Quellzähler zurückgesetzt; eine darüberliegende Liste markiert neuen Text nicht als gelesen. Gesamtwerte lassen Kopien aus Mentions und Help aus. Echos ausgehender Nachrichten erhöhen die Ungelesen-Zähler nicht. Das Lesen von Mentions markiert den eigenen Feed unabhängig, während die Zähler der Quellunterhaltungen erhalten bleiben.

F5 oder /unread gruppiert nach Server erst erhaltene Erwähnungen, dann ungelesene Unterhaltungen. Erwähnungen zeigen den vollständigen umgebrochenen Text mit Zeitstempeln; Quelleinträge kennzeichnen Server/Channel/Query. Aktionen: Open, Clear mentions, Back. Open wählt die Quelle aus; ein geschlossener Privatdialog kann anhand des aufgezeichneten Nicknamens wieder geöffnet werden, ohne etwas zu senden oder verworfenen Verlauf wiederherzustellen. Geschlossene Kanäle werden nicht erneut betreten, unerreichbare Server werden gemeldet. Die stabile Quellidentität, nicht Zeilenposition oder -text, bestimmt die Navigation.

Clear mentions oder /mentions clear entfernt Kopien der Erwähnungen auf allen Servern, ohne Unterhaltungsverläufe, Ungelesen-Zähler, Entwürfe oder Warteschlangen zu ändern. Neue Erwähnungen können unmittelbar eintreffen. Seitentasten blättern zunächst innerhalb einer langen ausgewählten Erwähnung, bevor sie den Eintrag wechseln. /mentions ohne Parameter wählt nur den Feed des aktuellen Servers.
