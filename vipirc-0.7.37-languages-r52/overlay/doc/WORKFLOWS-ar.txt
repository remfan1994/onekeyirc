دليل عملي لـ vipirc / onekeyirc - اختصارات المفاتيح والأوامر الآلية ونقل DCC
======================================================

ترجمة أولية. اكتب الأوامر والخيارات كما هي تماما.
للتفاصيل الأمنية الكاملة راجع MANUAL.txt وSECURITY.md بالإنجليزية.

/help autocommands
------------------

تخص الأوامر الخادم المحدد. تنفذ مرة واحدة بعد التسجيل ونجاح SASL المطلوب.

التأخير الافتراضي 15 ثانية، وبين اكتمال أمر وآخر 2 ثانية على الأقل.

اضبط الوقت عبر delay 0..300 وinterval 2..60. توقف الاتصال لا يطلق دفعة تعويضية.

الأوامر المسموحة: /msg و/join و/nick و/away و/back و/whois، مع أسمائها البديلة الموثقة.

الحد 16 أمرا، طول كل منها 511 بايت UTF-8. يجب أن يسع الأمر رسالة IRC واحدة ولا يقسم تلقائيا.

لا صدفة أو أوامر IRC خام أو توسعة للمحادثة الحالية. الانضمام التلقائي لا يبدل العرض.

تسري التغييرات عند الاتصال التالي. يوقف /cancel أوامر البدء التي لم ترسل بعد.

تخفي القوائم نص الرسائل ومفاتيح القنوات؛ ولا تحفظ الأوامر الآلية في السجل أو الصدى المحلي.

احفظ عبر /save. يجب أن يكون الملف خاصا (0600 أو 0400)؛ والقائمة المفعلة غير الفارغة تتطلب TLS موثقا.

وضع الاختبار لا يشغل الأوامر الآلية. يحفظ نصها كما هو في الإعدادات دون تشفير GPG.

/help bind
----------

لا توجد روابط مفاتيح مخصصة افتراضيا. راجع /bindings keys و/bindings actions للأسماء المدعومة.

التعيين الجديد يستبدل إجراء المفتاح السابق في كل الخوادم؛ وتبقى الروابط الأخرى.

تعمل الروابط في الدردشة والأوامر، لا أثناء اللصق أو كلمات السر أو الإعداد أو القراءة أو التأكيد.

تسري الآن لكنها لا تحفظ حتى /save input. يعمل التنقل المعتاد حين لا يوجد ربط مخصص نشط.

تقبل الوظائف المحلية المسماة فقط؛ لا أوامر عشوائية أو وحدات نصية أو إرسال أو توسعة shell.

قد لا تصل المفاتيح المحجوزة للطرفية إلى البرنامج؛ ولا يغير ربطها إشارات الطرفية.

/help bindings
--------------

دون معاملات يعرض اختصارات المفاتيح المخصصة للتطبيق كله. القائمة الفارغة تعني عدم وجودها.

استخدم /bind للتعيين أو الاستبدال و/unbind KEY للحذف و/unbind all لمسح القائمة.

تدعم F1..F12 وCtrl-A..Ctrl-Z وAlt-a..Alt-z وAlt-0..Alt-9 ومفاتيح التنقل المسماة.

Ctrl-H هو Backspace وCtrl-I هو Tab وCtrl-J وCtrl-M هما Enter وCtrl-[ هو Escape؛ والربط واحد.

حروف Alt صغيرة دون Shift. يعتمد وصول مفاتيح الوظيفة/Alt على الطرفية والمضاعف.

يحفظ حتى 64 ربط KEY=action في [hotkeys] بالإعداد الرئيسي. يحفظ /save input التغييرات.

انظر /help hotkeys للنطاق وحماية المسودة وإشارات الطرفية.

/help unbind
------------

حذف الربط يعيد السلوك المعتاد للمفتاح. يمسح all قائمة الاختصارات المخصصة فقط.

يسري التغيير فورا على كل الخوادم. استخدم /save input لبقائه بعد إعادة التشغيل.

/help hotkeys
-------------

تخصيص اختصارات المفاتيح اختياري وفارغ افتراضيا. تظل أدوات التصفح والتحرير العادية متاحة.

استخدم /bindings للقائمة و/bindings keys للمفاتيح و/bindings actions للوظائف المحلية.

عيّن باستخدام /bind KEY ACTION؛ كرر للتبديل. احذف باستخدام /unbind KEY أو /unbind all.

تطبق التغييرات فورا على كل الخوادم؛ يحفظها /save input في الإعداد الرئيسي. الملفات الإضافية لا تتجاوز الجدول.

الصيغة [hotkeys] وسطر KEY=action لكل مفتاح، بحد 64. تكرار المفاتيح أو أسمائها البديلة خطأ.

تعمل الإجراءات في الدردشة الرئيسية وموجه الأوامر فقط؛ لا في كلمات السر أو الإعداد أو اللصق أو القراءة أو التأكيد.

في الواجهة البسيطة تحفظ شاشات القراءة المسودة والمؤشر. تغيير الشاشة أو المحرر يرفض مسودة غير فارغة؛ أنهها أو امسحها.

لا إجراءات إرسال أو أوامر عشوائية أو shell أو وحدات نصية. للخلفية والخروج آثارهما المعتادة.

تتوفر F1..F12 وCtrl-A..Z وAlt-a..z/0..9 ومفاتيح التنقل؛ وتبقى الأحرف العادية نصا.

تشترك Ctrl-H/Backspace وCtrl-I/Tab وCtrl-J/Ctrl-M/Enter وCtrl-[/Escape في البايتات؛ لا تربط منفصلة.

إشارات الطرفية واختصارات المضاعف تسبق غيرها. لا يعمل Ctrl-C أو Ctrl-Z إلا إذا وصلا للتطبيق؛ لا يعاد تعيين المفاتيح.

اللصق المؤطر المعترف به لا يشغل الاختصارات. لا يمكن تمييز اللصق غير المؤطر عن الكتابة؛ انظر /help keys.

/help dcc
---------

دون معاملات يعرض النقل. يعرض /dcc NICK PATH ملفا على الخادم المحدد.

PATH هو بقية النص حرفيا بما فيه الفراغات؛ والمسار نسبي لمجلد بدء العملية.

لا يغير العميل هذا المجلد حتى عند تصفح الملفات أو التشغيل في الخلفية.

يعلن الإرسال المختصر IPv4 المحلي لاتصال IRC. خلف NAT استخدم -address لعنوان IPv4 يمكن الوصول إليه و-port لمنفذ محول.

لا يطلب كشف العنوان من خدمة خارجية. اتصال IRC المعتمد على IPv6 فقط يتطلب IPv4 محددا.

DCC اتصال مباشر غير مشفر. يرى الطرف الآخر IP المعلن؛ وقبول العرض يكشف له IP أيضا.

لا يفتح العرض الوارد حتى /dcc accept NUMBER. يستخدم DIRECTORY مجلد البدء افتراضيا ويجب أن يكون ملكك وخاصا.

لا يستبدل ملفا موجودا؛ وترفض الروابط الرمزية والملفات الخاصة. وضع الاختبار لا يفتح ملفات أو مقابس.

ارفض العرض عبر /dcc reject NUMBER أو ألغ النقل الجاري عبر /dcc cancel NUMBER.

أرقام النقل مشتركة بين خوادم العملية. إغلاق الخادم الأصلي يلغي نقله؛ وقطع IRC لا يلغي نقلا مقبولا.
