Практическое руководство vipirc / onekeyirc - Серверы, сводка, пользователи и слова отслеживания
======================================================

ЧЕРНОВОЙ ПЕРЕВОД. Пишите команды и параметры точно как показано.
Точные правила безопасности - в английских MANUAL.txt и SECURITY.md.

/help summary
-------------

Показывает все серверы, channel 0, каналы/личные чаты, непрочитанное, упоминания, очередь, команды запуска и передачи файлов.

Локальная сводка доступна без сети. Для обновления нажмите r в просмотрщике или повторите команду.

Открытие не меняет чат и не помечает сообщения прочитанными. Копии упоминаний не входят в итог активности.

Упоминания могут быть непрочитанными; итоги не складывайте. Различаются открытые и покинутые каналы.

Отчёт читается с прокруткой и хранит черновики. Косая черта открывает команды; отмена возвращает к сводке.

При ошибке обновления остаётся старая сводка. Открытие и обновление не делают сетевых запросов.

Данные входа, содержимое очереди сообщений и автокоманд никогда не выводятся.

/help server
------------

С именем хоста действует как прямой /connect; заранее создавать профиль не нужно.

Без аргумента выбирает сообщения/MOTD сервера. NUMBER выбирает слот без подключения.

add создаёт профиль с новыми учётными данными, проверенным TLS и отключённым autoconnect; не выбирает, не соединяет и не сохраняет.

Значение PORT по умолчанию 6697. Другой порт не выключает TLS; открытый текст надо выбрать явно.

connect/disconnect не меняют выбор. close удаляет вторичную сессию/запись списка, но не файл профиля.

Номера серверов в простом интерфейсе: 1..8, главный 1. Главный остаётся; отключайте, а не закрывайте.

Номера постоянны до конца сессии. Panel 0 предназначена для настроек приложения.

/help users
-----------

Это текстовый список людей, не переключатель видимости. Известные префиксы режимов показаны.

Список открывается в отдельном окне даже пустой. Enter, Escape или q возвращает в выбранный чат.

Up/Down и Page Up/Down прокручивают список. В Help клавиша Enter продолжает прокрутку.

Неполные или усечённые ответы NAMES отмечаются. Запросы WHOIS не отправляются.

/help watch
-----------

Упоминания ника всегда активны. Add/remove считает остаток буквальным текстом, не регулярным выражением.

До 32 дополнительных строк по 1..127 байт UTF-8 на сервер. Сохранить: /save.
