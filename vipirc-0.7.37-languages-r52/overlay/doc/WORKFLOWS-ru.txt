Практическое руководство vipirc / onekeyirc - Горячие клавиши, автокоманды и передачи DCC
======================================================

ЧЕРНОВОЙ ПЕРЕВОД. Пишите команды и параметры точно как показано.
Точные правила безопасности - в английских MANUAL.txt и SECURITY.md.

/help autocommands
------------------

Команды относятся к выбранному серверу. Они выполняются один раз после регистрации и обязательной SASL-аутентификации.

Задержка по умолчанию 15 секунд; между завершёнными командами не меньше 2 секунд.

Время задают delay 0..300 и interval 2..60. Зависшее соединение не вызывает очередь накопленных команд.

Поддержаны /msg, /join, /nick, /away, /back и /whois, а также их точно указанные псевдонимы.

Не более 16 команд по 511 байт UTF-8. Каждая должна поместиться в одно IRC-сообщение и не делится автоматически.

Нет оболочки, сырого IRC и подстановки текущего диалога. Автовход в канал не меняет выбранный экран.

Изменения действуют при следующем соединении. /cancel отменяет ещё не отправленные команды запуска.

В списках скрыты сообщения и ключи каналов; автокоманды не попадают в историю и локальные повторы.

Сохраняйте через /save. Файл должен быть закрытым (0600 или 0400); непустой активный список требует проверенный TLS.

Тестовый режим не запускает автокоманды. Их текст хранится в настройках буквально, без шифрования GPG.

/help bind
----------

По умолчанию нет своих привязок клавиш. Списки имен: /bindings keys и /bindings actions.

Новая привязка заменяет прежнее действие клавиши на всех серверах; остальные остаются.

Работает в чате и командной строке, но не при вставке, вводе пароля, настройке, чтении или подтверждении.

Вступает в силу сразу, но до /save input не сохранится. Без активной привязки навигация обычная.

Только именованные локальные функции; нет произвольных команд, макросов, отправки или раскрытия shell.

Зарезервированная терминалом клавиша может не дойти до программы; привязка не меняет сигналы терминала.

/help bindings
--------------

Без аргументов показывает личные привязки клавиш для всей программы. Пустой список значит, что привязок нет.

Назначить/заменить: /bind; убрать: /unbind KEY; очистить всё: /unbind all.

Доступны F1..F12, Ctrl-A..Ctrl-Z, Alt-a..Alt-z, Alt-0..Alt-9 и именованные клавиши навигации.

Ctrl-H = Backspace, Ctrl-I = Tab, Ctrl-J и Ctrl-M = Enter, Ctrl-[ = Escape; привязки у них общие.

Alt-буквы - строчные без Shift. Доставка функциональных/Alt-клавиш зависит от терминала и мультиплексора.

До 64 записей KEY=action в [hotkeys] основной конфигурации. /save input сохраняет изменения.

См. /help hotkeys о области действия, защите черновика и сигналах терминала.

/help unbind
------------

Удаление возвращает клавише обычное действие. all очищает только пользовательские привязки.

Действует сразу для всех серверов. Чтобы сохранить после перезапуска, используйте /save input.

/help hotkeys
-------------

Свои назначения клавиш необязательны и изначально пусты. Обычная навигация и редактор сохраняются.

Для списка: /bindings, клавиш: /bindings keys, функций: /bindings actions.

Назначьте через /bind KEY ACTION; повторное назначение заменит. Удалите через /unbind KEY или /unbind all.

Изменения сразу касаются всех серверов; /save input пишет их в основную конфигурацию. Доппрофили таблицу не меняют.

Формат: [hotkeys], затем по одной KEY=action на строку, до 64. Повторы, включая алиасы терминала, ошибочны.

Действуют лишь в основном чате и строке команд: не в паролях, настройке, вставке, читалке или подтверждениях.

В минимальном режиме просмотр сохраняет черновик и курсор. Смена экрана/редактора запрещена при черновике; завершите или очистите его.

Нет действия отправки, произвольных команд, shell или макросов. Фон и выход работают как обычно.

Доступны F1..F12, Ctrl-A..Z, Alt-a..z/0..9 и клавиши навигации; печатные символы остаются текстом.

Ctrl-H/Backspace, Ctrl-I/Tab, Ctrl-J/Ctrl-M/Enter и Ctrl-[/Escape имеют общие байты; разные привязки невозможны.

Сигналы терминала и сочетания мультиплексора главнее. Ctrl-C и Ctrl-Z действуют только если байт дошёл; клавиши не переназначаются.

Распознанная вставка с маркерами не запускает привязки. Вставку без маркеров нельзя отличить от ввода; см. /help keys.

/help dcc
---------

Без аргументов показ передач. /dcc NICK PATH предлагает файл на выбранном сервере.

PATH - оставшийся буквальный текст, включая пробелы; путь относительно каталога запуска процесса.

Клиент не меняет этот каталог, даже при просмотре файлов и в фоновом режиме.

Краткая отправка объявляет локальный IPv4 IRC-соединения. За NAT укажите доступный IPv4 через -address и проброшенный порт через -port.

Внешний поиск адреса не выполняется. Для IRC только по IPv6 нужен явный адрес IPv4.

DCC - прямое незашифрованное соединение. Партнёр видит объявленный IP; принятие предложения также раскрывает ваш IP.

Входящее предложение не открывается до /dcc accept NUMBER. DIRECTORY по умолчанию каталог запуска; он должен быть вашим и закрытым.

Существующие файлы не перезаписываются; ссылки и спецфайлы запрещены. Тестовый режим не открывает файлов и сокетов.

Отклонить предложение: /dcc reject NUMBER. Отменить передачу: /dcc cancel NUMBER.

Номера передач общие для всех серверов процесса. Закрытие исходного сервера отменяет его передачи; разрыв IRC не отменяет принятую.

/help transfers
---------------

Те же команды и защита, что у /dcc. Описание отправки, приёма и отмены: /help dcc.
