ПАРАМЕТРЫ КОМАНДНОЙ СТРОКИ

-i, --idle: выбрать минималистичный интерфейс для этого запуска; --help и --manual описывают его.
-N, --ncurses: выбрать полный интерфейс. Действует последний явно указанный ключ интерфейса; сохранённое значение не меняется. -n по-прежнему задаёт ник.
-s, --server HOST: выбрать основной сервер по имени хоста или числовому IPv4/IPv6-адресу, но не по URL.
-p, --port PORT: порт от 1..65535. По умолчанию 6697 для TLS или 6667 при явно выбранном незашифрованном IRC.
-c, --channel LIST: список каналов для входа после регистрации прямого профиля. Разрешены списки через запятую и повторяющиеся ключи. В оболочке заключайте '#channel' в кавычки; баунсер сам восстанавливает участие в каналах.
-n, --nick NICK: заменить ник действующего при запуске профиля.
-C, --config FILE: выбрать основной файл конфигурации, каталог .servers и директорию профилей .d. Файл должен существовать, если его не создаёт --init-config; пути интерпретируются буквально.
--tls: требовать проверенный TLS (по умолчанию). Указание порта само по себе TLS не отключает.
--plain: явно запросить незашифрованное соединение; аутентификация сохранёнными учётными данными будет отклонена.
--ca-file FILE: использовать собственные центры доверия PEM вместо системных. Непустой обычный файл не более 16 MiB; обычная символическая ссылка разрешена. Пароль не запрашивается.
--no-connect: запретить все стартовые подключения и симуляторы; подключайтесь позднее отдельной командой.
--background: запустить отсоединённый рабочий процесс без tty, TERM и нажатия приветственной клавиши. Используется сохранённый интерфейс по умолчанию, если -i/-N не задаёт иной. Сохраните профили autoconnect или укажите --server; --no-connect имеет приоритет. Успех означает локальную инициализацию, а не вход на IRC-сервер.
--reconnect: повторять попытки при временных сетевых сбоях только в этом процессе, не начиная подключение и не сохраняя предпочтения. Паузы: 5,10,20,40,80,160,300 секунд; 60 секунд стабильной регистрации сбрасывают порядок. /disconnect отменяет, /connect запускает снова. Ошибки сертификата, аутентификации, конфигурации и протокола оставляют соединение отключённым. Ожидающие сообщения отбрасываются. При новом соединении вновь выполняются аутентификация и стартовые команды; прямые профили повторяют autojoin, баунсеры восстанавливают каналы. Отложенные настройки подключения требуют явного /connect в отключённом состоянии.
--test-mode: интерактивная автономная симуляция без сети/DNS, чтения и сохранения учётных данных.
--resume [JOB]: присоединиться к единственной проверенной отсоединённой задаче либо указать её номер; допускается --resume=JOB. Явные абсолютные пути сокета поддерживают совместимые старые процессы. Без номера сохраняется её интерфейс; -i/-N запрашивает другой. stdin, stdout и stderr должны использовать один интерактивный tty. Несколько задач или непроверенная задача исключают автоматический выбор; уже подключённая задача занята.
--sessions: показать подключённые и отсоединённые задачи этой учётной записи без tty и загрузки конфигурации.
--detach-session NUMBER: освободить проверенный контроллер, сохранив процесс и состояние; затем использовать --resume NUMBER. Допускается --detach-session=NUMBER.
--close-session NUMBER: завершить весь процесс с IRC-подключениями, передачами, черновиками и историей в памяти. Файлы конфигурации и журналов сохраняются. Для признания успеха нужна проверенная очистка; тайм-аут может предшествовать завершению, поэтому снова проверьте --sessions. Допускается --close-session=NUMBER.
--init-config: создать закрытый конфигурационный файл, не заменяя существующие или одновременно создаваемые файлы. Сообщение об ошибке синхронизации/очистки может появиться уже после создания полного файла.
--check-config: проверить конфигурацию, переопределения, каталог и сохранённые профили и выйти. Не открывает секреты, не запускает GPG, не проверяет CA/TLS и не подтверждает достижимость или вход.
--manual: вывести полное руководство выбранного интерфейса без терминала.
-h, --help: вывести справку CLI без терминала.
-v, -V, --version: вывести версию, сведения об авторстве и лицензии без терминала.

Длинные параметры допускают --name=value, короткие можно объединять обычным способом. -- завершает разбор параметров; позиционные аргументы не используются. Значения CLI имеют приоритет перед конфигурацией и умолчаниями. При обычном запуске переопределения, не относящиеся к хосту, применяются к сохранённому профилю по умолчанию; явный --server выбирает основной. --init-config/--check-config работают с основным. Если сохранённый профиль недоступен, сначала исправьте его или укажите --server.

Если --server отличается без учёта регистра, очищаются унаследованные источники учётных данных, аутентификация, пользовательский CA, идентификация баунсера/автоматический away, каналы и стартовые команды. Настройте новый хост явно. Изменения того же хоста и один --nick сохраняют настройки профиля. Другой --config выбирает отдельное рабочее пространство.

--resume, --sessions, --detach-session и --close-session — отдельные операции управления: не объединяйте их между собой или с параметрами конфигурации, подключения и запуска. Поддерживаемые ключи интерфейса могут оставаться в псевдониме команды. --background не сочетается с этими операциями, --init-config или --check-config. --test-mode также не сочетается с --init-config/--check-config (код ошибки использования 2).
