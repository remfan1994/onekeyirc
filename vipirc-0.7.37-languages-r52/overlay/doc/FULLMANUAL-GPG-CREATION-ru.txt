СОЗДАНИЕ ЗАШИФРОВАННЫХ ФАЙЛОВ ПАРОЛЕЙ

Чтобы создать учётные данные GPG, используйте /panel в любом интерфейсе. Выберите сервер, gpg как источник аутентификации или серверного пароля, затем create. Предлагается абсолютный путь в каталоге учётных данных рядом с выбранной конфигурацией. Для основного профиля по умолчанию:

    ~/.config/vipirc/credentials/account-password.gpg

Для пароля PASS сервера используется server-password.gpg. Занятые имена пропускаются, предлагаются варианты с номерами. В панели показывается реальный абсолютный путь; символ ~ в примере приведён только для пояснения, не для буквального ввода в конфигурацию. Enter принимает путь и при необходимости подготавливает закрытые каталоги с правами 0700. Один просмотр предложения ничего не создаёт. Для своего пути должен уже существовать закрытый родительский каталог, принадлежащий пользователю; права существующих каталогов никогда не меняются. Путь и наличие локальной gpg проверяются до запроса ключа и пароля. Введите полный шестнадцатеричный отпечаток из 40 или 64 цифр ключа шифрования, уже имеющегося в локальном хранилище GPG, затем дважды введите скрытый пароль. Уже существующие зашифрованные файлы остаются доступными для выбора. Пути из панели сохраняются как абсолютные, поэтому изменение каталога запуска не меняет их значения. Ключи не загружаются и не создаются; файл открытого пароля не создаётся.

Только завершающее действие Save, Apply или Connect запускает шифрование и публикацию явно запрошенного нового шифртекста с правами 0600. Apply only и Connect once могут создать шифртекст, не сохранив конфигурацию. Существующие файлы и символьные ссылки отклоняются. У каждого помощника срок пять секунд; интерфейс продолжает обрабатывать сетевые события. При ошибке шифрования настройки не применяются, сообщается путь и причина без секретов и вывода помощника. Finish отличает предложенные пути от созданных файлов. После успеха для полных путей предлагается /autoauth status; если сохранение не удалось или публикация частичная, соответствующие пути остаются в прокручиваемой проверке. Повторное сохранение конфигурации возможно без нового шифрования. Отмена удаляет только новые неизменённые файлы данной попытки; файлы, на которые ссылается сохранённая конфигурация, остаются. Escape возвращается на вопрос назад и отменяет ожидающее создание; закрытие мастера стирает скрытые поля. Офлайновый режим отказывает в создании до доступа к GPG, ключам или файлам. Для будущего расшифрования при необходимости разблокируйте закрытый ключ вне приложения.
