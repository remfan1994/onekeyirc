PLATFORMLAR, DERLEME VE LİSANS

Hedefler arasında Linux, ChromeOS'un Linux ortamı ve BSD sistemleri bulunur. Derleme C11, POSIX arayüzleri, GNU/BSD getopt_long, geniş karakterli curses ve uyumlu TLS geliştirme dosyaları gerektirir. İstemci ayrı bir programlama dili çalışma zamanı istemez. Python 3 test ve belge üretimi içindir; dağıtılan çıktılar Python olmadan normal derleme ve sohbeti sağlar. Bağımlılıklar için INSTALL'a bakın.

    ./configure
    make
    make check-offline
    make check
    make install PREFIX="$HOME/.local"

Derleme ve bağımlılıklar için INSTALL'a, güvenlik modeli/sınırları için SECURITY.md'ye, gerçekten test edilen platformlar için sürüm doğrulama raporuna bakın. Yerel BSD çalıştırması ayrıca doğrulanmalıdır; taşınabilirlik hedefi her Unix benzeri sistemin test edildiği anlamına gelmez. make check-offline ağ soketi olmadan CLI/PTY testlerini yürütür; daha geniş make check testi yerel loopback sahte sunucularını da kullanır.
