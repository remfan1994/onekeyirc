КОМАНДЫ ПОДКЛЮЧЕНИЯ И ЗАПУСКА

/connect с параметрами прямо подключает к HOST; /connect без параметров использует выбранный сохранённый/применённый профиль. /server HOST [PORT] следует тем же путём. /server NUMBER выбирает профиль без подключения, /server без параметров открывает вид сервера/MOTD. /server add HOST [PORT] [NICK] добавляет отключённый несохранённый профиль. /server connect NUMBER, /server disconnect NUMBER и /disconnect [NUMBER] управляют нумерованными подключениями. /server close NUMBER закрывает вторичный профиль, оставляя его файл на диске.

Для новых адресов требуется проверенный TLS на 6697 и действующий ник/пользователь входа; учётные данные и каналы не наследуются. Совпадающее назначение сохраняет транспорт, порт, ник и аутентификацию, выбирая активное соединение, а не создавая второе. Если несколько профилей баунсера используют один хост, сначала выберите нужный NUMBER, затем простой /connect. Команды подключения не сохраняют настройки автоматически. В полном режиме слоты серверов 0..7 (основной 0), в минималистичном 1..8 (основной 1). Подключение/отключение не меняет выбор. Берите номера из /servers соответствующего интерфейса, а не из отдельного выбора /panel.

Параметры /connect идут перед HOST. -ssl — синоним -tls, +PORT требует TLS; обычный номер порта никогда не выключает TLS. Работают формы --tls, --plain и --nick; новая открытая связь по умолчанию использует 6667. Пароли не передаются позиционными аргументами. Close вторичного профиля удаляет ссылку каталога, черновики/историю и передачи, но оставляет файл профиля.

/autoconnect влияет на следующий запуск, не на текущее соединение. /autojoin готовит список каналов прямого профиля для следующего явного /connect, не вызывая join/part сейчас; запрос показывает регистрацию и действующие/ожидающие членства. Автоматические повторы сохраняют текущие настройки; /connect в отключённом состоянии применяет подготовленные изменения. /join действует сразу после регистрации. Баунсеры сами восстанавливают каналы, отказываясь менять autojoin; /autoauth для них тоже запрещён, пользуйтесь Settings или /panel.

/autoauth готовит SASL исключительно с проверенным TLS. Status локально показывает целиком текущие/отложенные пути к учётным данным без чтения файлов; обычный вывод Settings скрывает их. Запросы в полном режиме имеют Refresh/Back и сохраняют черновики. PATH — буквальный остаток строки, включая пробелы. Встроенные секреты следует хранить в закрытой конфигурации или Settings, не вводить командами.

/save без параметров записывает выбранный действующий профиль, в том числе отложенные настройки. /save input и /save output оба пишут основной профиль с параметрами приложения: это синонимы, не сохранение только ввода или вывода. Ожидающие изменения подключения основного профиля тоже входят. /save all записывает исправные профили; /saveconf дополнительно запоминает выбранный профиль по умолчанию для следующего /connect. Сохранение не включает autoconnect. Каждый файл пишется закрыто и атомарно, но всё пространство не является одной транзакцией: ранние успехи остаются после поздних ошибок. Нечитаемые профили не переписываются. Test mode никогда не сохраняет.

/set autoconnect on|off — совместимый псевдоним полного интерфейса. /set меняет настройки приложения в обоих режимах; параметры отправки, редактора и отображения влияют на минималистичный режим. /panel открывает пошаговую настройку в обоих; /quickstart спрашивает четыре основных параметра. /settings открывает формы в полном режиме и отчёт в минималистичном.

/list [MASK] [OPTIONS] после регистрации запрашивает список каналов сети. Серверу отправляется только MASK; --min-users/--max-users, --name и --topic фильтруют локально. --sort channel|users|topic, --asc/--desc и --limit N задают показ; по умолчанию сортировка по числу пользователей по убыванию, --limit 0 отменяет ограничение показа в кэше размером 8192 записей. /list show меняет сортировку/порядок/предел без повторного запроса; /list clear очищает кэш. /ls и /cl показывают только локальные виды.

При потере связи или явном отказе сервера от LIST частичные результаты остаются в кэше, но запрос освобождается. Повторите /list после регистрации либо очистите /list clear; неполный результат не является полным каталогом сети.

В браузере полного режима Up/Down или j/k выбирают строки, Left/Right или h/l — столбец сортировки, s обращает порядок, Page Up/Page Down и g/G служат навигации, Enter — входу, r — повтору запроса, / — Command, Escape — возврату. Щелчок по столбцу сортирует. В минималистичном режиме /list show печатает кэш, /summary показывает отдельный локальный обзор рабочего пространства.

    /connect [-tls|-plain] [-nick NICK] HOST [PORT]
    /connect
    /server HOST [PORT]
    /server NUMBER
    /server
    /server add HOST [PORT] [NICK]
    /server connect NUMBER
    /server disconnect NUMBER
    /disconnect [NUMBER]
    /server close NUMBER

    /autoconnect [on|off]
    /autojoin [list|add #CHANNEL|remove #CHANNEL|clear]
    /autoauth [status|off|sasl USER file PATH|sasl USER gpg PATH]

    /saveconf
    /set autoconnect on|off
    /panel
    /quickstart
    /settings

    /list [MASK] [OPTIONS]
    /list show
    /list clear
    /ls
    /cl
    /summary

    --min-users   --max-users   --name   --topic
