Optionales Sprachpaket r51: vipirc-0.7.37

Nur auf unveränderten englischen r1-Quellcode anwenden; nicht über r50 oder andere Sprachpakete installieren.
Wählen Sie eine der angezeigten Bereichsnummern.
Geben Sie einen IRC-Serverhostnamen oder eine IP-Adresse ein.
Geben Sie direct (ein Enter) oder review (zwei Enter) ein.
GPG-Dateierstellung ist im --test-mode deaktiviert; weder Hilfsprogramm noch keyring oder Datei wurden verwendet.
Sprachprüfung und vollständiger ncurses-Oberflächentest von vipirc stehen weiterhin aus.

  tar -xzf vipirc-0.7.37-english-source-r1.tar.gz
  tar -xzf vipirc-0.7.37-languages-r51.tar.gz
  sh vipirc-0.7.37-languages-r51/apply.sh vipirc-0.7.37
  cd vipirc-0.7.37
  ./configure && make
  VIPIRC_LANG=de ./vipirc --version
