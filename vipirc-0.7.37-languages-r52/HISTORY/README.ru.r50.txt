Дополнительный языковой пакет r50: vipirc-0.7.37

Применяйте только к исходному английскому коду r1 без изменений; не устанавливайте поверх r49 или других пакетов.
Новый файл учетных данных не должен совпадать с файлами конфигурации и их дополнениями; выберите предложенный каталог.
Шифрование GPG еще выполняется; ждите или вернитесь для отмены.
Введите полный отпечаток локального ключа GPG: 40 или 64 шестнадцатеричные цифры без пробелов.
Введите yes для проверенного TLS или no для IRC без шифрования.
Все еще требуются проверка носителями языка и полная проверка ncurses-интерфейса vipirc.

  tar -xzf vipirc-0.7.37-english-source-r1.tar.gz
  tar -xzf vipirc-0.7.37-languages-r50.tar.gz
  sh vipirc-0.7.37-languages-r50/apply.sh vipirc-0.7.37
  cd vipirc-0.7.37
  ./configure && make
  VIPIRC_LANG=ru ./vipirc --version
