Paket bahasa opsional r44: vipirc-0.7.37

Terapkan hanya pada kode sumber Inggris r1 yang masih asli; jangan timpa r43 atau paket sebelumnya.
Daftar ini berisi tampilan yang sudah terbuka di server terpilih. Up/Down memilih; Left/Right memilih Open, New, Part, atau Close; Enter menjalankan. Kanal 0 adalah server. /cl dan /channels menampilkan kanal lokal; /list [MASK] [OPTIONS] membuka direktori jaringan; /ql menampilkan percakapan privat.
Tinjauan penutur fasih dan pengujian penuh antarmuka ncurses vipirc masih diperlukan.

  tar -xzf vipirc-0.7.37-english-source-r1.tar.gz
  tar -xzf vipirc-0.7.37-languages-r44.tar.gz
  sh vipirc-0.7.37-languages-r44/apply.sh vipirc-0.7.37
  cd vipirc-0.7.37
  ./configure && make
  VIPIRC_LANG=id ./vipirc --help
