r23 добавляет полные черновые переводы глав SETTINGS и FILES AND ENVIRONMENT из руководства vipirc. Теперь подготовлены 45 из 52 разделов; необходима проверка носителями языков.

Исходный английский код: vipirc-0.7.36-english-source-r1.tar.gz
Необязательный языковой пакет и исправление RTL: vipirc-0.7.36-languages-r23.tar.gz

Распакуйте оба архива в один родительский каталог.
Примените исправление один раз перед настройкой и сборкой:
    sh vipirc-0.7.36-languages-r23/apply.sh vipirc-0.7.36

Сборка: cd vipirc-0.7.36 && ./configure && make
--version: vipirc 0.7.36 [lang-rtl-r23]
Язык: VIPIRC_LANG=ru

Не устанавливайте поверх прежних исправлений; используйте новую распаковку исходного английского кода r1.
Исходный английский код не меняется. Английские MANUAL.txt и SECURITY.md остаются основными источниками; переводы требуют проверки носителями языков.
Старые инструкции находятся в HISTORY/; не запускайте приведённые там команды.
