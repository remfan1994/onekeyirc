Pek bahasa pilihan r52: vipirc-0.7.37

Gunakan pada sumber Inggeris r1 asal sahaja; jangan tindihkan pada r51 atau pek lain.
Masukkan nama hos atau IP pelayan IRC tanpa URL atau port. Untuk ZNC atau soju gunakan /panel.
Pilih none, file (fail teks peribadi), gpg (fail tersulit) atau plain (nilai tersembunyi dalam konfigurasi).
direct = hantar dengan satu Enter; review = semak log dan sahkan dengan Enter kedua. Untuk semua pelayan.
Nama samaran atau pola nick!user@host.

  tar -xzf vipirc-0.7.37-english-source-r1.tar.gz

  sh vipirc-0.7.37-languages-r52/apply.sh vipirc-0.7.37

  ./configure && make
